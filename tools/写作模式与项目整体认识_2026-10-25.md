## 1 · 项目目标（owner 定的原话口径）

> **产出一套优化 Agent 思维面 / 思维跳跃性的工作流。**

**这不是"研究 Agent 有没有创造力"，也不是"评测别人的多 Agent 方法"。**
 它是：**我们提出一套工作流，目标是让 Agent 的思维面更宽、思维跳跃性更强，并且这套工作流本身是可设计、可学习、可驱动的。**

### ③ 方向③（三方向组 / 层3）
- **策略表示（核心公式）**：`score(a) = u[repair] + v[scope] + t[strict] + m[failure][repair]`，`p ∝ exp(u+v+t+m)`；**全策略 57 权重**（动作部分 47 = 6+2+3+6×6；架构自由度 10 = arb3+nf4+mm3）**因子化而非 36 路扁平 softmax**，**对照写准：36 路扁平 = 36 个权重，因子化 = 47 个，参数【更多】**（不是"更少"），**真正的理由是"每个权重的可学子空间更小、更语义明确"，更易学、更不易过拟合**；**只有对照"全交互扁平"（36×6 = 216）时才是数量级上的更少**
- **核心命题**：**在线性 softmax 里与 op 无关的状态特征对选择零作用**，**`m[failure][repair]` 是唯一让"当前失败类型"影响动作选择的通道**，**交互项退化的可诊断条件 = 触发器多样性 = 1**（本批实测 `{'conflict': 24}`，24/24 单一触发器，与因子偏置共线）
- **动作空间**：`action = (repair_type 6, scope 2, strictness 3)`，**36 个可组合动作**；判据「**映射关系是人手写的，就是层2**」
- **学习目标（代理奖励）**：`r = −λ_trap(6.0)×陷阱命中 + λ_width(4.0)×分支分散度 − λ_conflict_pairs(0.8)×跨槽位矛盾对数 − λ_cost(0.02)×调用数`；设计形式是**二元 MOO**（质量/多样性 + Pareto 非支配保留），当前实现是加权奖励
- **旧奖励失败可复算**：矛盾对数中位 = 0，**唯一在奖励里的项恒为 0**，奖励不区分任何行为，学出的 `u` 几乎全负且彼此无差别，**"优化器在平坦地形上走，权重只能是噪声"**
- **致命 bug**：`scored.sort(key=lambda x: -x[1][0])` 按 op 的**字符串**倒序排，策略永远选字母序第一个，**学习从未发生，而日志像在学**，原则：**聚合指标会把"根本没在学"显示成"在学"**，防护：操作直方图 + 逐维权重分解 + 每维对 argmax 的实际影响
- v3 架构训练：矛盾率 **33.3%→0.0%**、终局奖 **−0.47→+0.27**、**宽度没泛化**；7 轮×5 题×10 步
- 训练 v2（Agent 自主探索架构）：3 轮 5 份自主提案，宽度 2.00→3.2–4.0 全部↑、矛盾率 40–60% 全部↑、**0/5 采纳**、**反馈闭环有效 58.8%→40.0%**；留出集 69.2%/71.4%/71.4% 无一可行
- 三条踩坑才知道的：**必须给 proposer 行动空间说明书**；**诊断不能含 oracle 侧统计**
- 信用分配（设计）：把"自报置信度"换成「**这条反馈实际引用的依据 ID**」，agent×依据 离散表
- 查表 vs 学出来：**同一动作空间、同一份代码、同一套采样逻辑**，差只可能来自权重从哪来，**本篇最有用的消融装置**

# 第二部分 · 写作模式（九条铁律）

## 铁律一：先假设你啥都不知道

**不要被现有稿子的"未检出 / 未完成 / 局限"框架框住。**
**你的任务是：写出这篇论文该有的样子。**，**先按项目目标把主张、方法、论证结构写出来**，读数作支撑。
**不是"不用严谨"** —— **是"不要因为某条读数还没定版就不写这一节"**。

## 铁律二：主张在前，读数作支撑

 每一篇都必须能一句话回答：**「我们提出了什么？」**
**主张 = 方法 / 工作流 / 机制 / 判据，不是读数。**
 结构模板：**问题 → 我们提出的东西（主体，占最大篇幅）→ 为什么这样设计 → 第一轮实测 → 边界与下一步**。

## 铁律三：区分「限定」与「自我设限」（最重要的一条）

| | 是什么 | 例子 | 你的做法 |
|---|---|---|---|
| **限定**（保留） | **在什么范围内成立** | 「本批本域本口径下」「单题」「n=5」 | **保留**，这是科学诚实，也是可信度 |
| **自我设限**（删） | **把主张整个废掉** | 「本文未测 X，因此不能断言 Y」「本文不主张任何……」 | **删掉**，或改写成**下一节要做什么** |

**判定方法**：**这句话是在限定主张，还是在取消主张？**
**"在 X 范围内，我们观察到 Y"** = 限定 保留
**"因为没测 X，所以我们什么都不能说"** = 自我设限 删

**注意**： 「未检出」在这四篇里**大部分时候是限定而不是自我设限**（比如②的"未检出优于直调"在**双边净增益口径**下可能是错的，**它现在应该被写成"待补算"**），**不要一律删掉"未检出"，要判断它在这一句里扮演什么角色**。

## 铁律四：证据不足，写【待取证】条目，不写自我设限结论

**两种写法的区别（这是这一轮的核心机制）**：

**自我设限版**（禁止）：
> 「本文未测注意力层的内部激活，因此我们不能证明注意力机制是塌缩的根源。」

**待取证版**（要求）：
> 「**【待取证 T-L1-01】** 注意力层的内部探针读数。本节的主张（根源在注意力层）依赖三条机制链的可测代理量（`P1a` 后段新信息率 / `P4a` 早期决策保持率 / `P3a` 槽位结论集 Jaccard）。
> 取证目标：本地开放权重 `Qwen3-0.6B` + CPU 的注意力/隐藏态探针；**判据已在稿内定版**（H1–H7 各带可失败预测）。
> 取证完成后回填并复核本节主张是否成立。**在回填前，本节按『机制假说 + 已定版判据』陈述，不作存在性断言。**」

**区别**：前者**取消主张**；后者**保留主张 + 交出取证任务**，**后面审稿 Agent 拿到的是一张任务清单，不是一篇自我否定的稿子。**

## 铁律五：不许编数字（但这不等于自我设限）
