## 摘要

> **本文的规程尚未经过跨方法量化验证与外部复现**（见 §7 第 2 条与 §9）；因此本文的定位是**案例驱动的规程论文**，而非已证实有效的通用审计系统。

LLM 创造力研究的一类失效并非随机噪声，而是**结构性的**：研究者报告"完成了"，而实际上从未被独立验证。本文把这一类失效称为**「看起来完成」的落差**（the look-done gap），并给出**十三个**已被实例化的类别，每类附案例、可自动化的检测规则、以及各自的对策与其当前落地状态。**本文的结论强度按类别逐个不同**：十三类分属三档证据等级（§1.4），**不构成"十三类均已验证"**。我们主张三点：

**P1（诊断）**：创造力研究中的失败模式高度集中于**少数几个可枚举的机制**——门控里写进了先验、检查器本身是坏的、措辞污染了选择侧、二手转述未回源、判据只认字面词。这些不需要新的统计方法就能检测。

**P2（更根本）**：上述失效都属于**第二层**。更深的第三层是**代理错位**——我们用来代表"目标构念"的量（断言条数、去重宽度、字数、角色数）**本身就不是那个构念**；以及**行为冒充机制**——架构输出行为的改变被叙述成内部机制的改变，而两者的证据要求完全不同。

**P3（对策）**：**外部只读审计提供了一种重要的独立核验机制**：独立主体在不修改代码、不跑实验的条件下审计研究设计与实现，并把"机制归因成立 / 仅有输出行为对比"写成**预先声明的否证条件**。本文给出该审计协议，以及使其自身可信的三项要求。**本文不主张它是唯一有效的系统性防线**：规程、自动化测试、预注册、独立复现与数据审计与它**互补**，而本文**尚未**证明它优于、也不能替代它们（见 §7 第 2 条与 §9）。

**关键词**：研究方法 · 测量效度 · 可复现性 · LLM 创造力 · 外部审计 · 否证条件

## 1. 引言

### 1.1 问题的形状

创造力研究中的一个反复出现的现象是：**同一个机制，在开放作文题上有效，在有正确答案的实际题上完全失效**。这一现象的常规解释是"域不同"。本文主张，**在相当一部分案例中，域是最后才被查到的解释，而第一层原因是研究自身的测量结构**。

### 1.2 什么是「看起来完成」本文把失效的一类命名为**「看起来完成的落差」**：报告、图、表、代码、日志都存在且读起来完整，但**支撑核心结论的那条因果链从未被独立检查**。它与"做错了"不同。做错了会有反例；这一类**没有反例**——它安静地产生看起来漂亮的结论。

## 2. 第二层：六类具体机制

> 六类全部来自 `✅` 一手复盘材料：公开仓 `agent-creativity-mechanism-study` 的 `POSTMORTEM.md` 与 `HANDOVER.md`，二组 `v0.8.0优化交付.md`，第四组 `第四组论证.md` §5。**这四份文件不在本交付包内**（可回源状态见 §1.4 表 2）—— 外部核验需回公开仓。

### 2.1 ① 架构幻觉

**做了什么**：让 11 个 Agent"按方法说明回答四个问题"，每个方法说明代表一种认知机制。

**实际发生了什么**：Agent 读了一份方法描述，然后**写了一段叙述自己执行了该方法的文字**。机制从未被执行。

**怎么发现的**：抽了一个负对照的完整会话日志，三次工具调用：`read` 读提示词 → `write` 一次性写出全部 4 个答案 → `bash` 数字数。**没有 sleep，没有第二次生成。**

**更糟的是它自己汇报了**：

> "空放前后是否有实质变化：四题都有实质变化。Q1：空放前是'按分数排名给学校梯队'，空放后转为纠错…"

它详细描述了"空放前"与"空放后"两个版本——**而这两个版本里根本没有"前"**。这是模型为一个没发生的机制**编造的执行记录**。

**对策**：**用架构消除叙述空间，而不是靠提示词约束。** 改成每个 Agent 只执行一条 shell 命令（`python3 runarm.py <档> <题>`），不参与内容生成。

> **可自动化检测**：审计调用日志，检查每条声明的机制是否有对应的**多次独立工具调用**。`✅` 已固化为规程：**审计只认调用日志，不认 arm 的自述。**

### 2.2 ② 判定函数泄题

**做了什么**：设计一个"效用闸"判断候选答案是否站得住。

**实际问题**：`gate.py` 里的实体表是这样的：

```python
ENT = re.compile(r'(湖北|武大|华科|一本|特控|位次|专业组|转专业|保研|分数线|'
                 '床头|前15位|第\d+圈|退赛|补交|认错|'
                 '多血质|胆汁质|粘液质|抑郁质|单型|混合型|课堂|作业|清单)')
```

**这是四道题的标准答案元素全集。** 选中文档把 `gate.py` 重命名为 `CONTAMINATED-DO-NOT-REUSE`。

**为什么比提示词泄题更隐蔽**：模型**看不见这段代码**，它只在**选择侧**起作用——8–16 个候选里，谁提到了这些实体谁就过闸。

**后果**：三个臂报出的"闸门通过 8/8 全过"不可信。**很可能是闸门在认答案，不是机制在起作用。**

**为什么漏掉**：做了泄题检查，但只检查**提示词字面量**，没检查**判定函数**。

**对策**：**门控只允许"度量"，不允许"先验"**——参照系必须由调用方从**真实产出**传入；门控接口被设计成只能计算度量。`✅` 已固化为单元测试（`test_gate_contains_no_content_words` 专门守这条）。

> **可自动化检测**：把门控/判据文件里出现的**内容词**与题目/答案的关键词集合求交，交集非空即报警。`✅` 已有前车之鉴：一个判据文件因此被直接改名标记为不可复用。

### 2.3 ③ 检查器失效

**做了什么**：为"不得暗示答案"建了一套禁词表。

**实际问题**：代码里实际写的是

```
"① 哪一篇与常规建议最不同？② 哪一篇给出的具体判断最站得住？③ 哪一篇最不像套话？"
```

而禁词表是"新颖 / 不寻常 / 可检验 / 承重 / 深度 / 洞见…"这些**抽象词**。**一条都没命中。**

而且还拿这个结果当证据，宣称"已删除评价口径词"——**实际上被改的文件根本没被调用**，那 48 份产出用的还是旧措辞。

**对策**：**检查器必须先证明自己能抓到东西**。先把禁词表补上真实使用的口语化表述，把检查器升级为"先剥 docstring 和注释，只扫真正发给模型的字面量"，**并且必须先验证检查器能真的抓到东西（往代码里塞一个已知违规，看它是否报错），再用它当证据。**

> **可自动化检测（自举测试）**：**变异注入**——故意在代码里塞一个已知违规，检查器必须报错；塞一个已知合规，检查器必须放过。`✅` 该模式已在第四组用于验证负向测试本身有效。

### 2.4 ④ 措辞污染

**做了什么**：在选择判据里写"挑最不寻常 / 挑最不像套话的 / 挑最站得住的"。

**问题**：这三条几乎就是评分表（框架转换 / 可检验 / 立场代价）的原话。**把评价口径写进提示词，等于给所有臂的答案打上"这是高分点"的标签。**

**后果**：作文题那轮，去掉综合门的臂领先 **2.8 倍**（逃逸度 0.1048 vs 0.0377）。**据此得出"去掉综合门是关键"并建议了改造方向。**

**后来**：实际题那轮（改成中性措辞后）**反转了**——带融合门的臂反而领先（0.4659 vs 0.3030）。

**更诚实的一句**：那次反转**也没能干净归因**，因为一次改了两个东西（输出格式 + 选择措辞），没做单变量对照。

**对策**：选择判据改为**任务中性**（"对提问者最有用"）；**一次只改一个变量**——做不到就不要下因果结论。

> **可自动化检测**：把选择侧提示词与**评分表的维度词**做词表级比对，命中即报警。`✅` 记忆里已有同族教训：关键词机械过滤会误杀事实（`ceo-agent` 项目）。

### 2.5 ⑤ 二手转述未回源

**做了什么**：转述某篇 preprint 的一句话：ToT"generates and evaluates within the same model call"，并以此论证"ADHD 与 ToT 有承重差异"。

**实际问题**：下载 ToT 源码后，`bfs.py::solve()` 是三段完全分开的：

```python
new_ys    = [get_samples(task, x, y, ...)]           # 生成 ← 独立 gpt() 调用
values    = [get_values(task, x, new_ys, ...)]        # 评估 ← 独立 gpt() 调用
select_ids = sorted(ids, key=lambda x: values[x])[:n]  # 选择 ← 纯 Python
```

**生成、评估、选择是三个独立函数，不是同一次调用。** 那篇论文用来确立自身差异的**第三条论据，在代码层面不成立**。

**根因**：读的是那篇 preprint，**没读它所评论的那篇的代码**。

**对策**：**凡是从论文里转述的关于其他工作的说法，回去看被评论对象本身。**

### 2.6 ⑥ 关键词扫描漏判

**做了什么**：用正则按判据扫 48 份答复，报"12 个单元只有 2 个非零"。

**实际问题**：模型在自行车题里写的是"**早突围**""**兔子小集团**"——"兔子"就是中文业余赛里突围骑手的意思，"套圈"是同一个动作。**语义完全命中，但因为没写"透支""套圈"这两个词，被判 0 分。**

量表题同理：模型说了"三项负分与一项高分反差悬殊，可能反映**答题一致性偏差**"——察觉了异常，只是没命名成 ADHD，也被判 0。

**对策**：**判据扫描必须能识别同义表述。纯关键词匹配在这一层是不合格的工具。**

> **可自动化检测**：对判据扫描器做**语义等价改写测试**——把已知命中的答案做同义改写，命中率必须保持。

### 2.7 六类的共同结构

| # | 表面 | 真实 |
|:-:|---|---|
| 1 | 报告写完了 | 机制从未执行 |
| 2 | 检查器通过了 | 检查的是提示词，漏了判定函数 |
| 3 | 已删除违规措辞 | 改错了文件，内联实现没动 |
| 4 | 架构领先 2.8 倍 | 领先来自我自己的措辞 |
| 5 | 论文说 ToT 如此 | 代码不是如此 |
| 6 | 判据扫描客观 | 只认字面词，语义全漏 |

> **全部是"看起来完成了"与"被独立验证过"之间的落差。**
> **这类错误通常需要有人反复追着问"你怎么知道的"。** —— 但**追问只是防线之一**：本文**不主张**任何单一手段足以挡住全部六类（见 §4 开头与 §7 第 2 条）。

## 3. 第三层：四类更根本的失效

> 这一组的材料主要来自 `📌` **2026-10-20 的外部只读审计**（对第四组/三组 cmp8 实验台的一次只读代码与设计审计）。审计报告由独立主体产出、不修改代码、不跑实验；其提出的每一条技术指控，事后**逐条回查源码核实，全部成立**。
> **一手文件位于另一沙箱，尚未回查**；下文所有具体数字标 `📌`。

### 3.1 ⑦ 代理错位：测的是代理，目标是原物

**审计的判断**：研究的目标构念是**有效信息维度数**；而本研究用来代表"广度"的量是**断言条数**与**去重宽度**——**这两个都不是目标构念的替代物**。

**后果比 bug 更深**：即使核验器修好、容量匹配、错误率轴变得可读，**测的仍然不是目标**。

**由此得到的诚实修正**：一个被报告为"效果层接近 0"的结论，重新表述后应是"**机制层较好、度量层更低（因为口径选错代理）、效果层更低**"。

**同族证据**（`✅`）：字面相似度是采纳度的**反向**指标；逃逸度是**重加权**指标，测不出扩张；`n_raw` 严重高估内容量（去重后 18 条实例只剩 5.2 条不同考虑）。

**对策**：
1. **明确写出目标构念的定义**，再逐个审查"我用的这个量，是不是它"；
2. 把目标构念**锚定在可自动核验的原子事实上**（如依据包中的原子事实条目），使"新增维度 / 丢失维度"可自动计算，避免把主观性转移到标注协议里；
3. 报告"新增"与"丢失"**两侧**，净增益 = 新增 − 丢失。

### 3.2 ⑧ 行为冒充机制

**审计的判断**：风险登记里明写"输出发散被说成内部机制改变"。**内部机制作为独立假说，需要独立的机制测量。**

**预先声明的否证条件**（审计给出的、本研究此前没有的写法）：

> 机制归因成立 | 仅有输出行为对比 | **只描述行为；不宣称注意力集中或决策层过拟合已获内部因果证明**

**本研究自身踩过的同族坑**（`✅`）："权重改变了架构行为"成立（操作直方图实测），但"改变带来了更好的答案"不成立（内容轴不可用）——**两者必须分开写**。

**对策**：**在跑实验之前**就把"我们只声称到哪一层"写进否证条件表。事后再补的诚实声明不阻止错误结论的产生，只让它存活得久一点。

### 3.3 ⑨ 同名文件两份：改一处不同步

**审计发现的形状**：训练侧与执行侧各有一份**同名**的 `ops.py`，**内容已经不一致**。差异在 `assemble()`：执行侧多了一节"未经核验的断言"（`verdict=None` 的断言不再被静默丢掉），训练侧还是旧版。

**影响被精确分层**（这是本节最有价值的方法）：

| 缺陷 | 执行侧（只执行、不训练） | 训练侧（算梯度） |
|---|---|---|
| 特征/分数行错位 | **无害**——决策直接用 `w·f`，F/s_all 不参与决策 | **有害**——梯度把功记给了错的特征行 |
| softmax 用被污染的分数 | 无害 | **有害**——行为分布与更新假定的分布不一致 |
| 两份 `ops.py` 不一致 | — | **有害**——训练时算的"宽度" ≠ 实际交付的宽度 |

**已跑完的产出完全不受影响**；受影响的只有**"权重具体归因到哪一维"**这个解释层。

**真相源链**（`📌`）：`cmp8/rebuild/cmp8_p1.py` 是 `ops.py` 与 `learnarch.py` 的**唯一真相源**；`cmp8/creativity_lab/` 是它的产物；仓库根的 `creativity_lab/` 是**手写的老版本**——**这才是"重建流程漏一步"的经典形态**。

**对策**：
1. **单一真相源 + 派生产物**，禁止手写副本；
2. **字节级一致性校验**作为 CI 步骤（`cmp -s`）；
3. 每次改真相源后，**必须从干净解压重建再逐字节 diff**——逐字节一致只能证明"重建是确定性的"，**证明不了"重建流程是完整的"**（后者需要负向测试：把文件退回未打补丁状态，重建必须补回来）。

### 3.4 ⑩ 决策次数当独立样本数

**审计的判断**：把"决策次数"当作有效样本量，**会低估方差**。统计单位必须是**任务**。

**本研究自身曾被推翻的说法**（`✅`）：曾强调"特征与题无关，n = 决策次数，能泛化"。**方向对（不是题集上挑赢家），但 n 不能当独立样本数用。**

**对策**：分析单元 = 任务；题内重复测量是嵌套的，不是独立样本。**功效估计必须按任务数算，题数不够就买题数，不是买采样数。**

### 4.2 审计应覆盖的七个面

| 面 | 要问的问题 | 对应失效类别 |
|---|---|---|
| **执行** | 机制真的被执行了吗？日志能证明吗？ | ① |

| **一致性** | 同名文件是否同版本？训练侧与执行侧同源吗？ | ⑨ ⑪ |
| **归因** | 我们声称的机制强度，与证据类型匹配吗？ | ⑧ |

### 4.3 让审计自身可信的三项要求

1. **变异注入**：审计提出的每条检测规则，必须先被"故意注入一个该类缺陷"验证过能抓到；不生效的规则不许写进规程。

### 5.2 写报告时

- [ ] 每一张表/图能指出它的**生成命令与输入文件**
- [ ] 每个百分比**同时给绝对分母**（"矛盾率 25%（分母 1 条）"）

- [ ] 正式结论与过程记录**分栏**

### 5.3 判断"这是不是假信号"

| 症状 | 最可能的成因 | 检查 |
|---|---|---|
| 冒烟测试优势巨大，换题就消失 | n=1 噪声 | 至少 5 题复现 |
| 改一个词结论就反转 | 措辞污染 | 单变量对照 |
| 聚合指标漂亮但行为分布没变 | 聚合掩盖"没在学" | 打印**操作直方图** + 每维权重对 argmax 的实际影响 |

| 换了判据就变结论 | 判据与被测同源 | 跨家族判官 + 判据自检 |
| 归因到某一维权重 | 特征/分数行错位 | 断言 `F[choice] == 被选中动作的特征` |

### D.2 新增第十二类：**"指标零区分度"伪装成结论**

> 证据等级 **E1**（§1.4）｜ 实例 A 与实例 C **已回源**到 `来源与底稿/来源_第二组交付报告_1025_全文_872行_结论0至2.17.md`（结论 4 ③ 与第二部分 B「我推翻了自己的什么」）｜ **实例 B 的原始分母表本包内未核到，记为 `📌` 待回查**（§9 第 9 项）。

**实例 A**（语义面宽旧口径，已回源）：组内归一化 `cos ≥ 0.7`，**四个臂全报 4.0**。
**"四个臂一样宽"这个"结论"，是口径造的，不是数据说的。**
修法：**增量判据** —— 支 j 被覆盖 ⇔ `cos(支j,输出) > max_{k≠j} cos(支j,支k)`（**严格大于**；零增量 = 没带来额外偏好）。

**实例 B**（历史 84 份答案的比率，【待回查】**本包内未核到原始分母表**）：**5 个非零矛盾率样本的分母都 = 1**，**那些比率不可分辨**。
**此处"不可分辨"是分母结构问题，不是"没测出差异"**：分母为 1 时该比率**没有可分辨的取值空间**，**本文不据此对任何效应下"未检出"判决**（本文亦未做该对比的功效估计）。通用规则：**比率指标必须配绝对分母**。

**实例 C**（自校准锚用错，已回源）：`survival_rate` 是**跨支均值**，只复制了其中一支的输出只能拿 ≈1/n（n=5，0.2），我据此判"历史归档错位"，**其实是我的锚错了**（实测 0.277 本该通过）。通用规则：**干净锚 = 自我覆盖**（输出与**最像它的那支**的覆盖率），应 ≈ 1.0。

**这一类与原文的区分**：原文 ⑩ 讲"决策次数当独立样本数"（低估方差）；这一类讲的是"**指标本身没有分辨力，却照样输出了表**"。
