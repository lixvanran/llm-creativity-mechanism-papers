## 摘要

「搜索空间过早闭合」是 LLM 创造力研究里被反复引用、却很少被**操作化**的一个说法。本文的贡献不是再描述一次这个现象，而是把它变成一组**可分别证伪的命题**，并在**纯黑盒**（无内部探针、无自托管权重）的条件下执行其中可执行的部分。

我们把「闭合」定义为**相对于一个参照系**的可证伪命题（定义 1），并给出**三层分离协议**——解码层、表征层、架构层——每一层有自己的主指标与可失败预测。主指标是**宽度指数** `α = d log PR / d log K`（`PR(K)` = K 次独立采样产出的去重并集宽度），选择它是因为绝对宽度差**基本落在噪声地板内**（臂间最大绝对差 11 条，而同臂换样本的自助 SD 就有 3.3–9.1 条、跨配置重跑的 Δ 最大 74 条）。

**本文报告三个层次的结果。**

**一、现象成立，但只在一个层面成立。** 每份答案 9 条断言去重后只剩 **5.2 条**不同考虑；实例内互相余弦 **0.91–0.97**；分支数增加而有效信息维度**不增**（0.457 vs 基线 0.500）⇒ **表述层同质化成立**。

**二、但在解码层，"搜索空间被关死"不成立。** 纯采样的宽度指数 α = **0.886**（95%CI [0.739, 1.045]，K≤3）与 **0.944**（95%CI [0.772, 1.117]，K≤4），三套独立口径同向；K=3/4 处边际增益仍有 **+10.4 / +16.1 条每新增一次采样**，**未见饱和**。

**三、归因到注意力机制在现有数据下不被支持。** 全部可用数据都在行为层（文本 + 外部核验器）：`logprobs` 被托管 API **静默忽略**（请求不报错、字段直接不存在）⇒ typicality / NLL / perplexity / PMI **全族作废**；沙箱无 GPU ⇒ 无自托管打分器；全仓不存在任何注意力权重、logits、hidden state 或表示层探针数据。⇒ 我们把结论写成"**剩余候选 = 表示/架构侧**"，而不是"我们证明了是注意力机制"。

**方法论上，我们主张本文最可复用的产物是三层分离协议本身**——它把"为什么模型变平庸"这个笼统问题，拆成三个能各自被证伪、且各自指向不同补救方向（采样侧 / 训练侧 / 架构侧）的问题。特别地，**架构层的干预已被实测为无效**：直调臂与工作流臂的 α 配对后 **5/5 的 95%CI 全部含 0**，且该结论与质量轴（18 个工作流变体 13 个更差、融合门矛盾率是直调的 10.5 倍）**不共享任何指标**。⇒ **在解码层加采样，是我们目前唯一测出正结果的方向**（K≤4 内还能拓开）；而这条路便宜得多。

**关键词**：搜索空间塌缩 · 过早闭合 · 宽度指数 · 黑盒操作化 · 三层分离 · 解码层 · 表述层

## 1 引言

### 1.1 现象：想法变少，不是答案变差

给定一个开放问题，LLM 的答案常常安全、完整、而空洞。它列出正确的类别、引用常识，却不给出任何**能改变决策**的具体信息。工程上这表现为"读起来像专家写的"，但拿它做决策时，它与一个没有上下文的通用回答差别不大。

我们把「答案有多空」叫做**中庸**（medianity）。

但"中庸"作为一个观察是无用的——它没有告诉你**该修哪里**。要修，就得知道闭合发生在哪一层。

### 1.2 我们与已有工作的边界

| 工作族 | 它改什么 | 它不触及什么 |
|---|---|---|
| 一般 Agent 搜索（ADAS、AgentSquare）| 搜**解**（或 agent 代码结构）| 问题空间**由任务给定** |
| 推理树/图搜索（ToT、GoT）| 搜**解路径** | 路径空间**由问题给定** |
| 反思机制（Reflexion、Re3、Self-Reflection）| 修**已有答案** | 不增**维度** |
| 注意力坍缩 / 低熵解码 / 早收敛（内部机制侧）| 给出**内部**成因假说 | 需要内部激活；本文**测不到** |
| **本文** | 给出**黑盒可执行的分离协议**，并执行其中可执行的部分 | **不**给内部机制判决 |

★ 关键区分：前三族**都在一个给定的空间里搜**。而"为什么这个空间会变小"这个问题，需要的是**分层**，不是更多的搜索。

### 1.3 贡献（三条，对应章节）

> **C1（概念）**：「搜索空间过早闭合」是一个**相对概念**——相对于某个参照系才谈得上闭合。本文给出一个**纯黑盒、可操作、可证伪**的定义与分离协议（§3.1、§3.3）。
>
> **C2（测量）**：给出输出侧可测表征（去重后有效信息维度数、宽度指数 α），并证明它与 token 数、字数、语义相似度等常见代理**不等价**（§3.2、§3.4）。
>
> **C3（分离）**：给出**三层分离协议**（解码层 / 表征层 / 架构层），并在**能力边界内**（黑盒 API、无内部探针）执行其中可执行的部分，给出**混合判决**（§5）。

## 2 相关工作

### 2.1 内部机制侧：注意力坍缩、低熵解码、早收敛

这一族给的是**内部**成因假说：注意力质量过度集中、多头塌成同质、logit 层低熵使采样几乎确定、长程依赖被相对位置衰减截断。

⚠️ 本文与这一族的关系必须写清：**我们不与它们竞争，也不复述它们。** 它们需要内部激活，而我们在黑盒条件下**拿不到**。我们能做的是**排除其他层**，从而把剩余候选收窄——这是**排除法**，不是**正面归因**。

⇒ 一个必须写进引言的诚实声明（来自 §7.3 的实际教训）：在托管 API 下，`logprobs` **静默忽略** ⇒ 这族文献里依赖似然的度量（typicality / NLL / perplexity / PMI）**在本文的实验条件下全部不可用**。⇒ 所以本文不是"没用上这些工具"，是"**这些工具在黑盒条件下不存在**"。

### 2.2 多样性坍缩与典型性偏置

- 📄 **Typicality bias**（arXiv:2510.01171，6,874 对正确性匹配样本）：人类**系统性偏好更典型的那个**，控制 TTR / perplexity / 长度配对后仍成立 ⇒ **perplexity / logprob / 离语料中心的 embedding 距离，在优化"个性"时是反向指标**；真实关系是**倒 U**。
- 📄 **Diversity Collapse**（ACL 2026 Findings 13）：专家权威 persona 会压多样性（Interdisciplinary 的 Vendi 最低 4.65，Horizontal 最高 8.08，而质量只差 0.62）。

⇒ 这两条给本文一个**方法论约束**：凡用于广度判断的指标，必须能区分"一个大而蓬松的云团"与"五个紧密的小簇"——而重加权类指标（逃逸度、离默认答案更远）**做不到**。

### 2.3 「问题空间」侧的既有工作

- 📄 **PSFA**（Wray / Kirk / Laird, *Eliciting problem specifications for LLM-Modulo cognitive systems*，Cognitive Systems Research 94:101409 (Elsevier, 2025)；arXiv:2405.12147）：它发现的"漏掉项"**参照系是人类专家的问题空间分解（Newell 1980 / GOMS）**，候选槽位**先验封闭**；它自己承认 *"...the least successful of all the nodes we included"*，把"生成 novel problem spaces"列为**开放问题**，并写下 *"strong attractor effect"* 与 *"parrot similar problems and solutions"*。
- 📄 **Novelty Search**（arXiv:2608.04341）与 **POET**（arXiv:1901.01753）：给出"以新颖性为目标的搜索"的形式化。

⇒ ⇒ **我们与 PSFA 有量纲差异的位置，正是"锚外"**：它封闭的是**问题空间**，我们问的是**答案空间**；且我们要求"锚外"可数（`VD_anchor_out`），从而给出一个**会让我们自己失败**的量。

⚠️ **必须澄清三处文献误用**（我们在核验中亲自踩到）：
① **Curiosity Search 没有"独立维度 / leave-one-out"这回事**——那是本项目自造并外借的用法；
② **MAME 是 agent×agent 的置信度矩阵**，不是 agent×依据的引用矩阵；
③ **POET 是 5 类障碍 / 9 个基因参数**，不是"独立维度"的搜索。

⇒ 引用错这三处，等于宣称前人做过我们没做的事。

## 3 方法

### 3.1 ★ 定义 1（黑盒闭合）—— 全文的支点

> **定义 1（黑盒闭合）**
> 设 R 为一个**参照系**（另一个模型 / 另一个采样温度 / 另一类任务）。
> 模型 M 的**可达集** `A(M)` = M 独立采样 K 次所得产出的去重并集。
> 则 M 相对 R **闭合** ⟺ `|A(M)| < |A(M) ∪ A(R)|`，且差异超出噪声地板。

**为什么这个定义重要**：
1. 它把「闭合」从**修辞**变成**可证伪命题**；
2. 它**不需要** `logprobs` / 注意力探针 ⇒ 在纯 API 环境下可执行；
3. 它把"归因"变成**可分离的**问题：**换参照系 = 换层**。

⚠️ **定义 1 自带一个必须写出来的限制**：它要求 |A(M)| 与 |A(M) ∪ A(R)| 用**同一套去重口径**计算，否则"A 比 B 宽"可能只是口径差。⇒ 本文所有宽度读数**必须带去重阈值**（§3.4）。

### 3.2 ★ 先把两个词分开（混在一起就量不出来）

| 词 | 定义 | 行为表征 | 本文测的是它吗 |
|---|---|---|:-:|
| **搜索空间** | 系统能产出的答案的**集合** | 结论集覆盖、宽度 | ✅ |
| **过早闭合** | 搜索**提前停止**探索 | 边际利用率提前掉零 | ⚠️ 代理（见 §5.5） |
| **塌缩** | 多样性在下降 | 跨 rep 交集率上升 | ✅（与上两者相关但不等价） |

⇒ **塌缩 ≠ 过早闭合**：塌缩是"空间在缩小"（可以一直缩到很小），过早闭合是"提前停止探索"（空间可能还很大，但不再往里走）。**二者的机制未必相同** ⇒ §5.5 给出一条**归因路由**（H7）。

★ **另一个必须正面处理的攻击**："这不就是输出冗余吗，不是塌缩吗？"
⇒ **冗余是同一答案内的重复；塌缩是不同答案之间的收敛。** 本文同时给两者，并**明确本文测的是后者**。

### 3.3 ★ 三层分离协议

| 轴 | 改变什么 | 参照系 | 主指标 | 状态 |
|---|---|---|---|:-:|
| **解码层** | 采样温度 / top-p / 采样数 K | 同模型不同温度 | `α(T) = d log PR / d log K` | ✅ **已测** |
| **表征层** | 模型档位 | 同族不同档位 | `Δ_PR = PR(跨档) − PR(同档 K=32)` | 【待完成】预注册待触发 |
| **架构层** | 工作流形式（分支数 / 融合策略 / preflight / 自检） | 同模型不同工作流 | `PR(工作流)` vs `PR(direct)` | ✅ **已测** |

★ **这一节是全文的骨架**——三轴都测了，层1 才是一个**完整的分层论证**；只测一轴，就只是一个单点观察。

### 3.4 ★ 主指标：宽度指数 α，以及为什么不能用绝对宽度

**宽度** `PR(K)` = K 次独立采样的去重并集宽度（去重口径：语义去重 + 字符 n-gram 去重，**必须报阈值**）。
**宽度指数** `α = d log PR / d log K` ⇒ **尺度无关**。

**为什么必须用指数**（✅ 实测，这是本文最实用的一条方法论）：

| 地板来源 | 量级 |
|---|---|
| 同臂同题换掉取哪 K 个样本（自助 SD） | **3.3 – 9.1 条** |
| 跨配置重跑（同臂同题，提示词不同） | Δ宽度均值 −14.7 ~ +26.7，**最大 74 条**，SD 最大 41.0 |
| **臂间 K=1 的绝对宽度差（最大）** | 21.6 − 10.4 = **11 条** |

⇒ ⇒ **绝对宽度差基本落在地板内** ⇒ 只有**指数**（尺度无关）能把差异从地板里捞出来。⇒ 且所有小于地板的差异一律写「**不可分辨**」，不写"无效应"。

**去重阈值必须带曲线**：同一份输出，阈值 0.10 与 0.30 可以让面宽从 5 变成 0 ⇒ **任何单点"面宽"数字都必须带阈值，且必须给曲线**（这一条来自第二组 10-25 的实测，属跨篇通用纪律）。

★ **为什么层1 用指数而不是绝对宽度、或任何"含 n 的比值"** —— 这里还有一条来自第二组的**定量教训**（见 A 篇 §3.8.1）：
> **任何含 n 作分母的量，在比较不同 n 的臂时是恒等式，不是因变量。**
> ⇒ 实测「多样性度量的 n 基线」：真·无效应下，「秩/n」**系统性下降**（245–290/300）⇒ 拿它检验"面变宽"**假阴性 ≈ 100%**；而 Vendi **系统性上升**（300/300）⇒ 不会把真效应判成假。
⇒ ⇒ ★ **本文的 α = d log PR / d log K 正是为了避开这个陷阱**：它比较的是**增长率**，不是**比值**。
⇒ ⇒★ **而且还有第二道门**（2026-10-24 晚补做）：**即使指标选对了，还必须减去它的机械基线** —— 嵌套子集校准（同一组 8 支里抽 5 支取 p90，K=200）显示，8 支实测超出机械基线的组次只有 **模态 10/27（37%）/ Vendi 5/27（19%）** ⇒ ⇒ **"读数方向对"不等于"效应成立"**（详见 A 篇 §3.8.1）。

### 3.5 有效信息维度数：为什么不能用量、角度数、新颖性

- **断言数 ≠ 维度数**：一条断言可以复述、铺陈、免责，**不改变任何决策**。
- **角度多样性 ≠ 维度数**：认知帧的 `trap` 字段是"**被否决**的信息"，**不承重** ⇒ trap 多 ≠ 维度多。
- **字符数 / token 数 ≠ 维度数**：同一答案在判官提示词版本变动下，承重维度读数在 `0/+1/−1` 与 `+1/+4/0` 之间跳 ⇒ **带宽 > 信号**。

⇒ ⇒ **唯一能站住的是"这条信息改变了哪个决策"** ⇒ 承重检验（C1 决策岔口可指名 / C2 删除反事实成立 / C3 在预注册结论空间内）。

⚠️ **C3 是最大的自伤点**：它使"发现原先未被纳入的维度"在结构上不可能 ⇒ 这正是 `VD_anchor_out`（锚外新增维度数）被提出来的原因，也是 §5.6 的接口。

### 3.6 统计纪律

分析单元 = **题**；同题多步 rollout 不是独立样本；差值必须 vs 噪声地板，落在地板内写「**不可分辨**」；正/负结论都要写分母；n=3 翻转 1 题 = 33 个百分点（这类读数必须带量级提醒）；"无效应"与"无检出力"必须分开。

### 5.2 ★ 一句话结论

> **「搜索空间过早闭合」在表述层是真的**（一次生成就把想法收窄，多个分支说的是同一句话）；
> **但在解码层不是**（只要多采样几次，有效信息维度就继续按 ≈K^0.9 增长）。
> ⇒ **闭合不是模型"想不出"，也不是"采样不出来"；是"说出来的高度同质"。**
> ⇒ 因此**在 Agent/架构层做分叉是无效的**（工作流臂与直调臂的 α 配对后 5/5 不可分辨），
> **在解码层做更多采样才有希望**——但本数据集 K≤4，**尚未定位平台**。

★ 这与论文簇里已有的结论**不冲突，而是给它补上了缺失的那一半**：A 篇的 944 条断言实验测的是「架构层干预有没有用」（答案：没有）；本文补的是「如果不改架构、只改采样，会怎样」（答案：K≤4 内确实能拓开）。

## 6 讨论

### 6.1 ★ 四层合起来看：到底该往哪投入

| 层 | 它告诉我们什么 | 它给出的下一步 |
|---|---|---|
| **层1（本文）** | 塌缩在**表述层**；解码层采样在 K≤4 内还能拓开，但**结构维度拓不开**（index 0.135）；**注意力归因不被支持** | 补 K ∈ {8,16,32}；拿到内部激活访问权才谈机制 |
| **层2** | **「面」本身不产生优势**；优势来自「面 + 有效的取舍规则」；融合门是双输 | 落地「排序取前 k，逐支输出到预算用尽」；补质量轴 |
| **层3** | 巡练分**不可用**（ρ=+0.166）；目标函数必须**二元**；宽度轴**不需要**留出集 | 换目标 = 检索 / 核验在环，不是加搜索 |
| **层4** | 反馈通路成立（9.13×）；驱动力通路**读数冲突**；状态化选择**要么无效要么恒真** | 状态必须在**生成过程内部**起作用 |

⇒ ⇒ ★ **一句话**：**四条路都指向同一个动作——把"什么算一个问题空间的一部分"这件事从"人写死的清单"里拿出来。**
层1 说清单把空间写死（H6）；层2 说摊开面不产生优势；层3 说宽度轴不需要留出集但巡练分不可用；层4 说状态写进 prompt 也不行。
⇒ ⇒ 而**我们目前唯一测出正结果的方向是"多采样几次"**（α ≈ 0.89–0.94，K≤4 未饱和）——**但 index=0.135 告诉我们它只拓开了条数、没拓开结构维度。**
⇒ ⇒ ★ **这是一个诚实但不舒服的结论**：我们最大的杠杆可能在**解码层**（更便宜、更简单），而它在**结构维度**上恰恰是不够的。

### 6.2 我们与 PSFA 的差异

PSFA 在 GOMS 先验格子里填，**我们要求锚外可数**。⇒ 这不是"我们更好"，而是**可证伪性**的差异：我们给了一个它没给的、**会让我们自己失败**的数。

### 6.3 与 Diversity Collapse 的关系

该文的贡献是**诊断**（多样性崩塌 + 权威吸引子 + 强吸引子效应），我们的贡献是把它接到**承重**判据上：*多样性*不等于*维度*，*权威*必须从判官身上剥掉。

### 6.4 与 AgentSquare / ToT 的关系

AgentSquare 证明**模块化设计空间**是可搜的；本文的"承重检验"在它的四模块框架里**无处安放** ⇒ 既是风险也是差异化。ToT 搜解路径；本文搜"该考虑哪些维度"，且**必须**配同预算 best-of-k 对照——否则"架构有增益"可能只是"多花了钱"。

### 6.5 给实践者的一条建议

> **要判断你的 Agent 有没有被"中庸"困住，不要看它答得对不对，要看它答的**条数**有多少种**结构。
> 因为本文实测：**多采样能给你更多条想法，但给不了更多条结构上不同的想法**（index = 0.135）。
> ⇒ **加采样次数是半个解。另一半在"要不要真的按结构去重"上。**

## 8 结论

我们把「搜索空间过早闭合」从一个**说法**变成了一组**可分别证伪的命题**，并给出了一个**纯黑盒可执行**的分离协议。

**一、我们给了"闭合"一个可操作的定义。** 相对于参照系的可达集比较（定义 1），换参照系 = 换层；主指标是尺度无关的宽度指数 α，因为绝对宽度差**基本落在噪声地板内**。

**二、我们执行了协议中在黑盒条件下可执行的部分，并给出混合判决。**
现象在**表述层**成立（9 条断言去重后剩 **5.2 条**，实例内余弦 **0.91–0.97**）；
在**解码层不成立**（α = **0.886 / 0.944**，K≤4 未饱和）；
**架构层已被实测为无效**（Δα **5/5 CI 含 0**，与质量轴不同指标同向）；
**注意力归因不被支持**（无任何内部激活数据）。

**三、我们把剩余候选收窄了，但没有假装收窄就是归因。** 剩余唯一候选 = **表示 / 架构侧**；ES 这条关系性证据在当前条件下**不可判定**（只有 mistral-nemo 的熵可测）。⇒ 我们写的是"**与注意力机制相容但本文未检验**"，不是"我们证明了是注意力机制"。

**四、我们给出了一个反直觉的限定，它可能是本文最有用的一句话。**
采样层能拓开**条数**（α ≈ 0.9），但**结构维度拓不开**（PR@32 = 4.11 vs 隔离参考 30.37 ⇒ **index = 0.135**）。
⇒ ⇒ **"多采样几次"是半个解。** 这既是当前唯一测出正结果的方向，也是它不够的地方。

⇒ ★ **一句自我限制**：本文**不**证明闭合的成因，**不**证明任何单一架构能解除闭合，**不**在饱和域上观察过闭合，**不**把维度数与人类评分绑定。
⇒ ⇒ 而按本项目的既有纪律——**"声称已验证 ≠ 已被验证"**——我们把上面每一条的**否证条件**写在了 §7 里：读者可以照着否掉我们。
