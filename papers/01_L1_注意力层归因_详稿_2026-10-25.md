## 摘要

「搜索空间过早闭合」是 LLM 创造力研究里被反复引用、却很少被**操作化**、也很少被**归因**的一个说法。本文做两件事：**把它变成一组可分别证伪的命题**（"闭合"是相对于一个参照系的可达集比较——定义 1，§1.2），并**提出"过早闭合最可能源于注意力层"的机制假说**—— **提出的形式不是断言，而是四条各自带可失败预测的机制链**（§2）**本文提出的是【机制假说】，不是已完成的归因；本批数据对该归因既不支持、也不否证，判决悬置（§6.5）**。

**我们提出了三样东西。**

**① 归因假说：四条机制链。**H1 前缀自洽诱导**（注意力质量压在自己刚写的内容上，后续是续写而非新探索）、**H3 头间冗余**（多头 / 多槽位同质，"发散"只是名义上的）、**H4 早期决策锁定**（相对位置衰减，长程依赖弱，早期决策被锁）、**H6 锚外结构上不可能**（注意力质量落在可枚举清单上，有效支撑集 = 清单，"锚外发现"结构上不可能）。每条链都带**代理量 + 可失败预测 + 若不成立转哪一条**，四条链合起来是一个**判决式集合**，而不是四个故事：**读完 §2，读者就知道下一步该做哪一件事能判掉哪一条**（§2.6）。

**② 定位工具：三层分离协议。** 解码层 / 表征层 / 架构层，每层有自己的主指标、可失败预测与本批状态，它回答的是"**这个归因落在哪一层**"，**本文最可复用的产物是三层分离协议本身**——它把"为什么模型变平庸"这个笼统问题，拆成三个能各自被证伪、且各自指向不同补救方向（采样侧 / 训练侧 / 架构侧）的问题（§3）。

**③ 测量学：宽度指数。**

```
    PR(K) = | ⋃_{i=1..K} Dedupe(S_i) |        （K 次独立采样的去重并集宽度）
    α     = d log PR(K) / d log K
```

**它回答什么问题**：**搜索空间宽不宽、以及能不能被撑开**（α = 1 线性增长；α < 1 边际收益递减；α ≈ 0 则加采样不再拓开空间），选择它是因为绝对宽度差**基本落在噪声地板内**（臂间最大绝对差 11 条，而同臂换样本的自助 SD 就有 3.3–9.1 条、跨配置重跑的 Δ 最大 74 条）（§4.1、§4.2）。

**本文报告三个层次的结果。**

**一、现象成立，但只在一个层面成立。** 每份答案 9 条断言去重后只剩 **5.2 条**不同考虑；实例内互相余弦 **0.91–0.97**；分支数增加而有效信息维度**不增**（0.457 vs 基线 0.500），**表述层同质化成立**。其中"有效信息维度不增"这一条是**条件性证据**：承重判据本身存在已知循环风险、且未做正负对照验证，**不能单独支持「没有产生新维度」**，只能与表述层同质化的其它读数同向（§4.5）。
**本文测的是「相对覆盖不足」，不是「过早停止探索」**：后者是**另一个构念**，需要额外的**停止条件或预算—收益曲线**才能测，**本文未测**（§1.3），因此本文在解码层只给出**「未观察到明显饱和」**，**不给"过早停止探索"的判决**。

**二、但在解码层，"搜索空间被关死"不成立。** 纯采样的宽度指数 α = **0.886**（95%CI [0.739, 1.045]，K≤3）与 **0.944**（95%CI [0.772, 1.117]，K≤4），三套独立口径同向；K=3/4 处边际增益仍有 **+10.4 / +16.1 条每新增一次采样**。**在当前任务集与 K≤4 的实验范围内，未观察到答案宽度的明显饱和；更大采样规模下的增长规律尚待验证。**两个 95%CI 均包含 1，数据并未证明增长率低于线性增长**；α 是**点估计 + 区间**，不是增长律（K 只覆盖 3–4，无法判断更大预算下是否出现平台）。

**三、架构层的干预在本批测量下未检出与直调臂的差异。** 直调臂与工作流臂的 α 配对后 **5/5 的 95%CI 全部含 0**；该读数与质量轴（18 个工作流变体 13 个更差、融合门矛盾率是直调的 10.5 倍；**该组 dual 臂数字未按 4 支口径重算**，见 A 篇 §7 局限 25）**不共享任何指标**；**α 轴 5/5 的 CI 全部含 0，不提供方向**，质量轴给出方向，**两轴互不矛盾，但不构成同向证据**。**这是「未分辨」，不是「不等效」**：本批每个 (数据集, 臂) 的独立采样数只有 K=3–4、每题的 α 只有 3–4 个 log 点、题数 5–10，**这是一条功效不足的不可分辨，不是一条等效性结论**（检出力声明见 §6.8.1）。**在解码层加采样，是本批唯一测出正结果的方向**（K≤4 内**未观察到明显饱和**）；而这条路便宜得多。

**四、本批排除的是解码层，不是注意力层。** 全部可用数据都在行为层（文本 + 外部核验器）：`logprobs` 被托管 API **静默忽略**（请求不报错、字段直接不存在），typicality / NLL / perplexity / PMI **全族作废**；沙箱无 GPU，无自托管打分器；全仓不存在任何注意力权重、logits、hidden state 或表示层探针数据。**"我们测不到注意力层" ≠ "注意力不是根因"**（§7.2）：注意力层是**未测**，不是**未证**（三层里**两轴已测、一轴本批不具备仪器**），其探针读数按 **【待取证 T-L1-01】** 登记，而**判决式已在 §2 定版**。

**最后，本文把一个可操作的靶点交给 ②③④**：**塌缩的真正条件不是"答案唯一"，而是"解法路径唯一"**（§6.6），**设计必须作用在【路径】与【可分叉决策数】上**（§8）。

## 1 引言 · 问题：搜索空间过早闭合

### 1.1 现象：想法变少，不是答案变差

给定一个开放问题，LLM 的答案常常安全、完整、而空洞。它列出正确的类别、引用常识，却不给出任何**能改变决策**的具体信息。工程上这表现为"读起来像专家写的"，但拿它做决策时，它与一个没有上下文的通用回答差别不大。我们把「答案有多空」叫做**中庸**（medianity）。但"中庸"作为一个观察是无用的——它没有告诉你**该修哪里**。要修，就得知道闭合发生在哪一层，**更要知道它为什么会发生**。本文对这两个问题各给一个答案：**§2 回答"为什么"（归因论证）**，**§3 回答"落在哪一层"（分离协议）**。

### 1.2 「闭合」的可操作定义（定义 1）—— 全文的支点

> **定义 1（黑盒闭合）**
> 设 R 为一个**参照系**（另一个模型 / 另一个采样温度 / 另一类任务）。
> 模型 M 的**可达集** `A(M)` = M 独立采样 K 次所得产出的去重并集。
> 则 M 相对 R **闭合** ⟺ `|A(M)| < |A(M) ∪ A(R)|`，且差异超出噪声地板。

**为什么这个定义重要**：
1. 它把「闭合」从**修辞**变成**可证伪命题**；
2. 它**不需要** `logprobs` / 注意力探针，在纯 API 环境下可执行；
3. 它把"归因"变成**可分离的**问题：**换参照系 = 换层**。

**定义 1 自带一个必须写出来的限制**：它要求 |A(M)| 与 |A(M) ∪ A(R)| 用**同一套去重口径**计算，否则"A 比 B 宽"可能只是口径差。本文所有宽度读数**必须带去重阈值**（§4.2）。

### 1.3 把「闭合」拆成两个可分别证伪的构念

> **定义 1 判定的是「相对覆盖不足」**：相对于一个明确指定的参照系 R，模型 M 遗漏了哪些**可识别的**答案或维度。
> 它首先测量的是**两个可达集之间存在差异**，**不必然意味着 M 过早停止了探索** —— 两个模型只要各自产生了一个对方没有的答案就可能满足该条件，**即便双方都充分探索过各自的可达空间**。

> **「过早停止探索」是另一个构念**：在给定预算下，继续探索本来还能产生具有意义的新维度，但当前过程**已经停止或明显降低探索效率**。
> 测它**需要额外的停止条件或预算—收益曲线**（例如边际利用率在什么预算下掉零），**本文未测**。

**本文的 K≤4 边际增益为正（+10.4 / +16.1 条每新增一次采样），这恰恰不构成"提前停止"的证据**，因此本文在解码层只给出**「未观察到明显饱和」**，**不给"过早停止探索"的判决**。

**三个构念的完成度（全文口径固定，§6.5 判决表与摘要按此对齐）**：

| 构念 | 本文测了吗 | 本文给的读数 | 证据状态 |
|---|:-:|---|---|
| **(i) 相对覆盖不足**（输出表述层同质化） | **测了** | 9 → 5.2 条断言；实例内互相余弦 0.91–0.97 | 行为层成立（§6.5 第 1 行）|
| **(ii) 过早停止探索** | **未测** | — | 需停止条件或预算—收益曲线，**本文未测**；归因路由见 §5.1 |
| **(iii) 解码层采样能力饱和** | **测了**（限 K≤4） | α 点估计 0.886 / 0.944，两个 95%CI **均含 1** | K≤4 内**未检出**饱和；K>4 **未测** |

### 1.4 三个词必须分开（混在一起就量不出来）

| 词 | 定义 | 行为表征 | 本文测的是它吗 |
|---|---|---|:-:|
| **搜索空间** | 系统能产出的答案的**集合** | 结论集覆盖、宽度 | |
| **过早闭合** | 搜索**提前停止**探索 | 边际利用率提前掉零 | **本文未测**（需停止条件或预算—收益曲线，§1.3）；代理量见 §5.1 |
| **塌缩** | 多样性在下降 | 跨 rep 交集率上升 | （与上两者相关但不等价） |

**塌缩 ≠ 过早闭合**：塌缩是"空间在缩小"（可以一直缩到很小），过早闭合是"提前停止探索"（空间可能还很大，但不再往里走）。**二者的机制未必相同**，§5.1 给出一条**归因路由**（H7）。

**另一个必须正面处理的攻击**："这不就是输出冗余吗，不是塌缩吗？"
**冗余是同一答案内的重复；塌缩是不同答案之间的收敛。** 本文同时给两者，并**明确本文测的是后者**。

## 2 归因论证：四条机制假说与它们各自的可失败预测

> **本章是本文的主体**。§1 把"闭合"变成可证伪的命题；**本章回答"为什么"**；§3 回答"**这个归因落在哪一层**"。

### 2.1 本章的论证形式：机制假说 + 已定版判据（本文提出的是假说，写在哪一层）

**本文的主张**：搜索空间过早闭合的最可能机制，是注意力层的四条各自带可失败预测的机制链（H1 / H3 / H4 / H6）—— 本文给出的是【机制假说 + 已定版判决式】，不是已完成的归因。

### 2.2 机制链 A · H1 前缀自洽诱导（premature closure 的首选机制）

| 项 | 内容 |
|---|---|
| **部件** | 解码步的**自注意力对已生成前缀**的质量分布 |
| **信号** | 注意力质量过度集中在**最近生成**的内容上（而不是题面 / 依据 / 更早的候选） |
| **机制链** | ① 前缀被写进上下文，② 每一步的注意力质量有一部分压在**它自己刚写下的内容**上，③ 下一个 token 的分布被前缀约束，④ 后续内容是对前缀的**续写**而非新探索，⑤ **有效支撑集变小**，⑥ 过早闭合 |
| **代理量** | `P1a` **后段新信息率**（答案后 70% 里"全文首次出现"的新实体 / 新断言占该段断言的比例）；`P1b` **前缀复述率**（后 30% 的实词 n-gram 落在前 70% 的比例） |
| **可失败预测 F-H1** | ① 在**同一臂内**，`P1a` **随生成位置单调下降**；② 在**臂间**，`P1a` 与**步数 / 前缀长度负相关**（步数多的臂，后段新信息率更低）<br>，**两条都不成立，H1 被否证**（"过早闭合"另有来源） |
| **若不成立，转哪一条** | 闭合不在**局部自洽**，转 **H6**（任务表示把空间写死了） |
| **本批状态** | 代理量**已实现并实测**（9 份答案），**零 API 成本**；**但判决所需的两项（臂内单调性 + 臂间相关）尚未执行**，见 **【待取证 T-L1-02】** |
| **效度边界** | 代理量测的是**文本层**的自洽性，**不等于**注意力质量分布，若 `P1a` 不降，也可能是模型本来就写不长 |

**为什么 H1 是"首选机制"**：它是四条链里**唯一一条在"局部续写"这个粒度上就能解释"过早"**的——它不需要"整个空间被写死"这种强条件，只要**注意力质量有一部分压在已写内容上**，就足以让后续变成续写，这也是它**最先该被测**的原因。

**判读陷阱（写在这里是为了不被后来的读者踩）**：单调性要在**臂内**检验（同一臂的前 30% vs 后 30%），**不要在臂间比**（臂间差异混着格式与预算），底稿实测过格式对称性问题：**4 个字段不对称**，跨臂读数混着格式贡献。

### 2.7 与内部机制文献的关系：我们不与它们竞争，我们把它们写成判决式

这一族给的是**内部**成因假说：注意力质量过度集中、多头塌成同质、logit 层低熵使采样几乎确定、长程依赖被相对位置衰减截断。

**本文与这一族的关系（一句话）**：**我们不与它们竞争，也不复述它们——我们做的是把它们从"假说"变成"判决式"。** 它们的每一条（注意力熵塌缩、logit 低熵、头间同质、位置衰减）在本项目里都对应 §2 里的一条链、一个**可测代理量**和一条**可失败预测**，**差别在于：它们说"可能会这样"，我们说"做成这样就能判掉这一条"。**

一个必须写进引言的诚实声明（来自 §7 的实际教训）：在托管 API 下，`logprobs` **静默忽略**，这族文献里依赖似然的度量（typicality / NLL / perplexity / PMI）**在本文的实验条件下全部不可用**。所以本文不是"没用上这些工具"，是"**这些工具在黑盒条件下不存在**"（§7.1）。

**但这条限制只作用在"读数"上，不作用在"论证"上**：§2 的四条链**不依赖任何内部量就能被表述、被判决**——它们的代理量全部在**文本层 / 结构层**，**正因为如此，§2 的论证今天就是可执行的**，只是执行它需要按 §2.6 的表去取对应读数（§12.1 的 T-L1-02 … T-L1-05）。

### 2.8 多样性坍缩与典型性偏置

- **Typicality bias**（arXiv:2510.01171，6,874 对正确性匹配样本）：人类**系统性偏好更典型的那个**，控制 TTR / perplexity / 长度配对后仍成立，**perplexity / logprob / 离语料中心的 embedding 距离，在优化"个性"时是反向指标**；真实关系是**倒 U**。
- **Diversity Collapse**（ACL 2026 Findings 13）：专家权威 persona 会压多样性（Interdisciplinary 的 Vendi 最低 4.65，Horizontal 最高 8.08，而质量只差 0.62）。这两条给本文一个**方法论约束**：凡用于广度判断的指标，必须能区分"一个大而蓬松的云团"与"五个紧密的小簇"——而重加权类指标（逃逸度、离默认答案更远）**做不到**。
**同时给 §2 的一条边界**：Diversity Collapse 说**权威 persona 会压多样性**，那是**输入侧**的机制，与 H6 同族；而本文的 H3 说的是**多头侧**的同质，两者是**不同的链**，不可互相代替。

### 2.9 「问题空间」侧的既有工作

- **PSFA**（Wray / Kirk / Laird, *Eliciting problem specifications for LLM-Modulo cognitive systems*，Cognitive Systems Research 94:101409 (Elsevier, 2025)；arXiv:2405.12147）：它发现的"漏掉项"**参照系是人类专家的问题空间分解（Newell 1980 / GOMS）**，候选槽位**先验封闭**；它自己承认 *"...the least successful of all the nodes we included"*，把"生成 novel problem spaces"列为**开放问题**，并写下 *"strong attractor effect"* 与 *"parrot similar problems and solutions"*。
- **Novelty Search**（arXiv:2608.04341）与 **POET**（arXiv:1901.01753）：给出"以新颖性为目标的搜索"的形式化。

**我们与 PSFA 有量纲差异的位置，正是"锚外"**：它封闭的是**问题空间**，我们问的是**答案空间**；且我们要求"锚外"可数（`VD_anchor_out`），从而给出一个**会让我们自己失败**的量。**而 H6（§2.5）给这个差异补上了机制解释**：清单在生成侧，注意力被清单吸住，锚外不可能。

**必须澄清三处文献误用**（我们在核验中亲自踩到）：
① **Curiosity Search 没有"独立维度 / leave-one-out"这回事**——那是本项目自造并外借的用法；
② **MAME 是 agent×agent 的置信度矩阵**，不是 agent×依据的引用矩阵；

## 3 三层分离协议：把这个归因定位到哪一层

> **这一章是本文最可复用的产物。** §2 给出了"归因是什么形状"（四条链）；本章给出"**它落在哪一层**"的定位工具。

### 3.1 协议

| 轴 | 改变什么 | 参照系 | 主指标 | 本批状态 |
|---|---|---|---|:-:|
| **解码层** | 采样温度 / top-p / 采样数 K | 同模型不同温度 | `α(K) = d log PR(K) / d log K` | **已测**（K≤4） |
| **表征层** | 模型档位 | 同族不同档位 | `Δ_PR = PR(跨档) − PR(同档 K=32)` | **【待完成】**预注册待触发；**本批不具备该仪器**（§7.1 三条原因），**未测**，不是**未证**；探针读数见 **【待取证 T-L1-01】** |
| **架构层** | 工作流形式（分支数 / 融合策略 / preflight / 自检） | 同模型不同工作流 | `PR(工作流)` vs `PR(direct)` | **已测**（未检出差异，≠ 不等效） |

**协议为什么是"工具"而不是"分类表"**：**每一轴都自带一个可失败预测**——不是"我们测过了"，而是"**如果这条轴上有东西，它会这样表现；没这样，这一轴被排除**"。于是 §2 的四条归因链可以被**逐条**钉到某一轴上：H1 / H4 落在**注意力与局部性**（解码层与表征层之间），H3 落在**表征层**，H6 落在**输入侧的任务表示**（由 §5.1 的 H7 路由把它判给流程层或层1）。

| 轴 | **可失败预测**（有东西，应当这样表现） | 若不成立，|
|---|---|---|
| **解码层** | 采样能力饱和，α 显著 < 1 且随 K 掉到平台 | 排除解码层（K≤4 内的范围内） |
| **表征层** | 更高档位，`Δ_PR` 显著大于噪声地板；档位↑，锚外维度率↑ | 排除"表征层单调更宽" |
| **架构层** | 工作流能撑开，`PR(工作流)` 显著大于 `PR(direct)` | 排除"架构层干预可拓开"（需检出力足够，§6.8.1） |

**三轴中两轴已测、第三轴本批不具备仪器**，因此本文交付的是**分层检验框架 + 一次定位**，不是**已完成的三层分离**；**只测一轴，就只是一个单点观察**。

### 3.2 与 §2 的接口：链 → 轴

| 归因链（§2） | 它主要落在哪一轴 | 该轴上的可失败预测 | 若该轴被排除 |
|---|---|---|---|
| **H1** 前缀自洽诱导 | 解码层（逐步生成）× 表征层（注意力质量分布） | 臂内 `P1a` 单调降 ∧ 臂间与步数负相关 | H1 仍可成立（它跨两轴），转 H6 |
| **H3** 头间冗余 | 表征层（多头分工） | 去权威化臂 `P3a` 显著低于基线 |，瓶颈在模型内部，层2/层3 的天花板确定 |
| **H4** 早期决策锁定 | 表征层（位置编码 / 局部性） | `P4a` 与长度 / 前 1/3 结论数正相关 |，转 H6 / H7 |
| **H6** 锚外结构上不可能 | 输入侧（任务表示），由 H7 路由判给流程层或层1 | 无依据臂 `VD_anchor_out` 显著更高 |，锚外不是被清单卡的，转 H1 / H4 |

**这张表是"三层分离协议"的真正用途**：它让"归因"与"层"之间有一个**可执行的连接**，而不是两张各说各话的表。

### 3.3 为什么必须分层，而不是更多搜索

 前三族工作（§1.5）**都在一个给定的空间里搜**。**在同一个空间里搜得更多，只会让"这个空间为什么会变小"这个问题原封不动地留在桌上。**，**分层不是分类癖，是因为每一层的补救方向完全不同**：解码层，改采样（便宜）；表征层，改训练 / 表征（贵）；架构层，改工作流（最贵），**不知道落在哪一层，就不知道该花哪一档的钱**。

## 4 测量学

### 4.1 核心公式：宽度指数 α

**宽度** `PR(K)` = K 次独立采样的去重并集宽度（去重口径：语义去重 + 字符 n-gram 去重，**必须报阈值**）。

```
    PR(K) = | ⋃_{i=1..K} Dedupe(S_i) |        S_i = 第 i 次独立采样的产出
    α     = d log PR(K) / d log K
```

**它回答什么问题**：**搜索空间宽不宽、以及能不能被撑开。**

| α 的取值 | 读法 |
|---|---|
| **α = 1** | 宽度随采样数**线性**增长，每多采一次，多拿一份等量的新东西 |
| **α < 1** | **边际收益递减**，加采样仍有收益，但越来越小 |
| **α ≈ 0** | 加采样**不再拓开**空间，搜索空间被关死 |

**为什么用指数**：它比较的是**增长率**，不是**比值**，**天然不含 n 作分母**，直接避开"任何含 n 的量在比较不同 n 的臂时是恒等式"的陷阱（§4.2）。
**本文的两个 95%CI 均含 1，数据并未证明增长率低于线性增长**，α 是**点估计 + 区间**，不是增长律（K 只覆盖 3–4）。

### 4.2 为什么不能用绝对宽度（噪声地板）

**为什么必须用指数**（实测，这是本文最实用的一条方法论）：

| 地板来源 | 量级 |
|---|---|
| 同臂同题换掉取哪 K 个样本（自助 SD） | **3.3 – 9.1 条** |
| 跨配置重跑（同臂同题，提示词不同） | Δ宽度均值 −14.7 ~ +26.7，**最大 74 条**，SD 最大 41.0 |
| **臂间 K=1 的绝对宽度差（最大）** | 21.6 − 10.4 = **11 条** |

**绝对宽度差基本落在地板内**，只有**指数**（尺度无关）能把差异从地板里捞出来。且所有小于地板的差异一律写「**不可分辨**」，不写"无效应"。

**去重阈值必须带曲线**：同一份输出，阈值 0.10 与 0.30 可以让面宽从 5 变成 0，**任何单点"面宽"数字都必须带阈值，且必须给曲线**（这一条来自第二组 10-25 的实测，属跨篇通用要求）。

**为什么层1 用指数而不是绝对宽度、或任何"含 n 的比值"** —— 这里还有一条来自第二组的**定量教训**（见 A 篇 §3.8.1）：
> **任何含 n 作分母的量，在比较不同 n 的臂时是恒等式，不是因变量。**
> 实测「多样性度量的 n 基线」：真·无效应下，「秩/n」**系统性下降**（245–290/300），拿它检验"面变宽"**假阴性 ≈ 100%**；而 Vendi **系统性上升**（300/300），不会把真效应判成假。
**本文的 α = d log PR(K) / d log K 正是为了避开这个陷阱**：它比较的是**增长率**，不是**比值**。
**而且还有第二道门**（2026-10-24 晚补做）：**即使指标选对了，还必须减去它的机械基线** —— 嵌套子集校准（同一组 8 支里抽 5 支取 p90，K=200）显示，8 支实测超出机械基线的组次只有 **模态 10/27（37%）/ Vendi 5/27（19%）**，**"读数方向对"不等于"效应成立"**（详见 A 篇 §3.8.1）。

### 4.3 α 的估计方法、拟合点与不确定性（四要素逐项登记，未归档项显式写明）

| # | 要素 | 本文能给到的 | 状态 |
|:-:|---|---|:-:|
| 1 | **估计方法** | `α = d log PR(K) / d log K`（对去重并集宽度取对数后对采样数取对数的斜率）；**尺度无关**，故可跨 K 比较 | 已写在正文 |
| 2 | **拟合点** | 两个批次：**审计仓 arm1**（7 题，K≤3）与**第四组 C0**（10 个题×文件组，K≤4）；每个 (数据集, 臂) 的独立采样数只有 K=3–4、每题的 α 只有 **3–4 个 log 点**、题数 5–10，**拟合点的数量本身就很薄** | **规模可回源；逐点数据未随本稿归档** |
| 3 | **误差估计方法** | 本文只报 **95%CI**（K≤3 [0.739, 1.045]、K≤4 [0.772, 1.117]）；**CI 的具体构造做法（回归 / 自举 / 迭代次数 / 随机种子）未随本稿归档** | **未归档** |
| 4 | **去重阈值敏感性** | 已有的阈值敏感性证据 = **三套去重口径下的 α 三元组**（embo-01@0.75 / @0.85 / 词面@0.60，0.886 / 0.948 / 1.108 与 0.944 / 0.926 / 1.022，方向同向）；**完整阈值曲线未随本稿归档** | **部分未归档** |

**为什么这一节必须写在这里（这不是补充说明，是可复核性声明）**：判决表声明"表内所有数字由脚本从若干机读数据文件取，不手抄"，但**那些取数脚本与机读数据文件在本仓内不存在**，**本文的 α 目前不可由第三方独立复算**。

### 4.4 有效信息维度数：为什么不能用量、角度数、新颖性

- **断言数 ≠ 维度数**：一条断言可以复述、铺陈、免责，**不改变任何决策**。
- **角度多样性 ≠ 维度数**：认知帧的 `trap` 字段是"**被否决**的信息"，**不承重**，trap 多 ≠ 维度多。
- **字符数 / token 数 ≠ 维度数**：同一答案在判官提示词版本变动下，承重维度读数在 `0/+1/−1` 与 `+1/+4/0` 之间跳，**带宽 > 信号**。

**唯一能站住的是"这条信息改变了哪个决策"**，承重检验（C1 决策岔口可指名 / C2 删除反事实成立 / C3 在预注册结论空间内）。

**C3 是最大的自伤点**：它使"发现原先未被纳入的维度"在结构上不可能，这正是 `VD_anchor_out`（锚外新增维度数）被提出来的原因，也是 §8.2 的接口。

### 4.5 循环性与它没有被验证的部分（承重检验的读法边界）

**"有效信息维度"这个指标存在一个三步循环，必须显式写出来**（外部审稿意见的原文三条）：

1. **先定义哪些内容算承重。**
2. **再用这些内容计算有效维度。**
3. **最后根据有效维度没有增长，得出模型没有产生新的有效维度。**

这**并不意味着该指标一定错误**，但它意味着：**在做完下面三项验证之前，"有效信息维度不增"不能被读成"没有产生新维度"。**

**三项未做的最低验证（逐项登记，状态为未做）**：

| # | 最低验证 | 具体要做什么 | 为什么必须有它 | 状态 |
|:-:|---|---|---|:-:|
| 1 | **盲评** | 让人在不看分数的条件下判断"这份答案比那份多考虑了东西吗" | 检验"承重"判据与人的直觉是否同向 | **【待完成】** |
| 2 | **反事实测试** | 对同一条断言做删除 / 替换，看维度数是否按预期变化 | 检验该指标是否**对内容变化敏感**、会不会恒定 | **【待完成】** |
| 3 | **人工构造的正负对照** | ①**正对照**：人为加一个**真正改变决策**的维度，指标**应当检出**；②**负对照**：只**换一种说法**（语义不变），指标**应当保持不变** | 这两项合起来直接检验"该指标会不会系统性漏掉新维度" | **【待完成】** |

**因此本文对"有效信息维度"的读法被固定为**：该读数是**条件性证据**——它与表述层同质化的其它读数同向，但**不能单独支持「没有产生新维度」**（§6.5 判决表第 1、2 行按此标注）。
**`VD_anchor_out` 的说明全部保留**：它是回应 C3 自伤点的既有设计（锚外新增维度数，**会让我们自己失败**的一个量），但**它同样需要上面第 3 项的人工正负对照才能判定自身效度**，**本项亦属【待完成】**。
**这也是本章 H6 链的一个读法边界**（§2.5）：H6 的判决量 `P6a` 恰好建在这个尚未完成对照的判据上，**在第 3 项补齐前，H6 的判决是"未执行"，不是"未通过"**（见 **【待取证 T-L1-05】**）。

分析单元 = **题**；同题多步 rollout 不是独立样本；差值必须 vs 噪声地板，落在地板内写「**不可分辨**」；正/负结论都要写分母；n=3 翻转 1 题 = 33 个百分点（这类读数必须带量级提醒）；"无效应"与"无检出力"必须分开。

## 5 归因路由（H7）：把"过早闭合"判给正确的层

### 5.1 路由表

| 观察 | 路由到 | 下一步 |
|---|---|---|
| 边际利用率**掉零位置**强依赖预算 / 轮数 | **流程 / 架构**（层2/层3 的靶子） | 层1 在这里**不适用** |

> - **S4**：答案唯一（能否定因果）**但论证路径多样**，**5 个模态**，且 5 支**给出同一个结论**（一致率 1.00），**「面宽」与「答案一致」可以同时成立**。

**「钻牛角尖」的正确定义**（这本身是一个容易被误用的词）：**面窄（模态数 ≤2）且答案不一致**（一致率 <0.5）—— 挤在同一模态里却各说各话。**当前 9 道题里一道都没有。**

**措辞边界（这一条极重要）**：
> **2×2 对照只区分了「题的条件」，它不构成任何注意力层面的归因。**
> 它说的是"**在什么样的题上，塌缩会发生**"（描述性、条件性），**不是**"**为什么会塌缩**"（机制性）。
> **本文的归因边界（§6.5 最后一行的"本批不支持，也未被否证"）完全不受这条影响，也不因这条而放松。**
> **唯一允许的写法仍是"与注意力机制相容、判决式已定版，但本文未检验"**；任何"**把成因直接归给注意力机制**"的无条件措辞**依然不成立**。
**但这条与 §2 是接得上的**：H6（§2.5）给出的机制链正是"**清单 / 依据包把注意力吸住，有效支撑集 = 清单**"，**当"解法路径唯一"是**题的性质**时，H6 预测它在**表示侧**同样成立**，2×2 提供了 H6 的一个**可检验推论**，而不是 H6 的证据（见 **【待取证 T-L1-06】**）。

**本节的边界（照要求标出）**
- **S4、S6 是自编题**，真实材料里这类题少；句式已刻意对齐以免措辞混淆。
- **数值一致率 ≠ 正确性**，只能说「5 支算出同一个数」，**不能说「算对了」**。
- **5 处分支缺失**（S1 r1/r2 各缺 1 支、S3 r1/r2 各缺 2 支），按预注册"每组 5 支齐全，否则该组作废"，**S1 仅 1 组、S3 仅 1 组有效**；但**S1 的 3 组模态数全为 1**（含唯一有效的 r3），结论不依赖作废组。**通道失败集中在"推导长"的理科题**，这是**仪器问题，不是世界问题**。

### 6.7 一句话结论

> **「搜索空间过早闭合」在表述层是真的**（一次生成就把想法收窄，多个分支说的是同一句话）；
> **但在解码层不是**（在当前任务集与 K≤4 的实验范围内，**未观察到答案宽度的明显饱和**；更大采样规模下的增长规律**尚待验证** —— α 的两个 95%CI **均含 1**，**数据并未证明增长率低于线性增长**）。
> **闭合不是模型"想不出"，也不是"采样不出来"；是"说出来的高度同质"。**
> 因此**在本批测量下，在 Agent/架构层做分叉未检出优于直调臂的证据**（工作流臂与直调臂的 α 配对后 5/5 不可分辨）—— **这是「未分辨」，不是「不等效」**（检出力见 §6.8.1），
> **在解码层做更多采样才有希望**——但本数据集 K≤4，**尚未定位平台**。
> **而"为什么是同质的"这个问题，本批回答不了**，它被转成 §2 的**四条机制链 + 已定版判据**（不是转成"我们不知道"）。这与论文簇里已有的结论**不冲突，而是给它补上了缺失的那一半**：A 篇的 944 条断言实验测的是「架构层干预有没有用」（A 篇的结论是**在【推导唯一】的任务上，任何架构旋钮都无可测贡献**——那是**它自己**的任务结构限定，不是"架构无效"）；本文补的是「如果不改架构、只改采样，会怎样」（答案：K≤4 内确实能拓开）。

3.，**跨篇统一写法**仍是：若真实效应存在，其量级需 **≥ θ₀ 个题内 rep σ** 才能在当前 n 下被检出（**θ₀ 以题内 rep σ 为单位，不是绝对差值**）—— **但本篇尚未在 α 尺度上标定 θ₀**，**因此本篇所有"未检出"读数只支持到"本批检出力不足以排除中等以下的效应"这一层**，不支持"等效"。

**因此本篇所有"未检出"读数的合法表述只有一种**：「**在本批测量下未检出差异；本批检出力不足以排除中等以下的效应**」——**"无效""等效""已证明"三种写法在本篇一律不成立**。

### 6.9 跨厂商熵-结构（ES）实验【待完成】

**目的**：测"熵低，维度低"这个跨模型关系（ES-H4）。
**当前状态**：正式采集中。
**已知的硬约束（决定了这条轴的强度上限）**：诊断后确认**只有 mistral-nemo 的熵可测**（Δ=0.827，SNR=27.9）；kimi 熵成功率 0%、qwen 熵 SD 巨大。
**ES-H4 在本文条件下测不了**，归因**不能靠跨模型关系**，只能靠**排除法 + 单模型剂量-反应**。
**论文相应降级**：这不是"我们没做"，是"**这个假设在本条件下不可判定**"——与 §7 的注意力归因同类。

## 7 仪器边界：本批为什么测不到注意力层

> **这一章是本文的"正面化支点"**：它把"表征 / 注意力层本批不可测"从**一句遗憾**改写成**一条关于仪器的结论**，而仪器边界是可以被换掉的。

### 7.1 三条仪器原因（不是"我们没做"）

| # | 原因 | 实测证据 | 后果 |
|:-:|---|---|---|
| 1 | **托管 API 静默忽略 `logprobs`** | 实测 MiniMax-M3：请求**不报错**、`choices[0].logprobs` 字段**直接不存在** |，**不是"我们没请求"，是"请求了也没给"**，依赖似然的度量族（typicality / NLL / perplexity / PMI / CPMI）**全族作废** |
| 2 | **沙箱无 GPU** | 运行环境无 GPU，无法自托管 |，无自托管打分器，即便拿到开放权重，也跑不起可用的探针管线 |
| 3 | **全仓无任何内部探针数据** | 全仓检索**没有任何**注意力权重 / logits / hidden state / 内部激活 / 表示层探针数据——检索到的"注意力 / attention"命中**全部**出现在**模型自己写的文章正文里**（谈注意力经济的散文），不是测量数据 |，**注意力层的内部量在本批不可测** |

**这三条合起来的后果**：注意力层的**内部**量（注意力熵、注意力秩、logit 熵）在本批**不可测**，因此**内部机制文献里的似然族指标与熵族指标，在本文的实验条件下全部不可用**。

**出处**：`来源与底稿/来源_L1判决表.md:24`（第 1、3 条；第四组《测量方案裁决》）、`来源与底稿/来源_H1-H7机制假说.md:33-38`（硬边界表：attention weights / logprobs / 内部激活三行）

### 7.2 "我们测不到注意力层" ≠ "注意力不是根因"

> **这一句是本文的边界声明，也是本文的机会声明。**

| 三个推论 | 内容 |
|---|---|
| **测不到，是仪器的边界，不是世界的性质** | 换一台有内部激活访问权的机器（自托管开放权重，或能返回 logits / attention 的端点），这条边界就消失，**仪器边界是可以被换掉的** |
| **测不到，不能被读成"注意力不是根因"** | 本批**没有任何一条读数**能区分注意力层与其它层，**"未测" ≠ "未证"**；与之对称的另一半也成立：**"未测" 同样不能被读成"注意力就是根因"**（§2.1 措辞上限） |
| **测不到，不削弱 §2 的机制假说** | §2 给出的是"**判决式已经定版**"，不是"**读数已经回填**"，**后面要补的是执行判决式的读数，不是重写假说** |

**一句话**（本文最该被记住的一句边界声明）：
> **本批数据对"注意力层归因假说"这一归因既不支持、也不否证，归因判决悬置在 §2.2–§2.6 的判决式上，等探针读数回填。**
> 而**"本批不支持"与"注意力不是根因"之间的距离，正是本文交给后面那位审稿人的那一份活**（§12.1 的 T-L1-01）。

**出处**：底稿原文——"**代理量动了 ≠ 机制成立**（可能是代理失效）；**代理量没动 ≠ 机制不成立**（可能是层级不对），**可失败预测是唯一的判决依据**"（`来源与底稿/来源_H1-H7机制假说.md:39-41`）

### 7.3 边界的后果：本文提出的假说写在哪一层

| 层 | 本批能说什么 | 依据 |
|---|---|---|
| **解码层** | 「**在当前任务集与 K≤4 的实验范围内，未观察到答案宽度的明显饱和**」（两个 95%CI 均含 1，未证明次线性增长） | §6.5 第 3 行 / §6.8 |
| **架构层** | 「**在本批测量下未检出与直调臂的差异**」（**不可分辨**，≠ 不等效；检出力见 §6.8.1） | §6.5 第 4 行 / §6.8 |
| **表征 / 注意力层** | 「**本批不具备该仪器，未测**」；**不是未证** | §7.1 / §7.2 |

**因此本文的归因写法只有一种**：在解码层与架构层给出**带检出力地板的未检出**；在表征 / 注意力层给出**带三条仪器原因的未测**；**两条都不许被读成"注意力机制已被排除"，也不许被读成"注意力机制已被证明"**。
**而 §2 的四条链，正是这个"未测"格子里已经填好的那部分**：判据已定版，读数待取（§12.1）。

## 8 给 ②③④ 的设计靶点

### 8.1 塌缩的真正条件 = 解法路径唯一，设计必须作用在【路径】与【可分叉决策数】上

**本文给 ②③④ 的第一个、也是最重要的一个靶点**（§6.6）：

| 题的条件 | 模态数 | 数值一致率 | 对设计的含义 |
|---|--:|--:|---|
| **答案唯一 + 路径多样**（S4） | **5.0** | **1.00** | **面宽与答案一致可以同时成立**，**"答案对不对"不是塌缩的判据**；**"路径有几种"才是** |
| **答案唯一 + 推导唯一**（S1 / S2 / S3） | **1.0** | 0.88–1.00 |，**路径唯一，塌缩**（，但这是"都算对了"，不是钻牛角尖） |
| **多解**（T1 / T3） | **5.0** | 0.50 |，**路径多样，不塌缩** |

**两条设计律**：

1. **多样性要作用在【路径】上，不是【身份】上** —— 换型号 / 换框架只换表面身份；**加一条独立路径**才加真路径。**这条与 ② 篇的五条设计原则之一同向，其归属属 ② 篇；本文提供的是它的适用条件。**
2. **杠杆 = 支数 × 题里的可分叉决策数** —— **本文给的是这条公式的适用条件**：在**解法路径唯一**的题上，可分叉决策数，0，**支数再大也没用**（，这解释了在推导唯一题上四臂全踩坑的现象）。

**本文这一条仍是条件性描述、不是因果律**（§6.6 边界）：2×2 只区分"题的条件"；S4 为自编题；每格题数不等；题级 n=3 不报 p 值，**要升到因果，须造同一题的孪生版本（路径唯一版 vs 路径多样版）并预注册**，**【待取证 T-L1-06】**（§10 L11 / L12）。

### 8.2 与层2 / 层3 / 层4 的接口

| 对方 | 本文提供 | 对方提供 |

| **层2（设计的手段）** | 「面」的定义（有效信息维度数）；等预算对照的必要性；**塌缩的真条件 = 解法路径唯一**（，杠杆公式的适用条件） | 层2 的 4 臂对照结果：同预算下"摊开面"无优势 |
| **层3（训练/自迭代）** | 宽度轴**不需要**留出集（覆盖无赢家可选）；巡练分不可信（ρ=+0.166）；**H6，靶子是"加宽任务表示"，不是"加架构"** | 层3 的目标函数定版 |
| **层4（状态驱动）** | **不同源**，不可互证 | 层4 回答内容层，本文回答搜索空间层 |

| 归因链（§2） | 若该链成立，②③④ 应该动哪个自由度 | 为什么（本文的读数支撑） |

| **H3** 头间冗余 | **结构化的去重绑定**（不是措辞级） | **措辞级 Jaccard 恒为 0.000，没有分辨率**；结构化绑定才有 0.500 / 0.429 / 0.333，**"两条分支像不像"这件事，必须换单位** |

## 9 讨论

### 9.1 四层合起来看：到底该往哪投入

| 层 | 它告诉我们什么 | 它给出的下一步 |
|---|---|---|
| **层1（本文）** | **注意力层归因假说**（四条链 + 已定版判据，§2；**本批未检验**）；塌缩在**表述层**；解码层采样在 K≤4 内**未观察到明显饱和**（α 点估计 ≈ 0.89–0.94，**两个 95%CI 均含 1**），但**结构维度拓不开**（index 0.135）；**注意力层的读数本批不具备仪器，未测，不是未证**（§7） | 按 §2.6 的表取读数（T-L1-01 … T-L1-05）；补 K ∈ {8,16,32}；拿到内部激活访问权才谈"已识别" |
| **层2** | **「面」本身不产生优势**；优势来自「面 + 有效的取舍规则」；融合门是双输 | 落地「排序取前 k，逐支输出到预算用尽」；补质量轴 |
| **层3** | 巡练分**不可用**（ρ=+0.166）；目标函数必须**二元**；宽度轴**不需要**留出集 | 换目标 = 检索 / 核验在环，不是加搜索 |
| **层4** | 反馈通路成立（9.13×）；驱动力通路**读数冲突**；状态化选择**读数冲突**（D 篇已把它降级为**待检验的假说**『状态化选择的两难』，不是已证明的定理） | 状态必须在**生成过程内部**起作用 |

**一句话**：**四条路都指向同一个动作——把"什么算一个问题空间的一部分"这件事从"人写死的清单"里拿出来。**
层1 说清单把空间写死（H6）；层2 说摊开面不产生优势；层3 说宽度轴不需要留出集但巡练分不可用；层4 说状态写进 prompt 也不行。而**我们目前唯一测出正结果的方向是"多采样几次"**（α 点估计 ≈ 0.89–0.94，**两个 95%CI 均含 1，未证明次线性增长**；K≤4 内**未观察到明显饱和**）——**但 index=0.135 告诉我们它只拓开了条数、没拓开结构维度。**
**这是一个诚实但不舒服的结论**：我们最大的杠杆可能在**解码层**（更便宜、更简单），而它在**结构维度**上恰恰是不够的。
**而 §2 补上了这 uncomfortable 结论的另一半**：**结构维度拓不开这件事本身有机制解释**（H1 前缀自洽 / H3 头间冗余 / H4 早期锁定 / H6 清单吸住注意力），**"加采样只是半个解"这句话，从经验观察升级成了带判据的机制陈述**（§2.2–§2.5）。

### 9.2 我们与 PSFA 的差异

PSFA 在 GOMS 先验格子里填，**我们要求锚外可数**。这不是"我们更好"，而是**可证伪性**的差异：我们给了一个它没给的、**会让我们自己失败**的数。
**本文给这个差异补上机制解释**：PSFA 封闭**问题空间**，H6（§2.5）说**答案空间**会被同一机制封闭（清单在生成侧，注意力被清单吸住，锚外不可能），**两者是同一件事的两个面，不是两个不同的批评**。

### 9.3 与 Diversity Collapse 的关系

该文的贡献是**诊断**（多样性崩塌 + 权威吸引子 + 强吸引子效应），我们的贡献是把它接到**承重**判据上：*多样性*不等于*维度*，*权威*必须从判官身上剥掉。
**与 §2 的接口**：它的"权威 persona 压多样性"是**输入侧**机制，与 H6 同族；而 H3 说的是**多头侧**的同质，**两条链不同、判据不同、不可互相代替**。

### 9.4 与 AgentSquare / ToT 的关系

AgentSquare 证明**模块化设计空间**是可搜的；本文的"承重检验"在它的四模块框架里**无处安放**，既是风险也是差异化。ToT 搜解路径；本文搜"该考虑哪些维度"，且**必须**配同预算 best-of-k 对照——否则"架构有增益"可能只是"多花了钱"。

### 9.5 给实践者的一条建议

> **要判断你的 Agent 有没有被"中庸"困住，不要看它答得对不对，要看它答的**条数**有多少种**结构。**
> 因为本文实测：**多采样能给你更多条想法，但给不了更多条结构上不同的想法**（index = 0.135）。
> **加采样次数是半个解。另一半在"要不要真的按结构去重"上。**
> **而要改"按结构去重"这件事，§2 给了两条具体的路**：**结构化绑定**（措辞级 Jaccard 恒为 0.000，必须换单位）与**加宽任务表示**（清单在生成侧，锚外结构上不可能）。

## 11 结论

**一、我们提出了"过早闭合最可能源于注意力层"的机制假说，并给出了它的判决式（**本批未检验**）** —— 形式是**四条机制链**（H1 前缀自洽诱导 / H3 头间冗余 / H4 早期决策锁定 / H6 锚外结构上不可能），每条带**代理量 + 可失败预测 + 若不成立转哪一条**（§2），**可判的是"判据"，不是"读数"**。读数回填前不作存在性断言（§2.1）；**本批数据不支持也未否证该归因**（§6.5 末行）。

**二、我们给出了定位这个归因的工具** —— 三层分离协议（§3），每一轴自带可失败预测；**本批排除的是解码层与架构层；表示 / 注意力层是"未测"**。
**本文的交付形态，按外部审稿的结论句收窄**：**建立了分层检验框架，并在有限条件下排除了部分解释** —— **不是**"识别了闭合发生在哪一层"（三轴中两轴已测，第三轴本批不具备仪器；§3.1 / §1.3）。

**三、我们给了"闭合"一个可操作的定义** —— 相对于参照系的可达集比较（定义 1），换参照系 = 换层；主指标是尺度无关的宽度指数 α（§4.1），因为绝对宽度差**基本落在噪声地板内**（§4.2）。
**但定义 1 判定的是「相对覆盖不足」；「过早停止探索」是另一个构念，本文未测**（§1.3）——本文的 K≤4 边际增益为正，**不构成"提前停止"的证据**。

**四、我们执行了协议中在黑盒条件下可执行的部分，并给出混合判决。**
现象在**表述层**成立（9 条断言去重后剩 **5.2 条**，实例内余弦 **0.91–0.97**；其中"有效信息维度不增"为**条件性证据**，§4.5）；在**解码层不成立**（α = **0.886 / 0.944**，K≤4 内**未观察到明显饱和**；**两个 95%CI 均含 1，未证明次线性增长**）；
**架构层在本批测量下未检出与直调臂的差异**（Δα **5/5 CI 含 0**，与质量轴不同指标同向）—— **这是「未分辨」，不是「不等效」**：本批检出力不足以排除中等以下的效应（§6.8.1）。

**五、本批的边界是仪器边界，不是"我们没发现"。** 托管 API 静默忽略 `logprobs`、沙箱无 GPU、全仓无内部探针数据，**"我们测不到注意力层" ≠ "注意力不是根因"**（§7.2），注意力层是**未测**，不是**未证**；**要补的是读数，不是假说**。

**六、一个反直觉的限定，它可能是本文最有用的一句话。**
采样层能拓开**条数**（α 点估计 ≈ 0.9，**两个 95%CI 均含 1**），但**结构维度拓不开**（PR@32 = 4.11 vs 隔离参考 30.37，**index = 0.135**）。
**"多采样几次"是半个解。** 这既是当前唯一测出正结果的方向，也是它不够的地方。**而 §2 给出了"为什么不够"的机制解释。**

**七、本文交给 ②③④ 的靶点**：**塌缩的真正条件 = 解法路径唯一**（§6.6），**设计必须作用在【路径】与【可分叉决策数】上**（§8.1），加上 §2 的四条链给出的四个具体自由度（打断前缀 / 结构化去重 / 可回溯 / 加宽任务表示，§8.3）。

**一句自我限制**：本文**不**证明闭合的成因**已被识别**（探针读数未回填；§2 陈述的是假说与**已定版判据**），**不**证明任何单一架构能解除闭合，**不**在饱和域上观察过闭合，**不**把维度数与人类评分绑定，**不**证明任何干预"无效"或"等效"。而按本项目的既有要求——**"声称已验证 ≠ 已被验证"**——我们把上面每一条的**否证条件**写在了 §10 里，并在 §5.1.1 给出了**每条推断箭头各自的独立证伪条件**：读者可以照着否掉我们。
