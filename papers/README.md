# 叙述层（过程记录）

**本目录是过程记录，不是投稿件。** 里面的文档含未经外部同行评议的结论陈述。
可复用的部分不在这里，而在上一层 `data/`（机器可读的过程数据）。

## 里面有什么

| 类型 | 文件 | 性质 |
|---|---|---|
| **结论文档** | `01_L1_…交差稿.md`（主稿）、`01_L1_…详稿….md`（详稿）、`02_A_…`、`03_C_…`、`04_D_…`、`06_L3_…` | 过程记录。含 claim、方法、公式、读数 |
| **合订本** | `09_四篇初稿_合订本_2026-10-24.md`、`../四篇正文合订本_2026-10-25.md` | 跨篇必须一起讲的三条限定、逐篇判决、供料追踪 |
| **审稿留痕** | `复核链/` | 独立审稿的方案、逐条判定、终版收口。判定绑定被审对象的 sha |
| **改稿留痕** | `改稿报告_*.md`、`终审报告_*.md`、`包级复核报告_*.md` | 每一条改动的处置与理由 |
| **规格** | `05_B篇_缺口清单与预注册.md`、`07_待填审计_判据定版状态.md`、`08_回源对照表.md` | 判定「哪些结论现在能下」的依据表 |
| **过程标记** | `_INTEGRATE_DONE.md`、`_FINAL_REVIEW_DONE.md` | 集成完成的留痕 |
| **可粘贴段落** | `净增益双边重算_可粘贴段落_2026-10-25.md` | 复算底稿（复算链的一环） |

## 读法

1. 先读 `../README.md` 的「三条必须一起讲的限定」与「本仓的诚实边界」——那决定了每条结论能说到什么强度。
2. 再读 `../DATASETS.md`——想知道「哪些是可复用的数据」从这里进。
3. 最后才进具体某篇。

## 引用边界

- 引用**读数**：可以，指向 `../data/readings.jsonl` 或具体 `文件:行号`。
- 引用**结论**：必须同时带该篇的「诚实边界」与证据档位标注。
- 引用**审稿判定**：必须带被审对象的 sha；对象一改，判定不自动继承（见 `../PROVENANCE.md` §5）。
