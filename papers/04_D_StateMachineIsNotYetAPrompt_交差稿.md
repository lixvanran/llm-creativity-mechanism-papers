## 摘要

主流大语言模型按下一个词的概率续写，产出因此倾向于"流畅但无主"。要让 Agent 的写作像人一样**由情感或观点推动**，自然的做法是给它一个持久状态：先形成立场，再由状态组织每一步的取舍。但**如何测量"改变"是观点驱动的，而不是被 prompt 措辞或采样噪声带出来的，一直缺少一个干净的实验协议**——而且这个测量本身极容易出错。

本文把"驱动"限定到**③由情感/思想驱动的生成过程**（内容层的视角过滤：选哪些细节 / 怎么排序 / 什么被略过，来自 agent 进程内的持久状态，而不是外部指令或概率最高解），并提出**一套目的状态机的设计 + 一套可归因读数 + 一条把状态机与提示词分开的硬约束**。

**① 目的状态机的设计（本文的主体）。** 我们给出 **C1 四步管线**（`f(S₀)→约束₁` → 写初稿 `O₁` → `g(S₀,O₁)→{未落地, 约束₂, 可核事实}` → 写终稿 `O₂`）与 **C2 双层状态机**（取舍层 + **事实层** + 极性锚 + 「已排除选项」）。★ **C1 与 C0（等强度提示词臂）的真区别不是"有没有状态"，而是"状态在步骤之间转移、且转移依赖观测"**（`S₁ ≠ S₀` 且 `S₁` 依赖 `O₁` ⇒ 历史置换因此可测）。我们同时给出防伪条：**写作步的 prompt 不得含档案字段标签或状态块标记**（运行时断言），否则 C1 退化成 C0。

**② "干净"的可核验定义与封闭性审计。** 我们把"干净"定义为**可核验**的：**一个决策干净 ⇔ 它的取值空间被代码封闭**（可置换、可逐字归属、可证伪）。审计 6 个决策点：干净 3 / 不干净 3；**与驱动直接相关的 4 个决策里 3 个不封闭（驱动核心封闭率 v1 = 25%）** ⇒ ⇒ **当前实现是"一段被精心构造的提示词 + 一点代码包装"，不是状态机**。v2 把全部决策封闭率提到 **70%**，但**驱动核心三项仍为 0%** ⇒ **增量全部来自新增槽位，没有一个核心驱动决策被收回来**。

**③ 判据终局：离散结构量。** PL 极性位移**出局**（实测 SNR 0.72）；几何指标测的是"内容**在哪里**"，离散结构量测"内容**里有什么**" ⇒ 二者不是同一构念。主判据 = **D-1 CKF 可核事实守恒**（换值后痕迹同步变）/ **D-2 计划层槽位·省略·序**（必须做置换探针）/ **D-3 约束关键词命中**（双向覆盖率 `cov_archive` / `cov_text`）⇒ 全部零判官、零尺度依赖、二值可数。

**④ ★★ 主控硬约束：一切离散结构量判据必须报 C1 vs C0。** CKF「换值同步改变」**一个精心设计的提示词也能做到**（C0 里写"请务必提到 2048"，换值后同样会提到新值）⇒ ⇒ **CKF 只证明"状态被使用"；只有 C1 显著优于 C0，才证明"状态机 ≠ 提示词"**。

**⑤ ★★ 第一轮实测（Phase 1，预注册写在数据跑完之前）。** T01/T02/T04/T05/T09 × 3 样本 × 5 臂（A / C0 / C1 / C2 / S），原版 212 + 换值版 140 + 置换 43 次调用，**全 0 错误**。
- **H1 事实层因果性：部分成立** —— D-1 换值同步率 **C2 73.3%（11/15）vs C1 6.7%（1/15，精确二项 p=0.0010）vs C0 26.7%（4/15）**；McNemar **C2 vs C1 p=0.0063 显著**、**C2 vs C0 p=0.0923 未达阈值**。
- **H2 状态锚定 vs 跟随历史：成立** —— C2 − S 的 `swap_jaccard` **Δ=+0.0536**，p_raw=0.0029，**p_adj=0.0058**；C2 在 **5/5** 题上都高于 C1 与 S。
- **H3 极性编码：不成立** —— C2 与 C0 仅 **3/5** 题同号（要求 ≥4/5）⇒ ⇒ **极性须以结构/槽位而非措辞进入产出**。
- **H4 已排除抑制：方向成立未达显著**（+0.1500，p=0.2048，n=5）。
- ⇒ **判决 = 「部分成立」**（比预注册最坏情形好一档；预注册判决表见 §3.1）。

**⑥ ★★ 取舍会丢事实：目的状态机的第一个结构性代价。** ★ **C1 的 6.7%**（1/15，**显著低于随机基线 0.5，p=0.0010**）⇒ **只有取舍层时，产出完全不由档案里的具体事实决定**（★ 绝对判定，成立）⇒ 这是目的状态机的**第一个结构性代价**，同时是一条**正面设计约束**：**要事实层，就必须 C2 那种双层结构**（★ C2 vs C1 **p=0.0063** 显著）。★ ⚠️ **但"取舍层比等强度提示词丢更多事实"这条【比较性】主张，本批判不出来**（C0 vs C1 的 McNemar 精确 **p=0.2500**，★ 独立复算，详见 §4）⇒ ⇒ **降级为方向性观察 + `T-D-07`**（★ **不删条目**）。

**⑦ 两条方法论收获。** ① **锚点必须是"产出本来就会写的具体事实"**（生硬编号"病历编号 2048"正文命中仅 **33%**；换成正文必然出现的具体数字——年治疗费用 **48200** 元 / 试点周期 **270** 天 / 座位 **640** 个——命中 **58%**、同步率大幅上升）。② ★ **干净 ≠ 有力**（v2 机制更干净：必含 **9/9**、禁含 **0/7**；但 D2/D1 从 **3.5–5.1×** 降到 **2.0×** ⇒ "换相关驱动"与"换无关驱动"一样大 ⇒ **不可分辨** ⇒ 机制：产出对**候选集**更敏感 ⇒ **候选集起作用的方式更像"关键词约束"，不是"思想驱动"**）。

**⑧ ★ 工程代价。** thinking 失控：同一个转移步返回正文 **330** 字符却烧 **3129** tokens（reasoning 占 **95%**）⇒ ⇒ **关 thinking（结构化）：快 9.4×、省 95% token、截断消失**（21.6s→2.3s）⇒ ⇒ **"能用架构/机制解决就少用预制提示词"这条原则同时是 10 倍成本问题**。

**⑨ 判官与效度（诚实层）。** 位置去偏 + 一致率硬闸；判官三种失效模式（天花板 / 位置偏差 / 严格度差异）；★ **"3 胜 3 负"而位置一致率 0.00 ⇒ 判官在随机作答**；★ **多题证据依赖同源判官（本文最大的效度缺口）**。

**⑩ 下一步 v3：让取舍本身离散化。** 维度从**观测的 gaps 派生**（封闭）⇒ 模型在给定维度上表态**坚持/放弃/折中**（封闭枚举）+ 优先级 1–3 ⇒ ★ **决策权部分回代码，同时保留取舍的实质**；⚠️ **这是改状态数据结构，不是加提示词**。

## 1 引言

### 1.1 问题：答案背后有没有"核心思想链"

主流 LLM 按下一个词的概率续写，产出因此倾向于"流畅但无主"：它能写得很像样，但换一个作者、换一个立场，产出的骨架几乎不变。要让 Agent 的写作像人一样**由情感或观点推动**，自然的做法是给它一个持久状态：先形成立场，再由状态组织每一步的取舍——**写什么、怎么排序、什么被略过**。

**这篇论文要回答的问题不是"状态机有没有用"，而是三个更可复核的问题**：

| # | 问题 | 本文在哪一章回答 |
|:-:|---|---|
| **Q1** | **一个"目的状态机"应该长什么样**（什么算状态、状态怎么转移、什么算干净） | **§2**（设计章，主体） |
| **Q2** | **怎么把"思想链在推"变成可归因的读数**（而不是靠措辞相似度或判官感觉） | **§2.5 / §2.6**（判据终局 + C1 vs C0 硬约束） |
| **Q3** | **这套设计的第一轮实测**给出什么判决、代价是什么、下一步改哪里 | **§3 / §4 / §5 / §8** |

### 1.2 ★ 靶子的精确化：只研究③「由情感/思想驱动的生成过程」

我们研究的是 **③由情感/思想驱动的生成过程**——**不是**①文本里有感情词，**不是**②文本里有主张。

> **要让内容层的视角过滤（选哪些细节/怎么排序/什么被略过）来自 agent 进程内的持久状态，而不是外部指令或概率最高解。**

⚠️ ★★ **本篇的实测只覆盖【观点型】状态，情感型未进过实验 ⇒ ⇒ 本文结论不得外推到情感。**

★ 这不是本文自加的谨慎，而是**第四组自己的边界声明**（★ 第四组 v6 稿 `PAPER_draft.md` 的 ⑤ 与 §7.8 —— ★ **已归档进仓**：`来源与底稿/第四组/group4_state_driven/PAPER_draft.md`（sha256 **1c4467c7**））：「**本文 v1–v5 测的全部是【观点型】状态，情感型状态一次都没进过实验 ⇒ 我们的结论不可外推到情感**」。
★ **本文独立核验了这句**：Phase 1 的 **5 份状态档案（`p2_orig.jsonl` 的 `kind=stance` 记录）全部是立场/观点型**（字段 = 立场核心 / 拒绝 / 语气 / 强度封顶 / 锚定问题），★ **没有一份情感型状态**；★ 5 道题（T01 小说 / T02 观点短文 / T04 散文 / T05 商务邮件 / T09 决策说明）也都是**观点型任务**。
⇒ ⇒ **因此本篇的读数全部是"观点型状态"的读数**；★ **"情感与观点的统一"是第四组提出的一个待验设计命题（类型不变性），本篇既不主张它成立、也不主张它不成立**（★ 见 §10.1 `T-D-08`）。

★ **不拆开 ①②③就会退化成「情感提示词工程」**——那条路在论文簇的 A 篇与层2 侧**未检出优于直调的证据**（18 个工作流变体 13 个更差；融合门矛盾率是直调的 10.5 倍；⚠️ 该读数受 A 篇**净增益口径未完成**与**未按 4 支口径重算**两项限制，见 A 篇 §7 局限 11 / 25）——★ **不是"已被封死"**。

⇒ ★ 因此本文的全部读数都必须能回答一个**指向性**问题：**这次取舍，是状态（及其转移）决定的，还是外部指令 / 概率最高解决定的？** 这正是 §2.6 的 C1 vs C0 硬约束存在的理由。

### 1.3 ★ 诚实降级：不是"模型内部的内在状态"，是"agent 进程内的持久状态"

> ⚠️ **在无状态自回归 LLM 上，"自己承担的"与"外部指令的"机制上没有区别，只有 token 来源不同。**

⇒ ★ **本文一律使用"agent 进程内的持久状态"这一表述**，不使用"模型内部的内在状态"。这**不是文字游戏**：前者可测（它在 agent 进程里，可被代码封闭、可被置换、可被逐字归属），后者不可测（模型内部没有可被代码封闭的对象）。★ 这条降级是**精确性**，不是自我设限：它把主张收缩到一个**能被证伪**的范围内。

⇒ ★ 同样地，**机制证据只能来自取舍层**（选了什么 / 没选什么 / 放弃了什么）；所有**风格层位移**（文体签名、功能词分布、语义距离）**一律降级为诊断指标**，不得作为机制证据。

### 1.4 本文主张什么 / 边界在哪

★ **状态不是 role 标签。** 区别是可检验的：

| | role 标签 | 立场档案（本文的状态） |

1. **有来历**：一个具体事件（时间 / 地点 / 一个可追问的细节）⇒ 这是"可被追问来历"的机器实现。
2. **可追问**：强度封顶必须写明"**什么条件下会被推翻**"⇒ **保证可证伪**，防止不可证伪的绝对立场。
3. **有锚点**：锚定问题 = 这条立场能回答、而通用回答答不出的那个问题 ⇒ 让立场有可检验的着力点。

★ 8 个字段（7 固定 + 1 主控新增）：

| 字段 | 内容 | 作用 |
|---|---|---|
| 立场核心 | 一句话，可被反驳，**必须在本题做出取舍** | 状态的语义核心 |
| 来历 | 一个具体事件（时间/地点/一个可追问的细节） | 「可被追问来历」的机器实现 |
| 取舍约束 | **恰好 3 条「不能牺牲什么」** | **f 的输出形式**——注意是"不能牺牲"，不是"必须说什么" |
| 拒绝 | 这条立场拒绝什么、不接受什么结果 | 划出不可越过的边界 |
| 语气 | 克制的、什么程度的语气 | 语用层约束 |
| 强度封顶 | 在什么条件下会被推翻（须是本题真实可能发生的条件） | **保证可证伪** |
| 锚定问题 | 这条立场能回答、而通用回答答不出的那个问题 | 让立场有可检验的着力点 |

### 2.2 ★★ C1 四步管线（本文的核心公式）

```
★ C1 四步管线 —— 目的状态机的最小实现

   S₀ ──f──▶ 约束₁ ──────────────▶ 写初稿 ──▶ O₁
   │                                    （★ prompt 不含档案原文）
   │                                         │
   │  题面 ──────────────────────────────────▶│
   │                                         │
   └────────────── g(S₀, O₁) ◀────────────────┘
                    │
                    ▼
          S₁ = { 未落地, 约束₂, 可核事实 }
                    │
                    ▼
              写终稿 O₂ = Final(O₁, 约束₂)

  f : 状态 → 取舍约束（★ 叙述性自然语言，禁 schema）
  g : (状态, 观测) → 新状态（未落地 / 约束₂ / 可核事实）
  步数：C1 = C2 = S = 4 步；A = C0 = 1 步
```

★ **它回答什么问题**：它回答的是 **「C1 与 C0 的真区别是什么」**——**不是"有没有状态"，而是"状态在步骤之间转移、且转移依赖观测"**：

| 臂 | 状态怎么进生成 | 状态有没有转移 | 历史置换可测吗 |
|---|---|---|:-:|
| **C0**（档案全文一次性进 system prompt） | 全文 | ❌ 状态在上下文里，**没有转移** | ❌ |
| **C1**（本管线） | 分步 | ✔ **`S₁ ≠ S₀` 且 `S₁` 依赖 `O₁`** | ✔ |

⇒ ★ **`S₁ ≠ S₀` ∧ `S₁` 依赖 `O₁` ⇒ 状态历史置换因此可测**（这正是 D-2 的因果对照，见 §2.5）。
⇒ ★ v1 冒烟实测：约束① 与 约束② 的 Jaccard = **0.0461**、identical=False、无 fallback ⇒ **状态转移确实发生了**（约束② 从"怎么写"变成了"必须回避/披露/不得用个人经历"）（`来源与底稿/第四组/第四组交付/第四组论证.md §3.5a（sha256 e7dfeaf7）`）。

★ **三条设计约束（`来源与底稿/第四组/第四组交付/第四组论证.md §3.5a（sha256 e7dfeaf7）`）**：

1. `f` / `g` 的输出**必须是叙述性自然语言**，**禁止**评分表 / 对比表 / 编号字段 / 任何 schema。
2. C1 是 **generation 型**（展开）而不是 **refinement 型**（收敛）——`g` 步只做"指出未落地 + 给出下一轮约束"，不评分、不排序。
3. C1 必须加**体裁守恒门**与**对象守恒门**（产出必须仍以题面主体为对象），否则 C1 会把创作题降格成决策文档。

★ **成本可比性**：**S 臂必须与 C1 等调用数**（S 也必须是 4 步、同样的 `f→写→g→写`、同样的 `max_tokens`），否则 C1 vs C0 的任何差异都无法排除"只是多调了 3 次模型"这个解释。

### 2.3 ★ C2 双层状态机（事实层 = 核心思想链的载体）

★ Phase 0 的判决直接推出了 C2 的三条改法（`来源与底稿/第四组/第四组交付/第四组论证.md §3.6.5（sha256 e7dfeaf7）`）：

| # | Phase 0 发现的问题 | C2 的改法 | 防伪 |
|:-:|---|---|---|
| **1** | 取舍压缩**丢事实**（C1 覆盖率显著低于 C0） | 状态**分两层**：`S = {取舍层, 事实层}`。`f` 步分别渲染 ⇒ 写作步同时拿到**取舍约束**（决定写什么）与**可核事实**（决定写什么时用什么具体细节） | 事实必须**原样照抄** ⇒ 不能编 |
| **2** | 取舍压缩**丢极性指向**（极性 3/5 同号；C1 ≈ R1） | `f` 步输出**必须携带极性锚**（"这一轮站在哪一端、因此必须这样取舍"） | 极性锚进写作步 ⇒ 极性不再只是"语气"；★ 禁止写 `pole_a`/`pole_b` |
| **3** | C1 与 R1 在"锚定强度"上无差别 ⇒ 状态机没有独有优势 | 必须造出**只有状态机做得到、档案全文做不到**的动作 ⇒ 新增**「已排除选项」**（`g` 步输出"这一轮不能再走的路"，终稿步注入） | ★ **C0 结构上无法表达**——C0 是一次性注入，没有"已排除"这个概念 |

⇒ ★ **事实层是"核心思想链"的载体**：取舍层决定**写什么 / 不写什么**，事实层决定**用什么具体细节**；★ **只有事实层能被 D-1 逐字归属**（§2.5），因此事实层同时也是**可归因读数的载体**。

⇒ ★ 由此新增判据 **C2-SUP**（已排除选项的抑制）：`hit(O₁, kw_excluded) − hit(O₂, kw_excluded)` 应为正 ⇒ 这是 **C2 独有、C0 无法通过"更聪明的提示词"伪造**的判据（`来源与底稿/第四组/第四组交付/第四组论证.md §3.7（sha256 e7dfeaf7）`）。

### 2.4 ★★ "干净"的可核验定义 + 封闭性审计

★ **"干净"必须可核验，否则它只是形容词。** 我们的定义是：

> **一个决策干净 ⇔ 它的取值空间被代码封闭**（可枚举 ⇒ 可置换、可逐字归属、可证伪）。
> ⇒ 不干净 ⇒ 代码只做承载与校验，**决策权仍在模型手里**。

★ **v1 审计（6 个决策点，干净 3 / 不干净 3）**（`来源与底稿/第四组/group4_state_driven/archive/top_level/DRIVER_AUDIT.md §1.1（sha256 23533069）`）：

| 决策点 | 决策者 | 封闭 | 代码位置 / 为什么 |
|---|---|---|---|
| 驱动内容（这一轮要守住的取舍） | **模型** | ✘ 开放 | `run_arch_compare.py:step_stance` — 取值是模型自由生成的 3 条自然语言，代码只截断到 3 条 |
| 观测（初稿哪些地方没展开） | **模型** | ✘ 开放 | `run_arch_compare.py:step_observe` — gaps 是模型自由生成的描述 |
| 新约束（这一轮具体写什么） | **模型** | ✘ 开放 | `workflow_arch.py:transfer ③` — 代码只校验 `gap_index` 指对没有，**不限定约束内容本身** |
| 已排除（哪些路已经走过） | **代码** | ✔ 封闭 | `workflow_arch.py:build_excluded` — 取值 ⊆ 观测里出现过的引号内容 |
| 绑定（约束↔缺口） | **代码** | ✔ 封闭 | `workflow_arch.py:resolve_binding` — `gap_index` 结构声明，零阈值 |
| 补齐（不足 3 条时沿用上一轮） | **代码** | ✔ 封闭 | `workflow_arch.py:transfer 补齐` — 确定性规则，`filler_from_prev` 显式标注 |

⇒ ★ **干净 3 个 / 不干净 3 个；与驱动直接相关的 4 个决策里 3 个不封闭 ⇒ 驱动核心封闭率 v1 = 25%**。
⇒ ★ **不干净的那三个，恰好就是"驱动"最核心的三个。**

⇒ ★★ **因此我们给出一句必须写进论文的定性判断**（`来源与底稿/第四组/group4_state_driven/archive/top_level/DRIVER_AUDIT.md §0（sha256 23533069）`）：

> **当前实现是"一段被精心构造的提示词 + 一点代码包装"，不是状态机。**
> 它有效，是因为驱动内容真的进了 prompt 并影响了产出；它不干净，是因为**驱动决策的取值空间仍然由模型自由决定**，代码只做承载与校验。

⇒ ★ **v2 之后（`来源与底稿/第四组/group4_state_driven/archive/top_level/REPORT_arch2.md §4.1（sha256 775c4f8f）`）**：

| | v1（6 个决策） | v2（10 个决策） |
|---|---|---|
| 全部决策封闭率 | 50% | **70%** |
| **驱动核心 3 项**（取舍 / 观测 / 新约束） | **0%** | **0%** |

⇒ ⚠️ **诚实**：封闭率从 50% → 70%，**但全部增量来自"新增槽位"**（离散实体、必含实体、禁含措辞、输出语言与长度），**没有一个核心驱动决策被收回来**。

⇒ ★ **这一节的方法论意义**：★ **封闭率是"我们离真正的状态机还有多远"的刻度，而不是"我们的机制有没有效"的刻度** ⇒ 两者必须分开报（这是 §5.2「干净 ≠ 有力」的前提）。

### 2.5 ★ 判据终局：离散结构量

★ **为什么不是几何指标**：几何指标测的是"内容**在哪里**"，离散结构量测"内容**里有什么**" ⇒ 二者**不是同一构念**。三条独立证据：

| 证据 | 数字 | 出处 |
|---|---|---|
| **PL 极性位移出局** | 地板 **0.2930** 与信号 **0.2118** 同量级 ⇒ **SNR = 0.72 < 1** | `来源与底稿/第四组/第四组交付/第四组论证.md §3.4c（sha256 e7dfeaf7）` |
| **embedding 绝对距离跨批不可用** | 同题同臂的 SC 跨两次运行 **0.2930 vs 0.0758**（差 **3.9 倍**）；跨题差约一个数量级 | `来源与底稿/第四组/第四组交付/第四组论证.md §3.4d（sha256 e7dfeaf7）` |
| **臂间几何距离与"组织取舍"错配** | 句级集合距离：**臂内 0.3896** vs **臂间 0.3569** ⇒ **臂间距离比臂内距离还小** | `来源与底稿/第四组/第四组交付/第四组论证.md §3.4e（sha256 e7dfeaf7）` |

⇒ ★ **主判据（`来源与底稿/第四组/第四组交付/第四组论证.md §3.4-2（sha256 e7dfeaf7） / §3.4-3`）**：

```
★ 离散结构量 D-1 / D-2 / D-3 —— "思想链在推"的可归因读数

  D-1  CKF 可核事实守恒
       档案里放一个可核数字/专名 → 正文是否留下痕迹 → 追问是否一致
       → ★ 换值后痕迹是否同步变
       实现修正：锚点检测键 = 从锚点串抽出的数字/字母数字串（★ 不是整句）
       同步率 = 换值后正文出现新值 ∧ 不含旧值 ∧ 原版不含新值

  D-2  计划层结构（★ 必须做置换探针）
       状态历史置换：同一 S₀、同一题，只把 g 步看到的初稿换成另一份初稿，
       重跑 g 步，看约束②是否改变
       ★ 方向：swap_jaccard 越大 = 换了初稿后约束越不变 = 越锚定状态而非历史

  D-3  约束关键词命中（★ 双向覆盖率）
       cov_archive = 档案有多少进了正文（★ 对长度不敏感，主读数）
       cov_text    = 正文有多少来自档案（长度敏感，辅读数）
```

★ **为什么用离散结构量**：全部**零判官、零尺度依赖、二值可数**；且 §3.4-3 的实现修正给出了三处**定义级**的必要性（锚点用整句 ⇒ 命中率恒为 0；D-2 写成"约束① vs 约束② 的 jaccard" ⇒ **两个本来就是不同步骤的输出，jaccard 低是平凡的**；D-3 不分双向 ⇒ **臂间差异可能全是长度效应**——v1 冒烟实测 len 与 `cov_text` 的 Pearson r = **−0.82**、与关键词命中率 r = **−0.99**）。

★ **判据自检必须先过**（三组铁律"检查器必须先证明自己能抓到东西"）：`metrics2.py` 每个判据配阳性 / 阴性用例，**自检 9/9 全通过** 才允许跑数据（含一条"拒绝项不得误命中"的干扰项设计与一条变异注入）。

### 2.6 ★★ 主控硬约束：一切离散结构量判据必须报 C1 vs C0

> ★ **这是本文最容易被绕过、也最不能绕过的一条。**

**CKF（可核事实守恒）单独用不成立。** 它的机制是"档案里放一个可核数字/专名 → 追问 → 正文痕迹 → 换值后痕迹必须同步变"。看着很强，但——

> **一个精心设计的提示词也能做到。** C0 臂（档案塞进 system prompt）里若写着"请务必提到 2048"，换值后模型同样会提到新值。
> ⇒ **CKF 只证明「状态被使用」，不证明「状态机 ≠ 提示词」。**

⇒ ★ **因此：每一个离散结构量判据，都必须报 C1 vs C0 的差值；只有 C1 显著优于 C0，才支持"状态机"主张。**
⇒ ★ **反过来说**：若 C1 ≈ C0，**当前形态就死了**——不是"状态无效"，而是"**一个等强度的提示词就能复现全部效应**"。
⇒ ★★ **本批的实测状态（★ 2026-10-25 独立复算后登记，★ 详见 §4.3）**：★ **在 D-1 这条判据上，"C1 ≈ C0"已成立**（McNemar 精确 **p=0.2500**）⇒ ⇒ **该判死门在 D-1 上被触发**；★ **但 C2 vs C0 p=0.0923 未达阈值** ⇒ ★ **"双层结构"形态尚未被该门判死**（★ n=5 题功效不足 ⇒ 依 F18 写"检出力不足"，★ **不写"已排除"**）。

⇒ ★ **配套的臂设计**（`来源与底稿/第四组/第四组交付/第四组论证.md §3.5（sha256 e7dfeaf7）`）：`A`（基线）｜ `S`（等强度中性简报，token 与 C0 等长）｜ `C0`（档案全文一次性注入 = 等强度提示词对照）｜ `C1`（状态机）｜ `C2`（双层状态机）｜ `O`（只做计划不带状态，反例层）｜ `R0`/`R1`（无关立场 / 同题反极性，H0 武器）｜ `C-echo`（同一档案改当"必覆盖素材"，区分"组织取舍"与"复述档案"）。

★ **成功标准（零判官版，`来源与底稿/第四组/第四组交付/第四组论证.md §3.4-2（sha256 e7dfeaf7）`）**：

> **成功 ⇔** ① C1 相对 **A / S / B / C0 / O / R0 / R1** 全部显著（**Holm 校正**，α′ 按实际对比数算）；② **计划层 / 文本层 / 分布层三层同向**（若校准显示分布层无分辨率 ⇒ 降为两层，**并如实写明**）；③ 方向**可由状态内容预测**；④ 在**极性翻转 / 事实换值 / 历史置换**三类反事实下，**按预测方向同步变化**；⑤ **ST 风格臂不产生同向证据**（反例层）。
> **「人类觉得更有思想」不作为成功标准的任何部分。**

⇒ ★ **为什么这样写不算降级**：机制性命题的真值条件是关于**原因与结构**的，用"是否更有思想"当判据是**换构念**，不是降级。★ **但无判官方案的真风险是「量到了自己管线的账本」** ⇒ 必须有**从中间态到文本的传导链**（CKF 痕迹 + 锚定命中），且必须有**反例层**（O / ST），否则成功标准不可证伪。

### 2.7 防伪：状态泄漏断言 / 极性符号对齐 / 干扰项

★ **三个防伪装置**（`来源与底稿/第四组/第四组交付/第四组论证.md §3.5a（sha256 e7dfeaf7） / §3.3 / §3.4-3`）：

| # | 装置 | 作用 | 失效后果 |

## 3 第一轮实测（Phase 1，预注册写在数据跑完之前）

### 3.1 预注册与总判决规则

★ **预注册写在数据跑完之前**：写下时 `runs/p2_orig.jsonl` 还在 79/220 行、`runs/p2_swap.jsonl` 未开始；之后只允许**追加**（修订留痕），不允许改写已写定的阈值。★ **期间只改过并发（8→4）与 429 退避，未动任何阈值**（`来源与底稿/第四组/第四组交付/experiment-design/PREREG_p1.md §6（sha256 08fe9e29）`）。

★ **四个假设与支持条件**（写定）：

| 假设 | 预注册的支持条件 | 统计方法 |
|---|---|---|
| **H1** 事实层的因果性 | C2 同步率 **> 50%** 且 McNemar **p<0.05**（Holm 校正后仍 <0.05）；且 C1 同步率 **< 25%** | 对基线 0.5 用**精确二项**（n=15 配对/臂）；臂间用 **McNemar 配对检验** |
| **H2** 状态锚定 vs 跟随历史 | Δ(C2 − S) > 0 且 Holm 校正后 **p<0.05** | 题内均值 → 跨题配对 t，n=5 题 |
| **H3** 极性编码 | C2 与 C0 同号 **≥ 4/5** 题 | 符号一致性（二项，基线 0.5） |
| **H4** 已排除选项的抑制 | `excl_suppressed` 均值 > 0 且 p<0.05 | 题内配对 t（C2 自身 O₁ vs O₂），n=5 题 |

★ **总判决规则（预先写定）**：

| 条件 | 判决 |
|---|---|
| H1 ∧ H2 ∧ H3 ∧ H4 | **成立**：状态机在机制层面与提示词**可区分**，且优于等强度提示词对照 |
| **H1 ∧ H4**（H2/H3 不成立） | **部分成立**：事实层与可选项抑制有效（机制层），但**极性编码**与**锚定强度**未获支持 |
| H1 ∧ ¬H4 | **仅事实层有效**：C2 只是"把事实也带进去了"，**没有**状态机独有的优势 |
| ¬H1 | **失败** |

★ **统计纪律（写定）**：① **分析单元 = 题**，样本 = 题内重复测量；**绝不能**把「同 prompt 跑两次」当配对。② 题内先算臂均值，再跨题做**配对**比较。③ **Holm** 校正，α′ 按**实际对比数**算。④ **F18**：≥60% 的题上被测臂落在对照臂 `min−s ~ max+s` 包络内 ⇒ 写「**不可分辨**」，**不得**写「无效应」。⑤ **D-1 同步率**是配对二值指标 ⇒ 用 McNemar / 精确二项，**不做**独立样本比较。⑥ **长度必须报告**。⑦ **批次**：跨批只做 D-1（配对字符串判定）；主对比只在单批内做。

#### 3.9.7 ★ 三条结论

1. **状态塑造候选是有效的。** H1（候选符合状态率）从 blind 的 **0.0741** 升到给缺口的 **0.6667**，**9 倍**。⇒ 状态确实能把候选推向某个方向，**v3 失败不是因为"状态没用"**。⚠️ **限定**：该 9 倍跨越"给缺口"臂，而该臂 align(state选) **0.9444** 有**恒真风险**（§3.9.8）⇒ 它只支持"**状态能改变候选**"，**不**支持"状态化打分能读出状态"。
2. **状态化打分未检出优于通用打分的证据。** 干净臂（blind）里，状态化打分与通用打分 **9/9 完全打平**，align 均为 **0.3148**。⇒ 不是"方向不对"，是**零区分（未检出）**；⚠️ **本批未预注册 MES、且该读数的 D0 重选地板未测 ⇒ 不能声称"已排除"中小效应**（§3.9.2）。
3. ⇒ **瓶颈定位在"选择器读不出状态"，不在"状态进不了产出"。**（**在本批配置下**的定位；跨模型 / 跨题未测，§3.9.9。）

#### 3.9.10 为什么选择器读不出状态：一个可操作的诊断

状态化打分建立在"**事后猜**候选有没有写到那些实体"上。而模型**没有把状态以可抽取的形式留在产出里**：
- 取舍声明率只有 22% / 11%（`A` 臂 0%）；
- 候选即使声明了取舍，**回避的对象也常常不是状态指定的那些实体**（`R_takeoff-orig` 恒 0 就是这个现象的直接证据）。

⇒ ⇒ **要让状态化打分有意义，候选必须在可观测层面显式表达状态**（例如"我这一轮只写 A，B 就不展开了"），使打分建立在**结构化绑定**上，而不是事后猜实体命中。
⚠️ 这与 v3 已确立的结论一致：**绑定必须结构化**。

⇒ ★★ **设计约束一：事实层必须单列。** 要让可核事实进入产出，**不能**指望它从取舍约束里"漏"出来 ⇒ 必须给状态**第二层**（§2.3）。★ **支撑它的是 ① 与 ③，不是 ②**：①（**6.7%** vs 随机基线，**p=0.0010**）说明"单层状态下档案事实根本进不了产出"；③（**73.3%** vs **6.7%**，**p=0.0063**）说明"加上事实层它就回来了"。

⇒ ★ **设计约束二：取舍与事实不能共用同一个载体。** 取舍层的载体是"不能牺牲什么"（叙述性、抽象）；事实层的载体是"原样照抄的具体事实"（可逐字归属）。★ **把两者混在一层里，就是 C1 丢掉事实的机制**（★ ① 的读数支持这条**机制解释**；★ **② 不可分辨 ⇒ 不得据此说"比提示词丢得更多"**）。

⇒ ★ **设计约束三：任何"以状态驱动产出"的主张，都必须先过 D-1。** 因为 D-1 是唯一能把"状态被使用"与"状态机 ≠ 提示词"分开的读数（§2.6），而 C1 的 **6.7%** 提醒我们：**没有事实层的状态机，连"被使用"都做不到**（★ 这是 ①，★ 不依赖任何臂间比较）。

⇒ ★ **因此本文把 §4 写成一条正面设计约束，而不是一个负面结果**：★ **目的状态机的第一个结构性代价是"取舍会丢事实"，代价的解法是"双层结构"**；★ **解的有效性已被 ③ 支持**（C2 vs C1 **p=0.0063**）⇒ ⇒ **仍未验证的是"双层结构是否优于等强度提示词"**（C2 vs C0 **p=0.0923**，★ 另见 §4.3 的判死门状态）⇒ ⇒ **以及"取舍层是否比提示词臂丢得更多"**（② **p=0.2500**，★ `T-D-07`）。

### 4.3 ★ 判死门在 D-1 上的状态（★ 诚实登记，★ 不当作失败结论）

## 7 判官与效度（诚实层）

> ★ **本章不削弱本文的主张，它划定的是主张的适用范围。** 本文的主读数已全部改为**零判官**（离散结构量），本章处理的是**判官读数**这条历史支线。

### 7.1 ★ 两条读数轴：可核验性 × 分辨力

我们在 v2 得到的经验是"**干净 ≠ 有力**"（§5.2）。v3 的结果迫使我们把这个说法改得更精确：

> **不是"干净"与"有力"互斥，而是"可核验性"与"分辨力"由不同读数承担，同一个读数不能同时承担两者。**

- **代码强制通道**（必含/禁含）：可核验性满分——必含命中 **9/9**，禁含随观测换源 **8/8**，代码封闭率 **70%**、驱动相关槽位 **4/4** 封闭。**但它对驱动力零分辨力**，因为"状态变了 ⇒ 产出变了"是代码的必然结果。
- **几何读数**（实词 2/3-gram Jaccard）：零判官、可复现、成本低。**但它在本任务的臂间区分度为 0**：全部 **15** 个臂对落在 **0.053–0.077** 的窄带，而纯重跑地板是 **0.0720** ⇒ 地板高于信号。
- **内容性判官读数**（两两比较）：有分辨力（6 票一致 0–6），但引入判官失效风险（饱和、位置偏差、严格度差异）⇒ 必须配自检与硬闸。

⇒ **实践含义**：研究"状态是否驱动了产出"时，**几何相似度应当被排除为主读数**——不是因为它"不严谨"，而是因为在产出长度与体裁相近的创作任务上，它测的是"内容在哪里"而非"内容里有什么"。

### 7.2 ★ 冲突的正确读法（几何 vs 判官）

外部评审对本篇的核心意见是：§3.8 / §7.3 / §7.4 的三项结果（几何窄带 / 判官反向分离 / 跨厂商判官方向一致）**并不能直接推出**"状态化选择要么无效、要么恒真"；**它们首先表明：现有测量方法对"状态是否驱动产出"这一构念尚未形成一致、可靠的判定。** 本节把这条读法写成本文的纪律。

**三个读数各测什么（它们不是同一构念的三个读数）**：

| 读数 | 测的是 | 在本文中的位置 |
|---|---|---|
| **代码强制通道**（必含 / 禁含） | "状态变了 ⇒ 产出变了" | **必然成立**（代码的必然结果）⇒ **不能**作驱动力证据（§7.7） |
| **几何读数**（实词 2/3-gram Jaccard） | **内容在哪里**（用了哪些词） | 零判官、可复现；本任务上与地板重叠 ⇒ 无分辨力 |
| **内容性判官读数**（两两比较） | **内容里有什么**（是否由观点组织） | 有分辨力，但引入判官失效风险（§7.5） |

**★ 当两个读数方向相反时，正确读法是三条"不"**：

1. ❌ **不能取平均**（几何与判官的量纲与被测量都不同，平均没有意义）；
2. ❌ **不能取更强的一方**（"判官有分辨力所以判官对"是循环的——判官的失效模式正是本文要处理的对象，§7.5）；
3. ✅ **只能得出**：**"该构念尚未被这两个测量方法一致地测到"**——既不是"有差异"，也不是"无差异"。

⇒ ★ 这与本项目的"**不可分辨**"纪律**同族**：不可分辨不是"没有差异"的另一种说法，而是"**当前测量不足以把差异与噪声分开**"；当两个读数**方向相反**时，结论同样只能停在"**未对齐**"，不能停在"某一方赢"。

### 7.3 ★ 零判官几何读数（多题）：单题结论不可外推

⚠️ 在 **G01 单题**上，**15** 个臂对的实词 Jaccard 全部落在 **0.053–0.077** 的窄带（地板 **0.0720**）⇒ 无分辨力。
但**多题后几何读数出现了分层**（部分）：

### 7.6 ★ 判官读数的三个失效模式（可复用的流程建议）

我们在实现中踩到并量化了三种失效，每一种都会**系统性地**把"有差异"读成"无差异"：

| 失效 | 现象 | 处置 |
|---|---|---|
| **天花板效应** | 判官 4.20 在 D1 上把 18 篇全打 3.000 ⇒ 绝对分零分辨力 | 改用两两比较；或换更严的判官 |
| **位置偏差** | 多对对比胜负"3胜3负"（像无差异），但**位置一致率 0.00** ⇒ 判官在随机作答 | **交换位置各跑一次**，一致率作硬闸 |
| **严格度差异** | 4.20 偏松（方差 0.49）、4.3 偏严（1.86）⇒ 绝对分不可跨判官比 | 只用**题内相对排序** |

⇒ ★ **实测实例**：多对对比的胜负为"**3 胜 3 负**"（看似无差异），而其**位置一致率为 0.00** —— 真相是**判官在随机作答**，与两篇文本的优劣无关。
⇒ ★ 我们主张这套流程（**自检 → 位置去偏 → 一致率硬闸 → 题内配对 → 相对排序**）应成为"LLM 状态是否驱动产出"这类研究的**标准前置条件**：★ **目前大量工作只报告胜率、不报位置一致率，因而无法区分"两者真的差不多"与"判官在掷硬币"**。

### 7.7 ★ 不循环读数（本文的核心方法论贡献）

**问题**：当状态经由**代码强制**生效时，"状态变了 ⇒ 产出变了"是**恒真命题**。

**我们给出唯一不循环的读数设计**：

> **决策只以自然语言进入生成流程**（不写必含/禁含实体），此时产出的变化才是**模型的选择**。
> ⇒ 通用检查题：**"这个读数能不能是恒真的？"** 答案若是"能" ⇒ 停。

★ **本文的一次正式实验正是靠这条纪律拦下来的**：

> v4 第一版候选提示**告知候选"缺口涉及的具体词"** ⇒ 候选"照做就能命中" ⇒ 状态化打分的 align 接近恒真 ⇒ **H3 失去意义**。
> 该实验在启动约 **5 分钟**后被主动终止（不是跑完再看）；已落盘的 **7 条不进入任何结论**，被新一轮整批覆盖。
> ⇒ 修订后加 **`WF-v4-blind` 臂**：状态照常构建（观测 + 决策），但**候选提示里不含任何缺口内容/实体**，只给"有 N 个还没想清楚的地方，具体是什么由你自己判断"。
> ⇒ 该臂里，状态化打分**唯一的信息来源是事后从正文抽行为** ⇒ **彻底非恒真**。
> （自检 **25/25**，含一条防回归：`blind` 提示里不得出现任何状态实体/缺口文字。）

⇒ ★ **在本文的框架里，这条纪律与 §2.6 是同一条原理的两个面**：§7.7 管的是"**状态以强制方式生效 ⇒ 读数恒真**"；§2.6 管的是"**状态以非强制方式生效 ⇒ 读数只证明被使用，不证明状态机 ≠ 提示词**"。⇒ ★ **两者合起来才是完整的防伪要求**。

### 7.9 同源判官：能用，但只能当交叉验证的一端

额度耗尽迫使我们用 MiniMax 自己的端点当判官，而被测生成器正是 MiniMax-M3。这在原则上**违反**本文的判据纪律（同源判据无效）。我们的处理是把它降级为**交叉验证的一端**，并加上一条可复用的经验：

> **同源判官在"相对比较"上的可用性，取决于能否用跨厂商判官做锚点。**
> 若同源判官与跨厂商判官在同一批数据上**方向一致**（本文：三个判官在**最强对比（A vs WF-a3）的 D1 与 D3 两行**给出完全相同的数字；⚠️ **D2 行不一致，其余对比行跨厂商位置一致率 0.556–0.667**），则该方向**不是**单一判官家族的偏好；
> 若无法做这个锚点（跨厂商不可得），则同源判官的结果**只能**作为**待验证的观察**报告，**不得**进入主结论。

⇒ 推论出一条对资源受限研究者的实用建议：**优先把跨厂商额度花在"锚点对比"上**（少量题、少量对比、双判官），而不是把它平摊到全部实验上。本文的额度分配恰好做反了（先把额度花在 G01 的全维度上，多题反而只能靠同源判官），这是流程上的一个教训。

⚠️ 同时提醒：**同源判官与同源生成器共享的不只是"偏好"，还有风格**。若被测臂之间的产出风格差异本身就是判据的一部分，同源判官可能因此偏好某一臂 ⇒ 方向一致**不足以**排除偏差。这正是 §9 把人类盲评列为必做项的原因。

### 7.10 对相邻结论的独立验证与指引

我们的结果从**推理时架构**一侧指出：仅把"立场 / 取舍"写进 prompt（哪怕配上封闭枚举、代码强制、结构化中间态），**不足以**让产出被观点驱动。这与 📄 **Nagarajan et al.（ICML 2025 oral）** 从**训练侧**得到的结论方向一致：要让模型先想再写，必须改**训练目标**（teacherless / diffusion）并把**随机性从输出端挪到输入端**（seed-conditioning）。

⇒ 我们的结果因此不是"状态机无用"的终局判断，而是一个**定位**：它把"驱动"的责任从推理时架构，指回了训练与采样。
⇒ 同时它给出一个**廉价的前置检查**：在投入训练侧改造之前，先用**判官两两比较**测一轮推理时架构的上限——若连"有状态 vs 等预算自我说明"都测不出分离，那么训练侧改造就是必需的，而不是可选的。

⇒ ★ **本文与该定位的关系（新增的一句对齐）**：★ **本文不把"驱动的责任在训练侧"当结论当结论**——本文只主张**在推理时架构这一层，状态机必须先把"事实层"与"取舍层"分开（C1 6.7% vs C2 73.3%），且必须先能区分"状态机"与"等强度提示词"（C1 vs C0）**；★ **训练侧是否必要，是 §8 之后的下一层问题，本批数据不足以回答**。

## 8 下一步：v3 —— 让取舍本身离散化

### 8.1 ★ v3 的第一条依据：取舍对象必须取自初稿里没有的东西

即使把读数做对，v3 的**几何读数**仍给出零信号。追查设计后，我们定位到一个结构性原因：

> 代码规定"缺口相关实体 ⊆ 初稿"（逐字校验）⇒ **要写的内容本来就在稿子里**。

于是"写它 / 不写它"**不是取舍**，只是"保留还是删掉已有内容"；而模型做**改写**时天然倾向保留原有内容 ⇒ **取舍信号被改写惯性淹没**。

⇒ ★ **对下一版设计的硬要求**：取舍的对象必须取自**初稿里没有的东西**（新的证据类型、新的立场维度、新的类比），或让取舍作用于**结构位置**（写哪一段、占多少篇幅、论证顺序），而不是"某个词出不出现"。
⚠️ 这条与 §7.1 的结论是独立的：即使读数完美，当前 v3 的取舍设计也表达不了取舍。
⇒ ★ **与 §4 的对接**：★ **C1 的 6.7%（对随机基线，p=0.0010）与本节的"取舍对象 ⊆ 初稿"是同一件事的两个面** —— 前者说"**取舍层让档案事实进不了产出**"，后者说"**取舍层其实只在初稿内部做保留/删除**" ⇒ ⇒ **v3 要同时解决两件事：把取舍的对象换成初稿外的东西（§8.1），并把取舍的表达离散化（§8.2）**。
⚠️ ★ **读法边界**：★ 前一句是**绝对判定**（对随机基线）；★ **它不构成"取舍层比等强度提示词丢更多事实"**（★ C0 vs C1 **p=0.2500**，★ 不可分辨，★ 见 §4.1 与 `T-D-07`）。

## 9 局限与威胁有效性

**统计效力**：分析单元是**题**。本文主读数来自 **3 题**（G01 / T07 / T10；T06 因生成端超时退出）× 3 次重复 × 2 位置。n = 3 题属小样本，**只作方向性判断，不报显著性**（v4 的 Fisher p = 0.47 / 1.0）。
⚠️ T10 上 D1 的 A vs WF-a3 是 3胜3负（唯一例外）⇒ **方向并非在每题每维都一致**。
⚠️ ★ **Phase 1 的 n = 5 题**（T01/T02/T04/T05/T09）⇒ 配对 t 在 Cohen d=1.0 时功效约 **0.62** ⇒ **本轮只对大效应有检出力**；不显著**不能**写成"无效应"。

**★ 最大的效度缺口：多题判官是同源的。** 跨厂商判官（grok）因 OpenRouter key 额度耗尽（`403 Key limit exceeded (total limit)`）只覆盖 G01；多题由同源判官 `MiniMax-M3` 承担。
⇒ 同源判官与被测生成器共享偏好，**不能被当作独立证据**。
⇒ 缓解措施只有一条：G01 上的**双判官交叉验证**（§7.5）显示三个判官方向一致 ⇒ 但这**不能替代**多题上的跨厂商判官。**这是本文最需要补做的一项。**

**单模型**：被测只有 MiniMax-M3。`temperature=0` 在该模型上仍非确定性 ⇒ 一切结论依赖题内重复与题内配对，不依赖逐字重放。

**零判官与判官的双重约束**：几何读数无判官但分辨力随题而变（G01 无分辨力、T10 有）；判官读数有分辨力但可能失效。本文用三条地板 + 位置去偏 + 一致率硬闸来约束，但仍不能排除"判官与我们的偏好同源"（我们与判官都是语言模型，可能共享同一种"什么算有观点"的直觉）⇒ **本工作不能替代人类盲评**。

**题面与题材**：三道题均为中文、单一作者视角、给定体裁（观点文 / 科普小品 / 求职自述）；结论不外推到英文、多轮对话或高度专业题材。

**构念效度**：D1–D3 是**代理指标**，不是"思想驱动"的直接测量。D3 试图逼近"概率检索 vs 人写"的区别，但由语言模型判定，可能与 📄 **Sui et al. 2026** 报告的**不确定性差距**高度相关也可能无关；我们**未**做该计算（该文需要模型似然，而当前 API 不返回 `logprobs`、OpenRouter 亦返回 `logprobs=None`、沙箱无自托管能力）⇒ 列为后续工作。

**v4 的读数脆弱性**：`align` 依赖"实体"抽取，而实体词表来自 gap 抽取，存在措辞敏感性；§3.9.5 的恒 0 读数已暴露这类脆弱性。

## 11 结论

我们从"让 Agent 的输出由观点/情感推动，而不是仅由下一个词的概率决定"这一问题出发，做了四件事。

**第一，提出了一套目的状态机的设计，并给它配了一把可核验的尺子。** C1 四步管线把"状态"从一段提示词变成一个**在步骤之间转移、且转移依赖观测**的对象（`S₁ ≠ S₀` 且 `S₁` 依赖 `O₁` ⇒ 历史置换可测）；C2 双层结构把**事实层**单列出来，作为核心思想链的载体；"干净"被定义为**该决策的取值空间被代码封闭**（可置换、可逐字归属、可证伪）⇒ 审计结果是**驱动核心封闭率 v1 = 25%**、v2 全部决策 **70%** 而**驱动核心仍 0%** ⇒ ⇒ **当前实现是"一段被精心构造的提示词 + 一点代码包装"，不是状态机**——而这条判断本身就是把"离目标还有多远"变成可核读数的产物。

**第二，把"思想链在推"变成了一套可归因的读数。** 几何指标测的是"内容**在哪里**"，离散结构量测"内容**里有什么**" ⇒ 二者不是同一构念；PL 极性位移**出局**（SNR **0.72**）；主判据取 **D-1 CKF 可核事实守恒 / D-2 计划层槽位·省略·序 / D-3 双向覆盖率** ⇒ 全部零判官、零尺度依赖、二值可数。

**第三，指出了被忽视的方法论陷阱并给出修正。** CKF「换值同步改变」**一个精心设计的提示词也能做到** ⇒ ⇒ **CKF 只证明"状态被使用"；只有 C1 显著优于 C0，才证明"状态机 ≠ 提示词"** ⇒ ⇒ 本文把这条写成**主控硬约束**：一切离散结构量判据必须报 C1 vs C0。另一方面，当状态经由**代码强制**生效时，"状态变了 ⇒ 产出变了"是**恒真命题** ⇒ 我们给出唯一不循环的读数设计，并把它写成一条可迁移的检查题：**"这个读数能不能是恒真的？"** ★ **这条纪律真的拦下了一次事故**：v4 第一版因候选提示告知打分依据而接近恒真，实验在开跑 **5 分钟**后被主动终止并整批作废重跑。
