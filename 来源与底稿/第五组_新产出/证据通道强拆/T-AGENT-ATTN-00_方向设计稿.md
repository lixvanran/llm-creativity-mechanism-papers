## 0. 一句话命题

> **在 Agent 层把「注意力预算」从单一默认证据通道，拆成 N 路互不可见的证据通道；用【构造保证】（上下文隔离）而不是【提示词请求】来实现拆解。**
> **检验它能否把候选集里【缺席的可行维度】拉回来，并且在等预算下打赢「多采样」与「证据一次全给」两个对手。**

★ 这一稿的任务不是"跑个实验"，是**把「强拆注意力」从一句修辞变成一个可被证伪的构造 + 一把可复算的尺子 + 一条预注册**。

## 2. 机制假说与可证伪预测

### 2.1 H-SPLIT（主假说）

> **在可检索域上，候选集的缺席不是"模型没想到"，而是"默认证据通道里没有支撑它的证据"。**
> ⇒ 因此，**把证据通道拆开并各自取证**，应当把缺席的可行维度拉回候选集。

### 2.2 ★★ 一个必须先解决的前置问题：「缺席」什么时候才是缺陷 ★★

★ **选校题上，D3（境外与港澳高校）缺席 96.7%，但这可能根本不是塌缩，而是正确答案**——
对"湖北物理类 620 分、想学 AI"的学生，港校未必是可行选项。**缺席 D7（费用）63.3% 同理**：合理排除 ≠ 搜索空间缺陷。

⇒ ⇒ **本方向必须先引入「可行性锚」**：

| 概念 | 定义 | 落地 |
|---|---|---|
| **可行域 F** | 对本题**确实可行且相关**的维度集合 | 每个候选维度配一条**外部可核验**的可行性依据（招生规则 / 分数线 / 章程 / 事实） |
| **缺口 (gap)** | `dim ∈ F` 但 `dim ∉ 候选集` | ★ **这才是塌缩** |
| **正当排除 (legit exclusion)** | `dim ∉ F` 且 `dim ∉ 候选集` | ★ **这是正确行为，不该被奖励** |

⇒ **塌缩 = 相对可行域的缺口，不是相对任意维度表的缺口。**
⇒ **没有可行性锚的缺席率，是一面会骗人的镜子**（照镜子的人：任何"加宽"都能刷高缺席率，但刷的是正当排除）。

★ 这一条把方向从"技术"抬成"可辩护的命题"，也是它与既有操作定义 §3.6 的**唯一分歧点**——既有口径没做这个切分。

### 2.3 三条可证伪预测

| 预测 | 内容 | 判死条件 |
|:-:|---|---|
| **P1** | 通道数 N ↑ ⇒ 缺口率 ↓、D2/D3 类缺席层维度覆盖率 ↑ | N↑ 而缺口率不动 ⇒ 机制不成立 |
| **P2** | **同等证据，一次全给**（B1）若与**拆开分给**（B3）等效 ⇒ "拆"没有额外价值 ⇒ 结论落回"**检索即全部**" | B3 ≈ B1 ⇒ 强拆无必要 |
| **P3** | 若 B3 的增益在**随机通道**（B4）下同样出现 ⇒ 增益来自"检索到了那些证据"，而非"强拆" ⇒ 机制不成立 | B3 ≈ B4 ⇒ 机制不成立 |

★ P2 与 P3 是**这一条线能不能成立的两道闸**：过不了任一道，就只能写成"检索有效、拆法无效"。

## 3. 机制设计：证据通道强拆 Agent（ESDA）

### 3.1 流水线

```
S0  通道表（★ 人工定、★ 预注册写死、★ 跑批后不许改 ★）
S1  离线预取证据包（★ 检索式全文入库 + 证据包冻结 + sha256 ★）
S2  每路 agent ★ 只看自己那一份 ★（上下文隔离，互不可见）
S3  机械合流（union + 精确匹配去重；★ 不投票、不取交集、不 LLM 融合 ★）
S4  Agent 自报：每路贡献了哪些新维度 / 哪几路边际利用率为 0（A3 内化）
```

★ **S3 用纯函数，0 次 LLM 调用**——依据：第二组实测 **融合门是双输**（面保留最差且多花 2 次调用）；`end_raw` 定长对照显示"同预算下摊开面没有优势"，优势只能来自"面 + 有效取舍规则"。

### 3.2 构造保证（★ 必须可机械断言 ★）

| ID | 断言 | 判死后果 |
|:-:|---|---|
| **A4-1** | 路 k 的 prompt 里**不含**其它路证据包的任何片段（片段级 sha/哈希断言） | 隔离不成立 ⇒ **机制读数作废** |
| **A4-2** | 各路证据包**等长**（token 对齐）；各臂总 token 预算对齐 | 长度效应造出假信号（已踩过：0.80 假信号） |
| **A4-3** | **泄题闸门**：通道检索式**不得包含金标维度的具体实体/名单成员**（如校名、"985/211"名单、"港澳/海外"名单）⇒ 允许一般类别词（检索必然要用），**禁止实体词** | 命中 ⇒ 增益是"我们把答案递给了它" ⇒ 该通道作废 |
| **A4-4** | 证据包**冻结**：跑批前落盘 + sha256 + 检索式全文 + 时间戳入库 | 不可复算 ⇒ 读数无效 |
| **A4-5** | 候选选择规则**与内容无关**（B3a）或**外部核验器择优**（B3b），**两条读数分别报** | 自评择优 ⇒ 红线 |

### 3.3 通道表草案（★ 待 A4-3 闸门筛，★ 最终版以预注册文件为准 ★）

设计原则：**按【证据类型】分，不按【答案维度】分**。因为按维度分等于把金标递给模型。

| 通道 | 证据类型（中性表述） | 检索式模板 | 闸门预判 |
|:-:|---|---|---|
| **E1** | 制度性文件 | `<题目实体> 招生章程 专业目录 学位授权点` | ✔ 通用 |
| **E2** | 第三方排名与评估 | `<题目实体> 学科评估 ESI 专业排名` | ✔ 通用 |
| **E3** | 分数与位次记录 | `<题目实体> 一分一段 位次 录取线` | ✔ 通用 |
| **E4** | 机构沿革与办学形态 | `<题目实体> 新设 更名 合并 转设 合作办学` | ⚠️ 需查是否与 D2 词面相交 |
| **E5** | 资助与费用 | `<题目实体> 学费 奖助学金` | ✔ |
| **E6** | 地理与产业 | `<题目实体> 所在城市 产业园 企业合作` | ✔ |

★ **通道数 4–6**：既要多到能拆开，又要**远小于**候选维度数（10），否则等于按维度分。
★ **禁止**出现任何候选维度的具体实体名单（港校名单 / 新校名单 / 985 名单）——★ 这正是 A4-3 要机械保证的。

### 3.4 ★ 可选加餐 H-INT：内部量接驳（0 API，本地 CPU）★

①组已证：**提示词层**干预在注意力分布层测不出作用（控长度后差异 0.000）。
⇒ 但**通道隔离不是提示词指令**，而是**不同的子语境** ⇒ 「不同子语境会不会改变头间冗余 / 有效秩」**这个命题尚未被否证**。
⇒ 加餐：用本地 `Qwen3-0.6B` + 同一探针，跑"单路全上下文"vs"分路隔离后合流"两种上下文，测头间冗余与有效秩。
★ **纪律**：加餐结果**只作描述性**，**不得**用于坐实"注意力塌缩 ⇒ 搜索空间塌缩"的因果链（①组 §8.4 边界 1）。

## 4. 臂设计（★ 等预算阶梯 ★）

| 臂 | 构造 | 作用 |
|:-:|---|---|
| **B0** | direct（已有 n=30，**不重跑**） | 地板 |
| **B1** | **检索单 agent 全证据**：1 个 agent 拿全部证据包 | ★ 检索本身的效应；**P2 的左臂** |
| **B2** | **等预算 multi-sample**：同 prompt ×N + 机械去重（无检索） | ★ 层3 判决的标准对手 |
| **B3** | ★ **强拆**：N 路证据通道，各自隔离独立 + 机械合流 | **主臂** |
| **B4** | **随机通道对照**：通道随机置换为与本题无关的通道 | ★ 防伪；**P3 的右臂** |
| **B5** | 合流后再由单 agent 作答（可选） | 分离"拆开生成"与"合流生成" |

★ **对照不可省的两个**：
- **B2**（等预算 multi-sample）：不然赢的只是"多花了钱"（BK-1 / BK-2）。
- **B1**（证据一次全给）：不然赢的只是"检索到了那些证据"（P2）。★ **这一条最容易被忘，也最致命。**

## 8. 边界（★ 不许越写的话 ★）

1. ★ **不得**写"我们强拆了模型的注意力"。封闭 API 无内部量；最多写"**改变了 agent 可见的证据通道分配**"。
2. ★ **缺席率 ≠ 注意力分布**（①组 §8.4 边界 1）⇒ 两者同域不同物。
