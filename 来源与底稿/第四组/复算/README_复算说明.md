## 3 · ★ 判据定义（★ 与第四组 `analyze_ckf.py` 同义，★ 但代码独立实现）

```
检测键 anchor_keys(anchor) = 锚点串里抽出的数字/字母数字串（[A-Za-z]*\d+[A-Za-z]*）
                              ★ 若锚点里没有数字 ⇒ 退回整句短语（大小写不敏感）
命中 hit_any(text, keys)    = 数字型：归一化后子串精确匹配；短语型：大小写不敏感
同步 synchronized            = new_in_new ∧ ¬old_in_new ∧ ¬new_in_orig
     （换值版出现新值 ∧ 换值版不含旧值 ∧ 原版不含新值）
```
★ **为什么不能用整句锚点**：★ 档案里注入的是整句（"这款罕见病药的年治疗费用是 48200 元"），而正文里模型只写 "48200" ⇒ ★ 用整句去正文里找**永远匹配不上**。

## 4 · ★ 统计

| 量 | 方法 |
|---|---|
| 各臂同步率 vs **随机基线 0.5** | 精确二项检验（双尾） |

## 5 · ★ 本脚本输出的三段结果

1. **逐行对拍**（若 `p2_ckf_analysis.json` 在场）：★ **我的配对数 vs 对方的配对数、交集、逐行 `synchronized` 不一致数** ⇒ ★ **这是复算本身可信度的证据**（★ 复现第四组自己的分析产物，而不是只报自己的数）。
2. **分臂同步率** + 各臂 vs 随机基线 0.5 的精确二项 p。
3. **臂间 2×2 + McNemar**（两侧精确 + χ² 连续校正）＋ 逐配对明细（人肉核用）。
