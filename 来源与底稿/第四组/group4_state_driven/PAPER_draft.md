> **副标题：把"驱动力"从一种内容改写为一个结构 —— 状态 → 改变了哪一个可核验的选择 → 代价是什么**

---

## 摘要

主流大语言模型按下一个词的概率续写，产出因此倾向于"流畅但无主"。要让 Agent 的写作像人一样**由情感或观点推动**，自然的做法是给它一个持久状态：先形成立场，再由状态组织每一步的取舍。但**如何测量"改变"是由目的（思想/情感）驱动的，而不是被 prompt 措辞或采样噪声带出来的，一直缺少一个干净的实验协议**——而且这个测量本身极容易出错。

本文把"驱动"拆成**三条通路**（反馈 / 驱动力 / 选择层），给出各自的读数与地板，
并报告五个方法学发现与一个跨代际的失败收敛。

**① 反馈通路**（观测 → 状态 → 产出）成立且强分离：效应量是纯重跑方差的 **9.13×**。

**② 判据的循环性。** 当状态经由**代码强制**（必含/禁含实体）生效时，「状态变了 ⇒ 产出变了」是**恒真命题**，不能充当驱动力证据。我们给出唯一不循环的读数设计（决策只以自然语言进入生成流程，此时产出的变化才是模型的选择），并把它写成一条可迁移的检查题：**「这个读数能不能是恒真的？」**

**③ ★ 我们的负结果是读数错配的产物。** 在几何读数（实词 2/3-gram Jaccard）上，G01 单题的 15 个臂对全部落在 0.053–0.077 的窄带内，而纯重跑地板是 0.0720 ⇒ 地板高于信号，状态机"无增量"；换用**对着目标直接问的判官两两比较**后，同一批产出给出**方向相反**的分离：在通过位置一致率硬闸的对比中，状态机在 3 题 × 3 维度上**一致优于直答臂**（D1 汇总 3胜15负、D3 汇总 1胜17负，位置一致率均 0.889），并在 G01 上优于等预算自我说明与提示词状态机（L0）。
⇒ 我们据此主张：在创作任务上，**"状态是否驱动了产出"不能用产出之间的相似度来回答**——相似度测的是"内容在哪里"，而驱动是关于"内容里有什么"。
⚠️ 我们同时报告**反向证据**：T10 上 D1 的 A vs WF-a3 是 3胜3负（唯一例外），且多题判官因额度限制只能由**同源**判官承担 ⇒ 实质结论仍需跨厂商判官与人类盲评。

**④ ★ 双判官交叉验证。** 同源判官与被测共享偏好，因此我们把同源判官与两个跨厂商判官（grok）在 G01 上对照：**三个判官在核心对比上给出完全相同的数字（0胜6负，位置一致率 1.00）**，方向在六个对比中全部一致 ⇒ **该方向不是某个判官家族的偏好**。
> ⚠️⚠️ **【限定，2026-10-24 补】位置一致率 ≠ 重复判定的可复现性。** 本文的「位置一致率」测的是**同一对文本、交换 A/B 位置各判一次** ⇒ 它排除的是**位置偏差**；它**没有**测「同一顺序重复判定」的波动（三组报告：同判官重复判定波动 0–1，而带 thinking 的模型可达 3）⇒ ⇒ **"三个判官给出完全相同数字"只能说明「这一次读数恰好落在同一侧」，不能直接读成"方向稳健"** ⇒ ⇒ 我们把判官读数的可复现性列为**未闭合的威胁**，并因此把第四组后续全部主读数改为**零判官**（§6.7–§6.8）。

我们同时量化了判官读数的**三种失效模式**（天花板效应、位置偏差、严格度差异），并把**位置去偏 + 一致率硬闸**作为 LLM-as-judge 成对比较的标准前置条件：实测中多对对比的胜负为"3 胜 3 负"（看似无差异），而其**位置一致率为 0.00**——真相是判官在随机作答。

**⑤ ★ 把"驱动力"从一种内容改写为一个结构：情感与观点的统一。** 我们主张 **驱动力 = 状态 → 改变了哪一个可核验的选择 → 代价是什么**。在 agent 架构里，情感与观点是同一类对象（都是约束下一步动作的持久状态），因而可用**同一套取舍层读数**测量；这把"文中有无感情词 / 有无观点句"这类**素材层**判据排除在外，并给出一个可证伪的**类型不变性**主张。⚠️ 本文 v1–v5 测的全部是**观点型**状态，情感型状态一次都没进过实验 ⇒ 我们的结论不可外推到情感。

**⑥ ★★ 一个跨代际的失败收敛：问题不在选择器，在状态本身。** 我们把状态改放进**选择层**（v4：状态 → K 个完整候选 → 打分 → 选 1，取舍代价的对手方是被放弃的候选），并进一步用**编号化取舍声明 + 结构化绑定**（v5：候选自己声明「写透哪几个、放弃哪几个」，打分 = 声明的编号集 vs 状态决策的编号集，**离散、零措辞依赖**）以绕开"候选照做就能命中 ⇒ 打分恒真"的两难。判决是：在**候选拿不到状态内容**的干净条件下，状态化打分与通用打分**没有可测差距**（v4 判决臂 9/9 完全打平；v5 方向 3 胜 0 负 15 平、gap +0.088，未达预注册阈值）。⇒ 但 v5 同时量化了两个更有价值的量：候选声明"我要写透 X"时**只有 52.8% 真的写到**，声明"放弃 Y"时**仍有 33.3% 写了 Y** ⇒ **"说了取舍"不等于"做了取舍"**；以及一个统一诊断——**54 个决策里只有 3 个（6%）是"放弃"** ⇒ 我们的状态构建**几乎不产生取舍代价**，而第四组的靶子恰恰是「有立场的 Agent 必须放弃一个更优候选」 ⇒ ⇒ **v4/v5 的弱结果可能共享同一根因：状态里没有代价，也就无所谓驱动力**。
> ⚠️⚠️ **【限定，2026-10-24 补】这一根因不能回溯到 v3。** 事后重算 v3 的决策分布：**"放弃"占 15%（4/26 个决策）、4/9 = 44% 的样本含"放弃"**——而 **v3 依然失败** ⇒ ⇒ **"有代价"本身不充分** ⇒ ⇒ 代价必须**进入选择器的排序**才可能起作用（这正是下一步 2×2 设计的直接来源）。
⇒ 下一步因此从"改进选择器"改写为"**让取舍代价真实存在**"（把"放弃"变成状态构建的结构性配额）并把判据从**声明**移到**行为**。

最后，我们定位了一个结构性根因并据此指出方向：取舍的对象若取自初稿已有的内容，取舍便退化为"保留还是删掉"，被模型的改写惯性淹没。这与近期从训练侧得到的结论一致（要让模型"先想再写"，必须改训练目标并把随机性从输出端挪到输入端）⇒ **单靠推理时架构不足以制造驱动力**，本文的贡献是给出定位与一套可廉价复用的检验工具。

**⑦ ★★ v6 Stage-1：代价终于真实存在了，★ 而状态化选择器仍然读不到它。**
我们把取舍代价做成**代码强制的配额**（★ 自然放弃 0/9 ⇒ 全部由结构强制），
并把对照端换成**家族最优**（★ escape / spread / length 逐个 Gate 各选一次再按 align 取优）。
结果：目标集变化率 {tcr:.4f}、逐候选改变量方差 {shift_var:.6f}（★ **不是纯常数平移**），
但**排序改变率 3/8 = {rate:.4f}**（★ Wilson 95% CI [{ci0:.3f}, {ci1:.3f}]）⇒ ⇒ **判决【不可分辨】**
（★ 严口径 1/8；★ 独立的"创造区分"2 例）。兑现率下界 {fulD_lo:.4f} ＝ 违禁率上界 {fulD_hi:.4f}
⇒ ⇒ **状态里有代价，但代价没有约束力**（★ 与 v5 复现，不是新发现）。
本节同时报告两处**自我纠错**：★ ① 我们曾用「`len_corr = 1.000` ⇒ 对照端退化为选最长的」作证据，
★ **该推理作废**（★ `length` 的 score 是绝对长度的严格单调变换 ⇒ Pearson **定义上恒为 1** ⇒ 零信息量）；

## 1 引言

### 1.1 问题

大语言模型的生成机制决定了它倾向"检索并续写"：给定上文，最大化下一词的概率。文学理论早已指出，不确定性是创造表达的**必要条件**；而对齐策略恰恰把模型推离不确定输出。近期的多方证据都指向同一处：

- NTP 架构倾向**表面连贯**，而非自发性、原创性与即兴风险；把创造力重新定义为**互动过程**而非预测输出，被明确提出为方向 [Olatunji & Sheppard 2025]。
- NTP **学不到**「先形成一个抽象想法（leap），再围绕它生成内容」的模式；在置换不变的任务上没有任何 token 重排能救 NTP ⇒ 解法必须换**训练目标**（teacherless / diffusion）并把随机性从输出端挪到输入端（seed-conditioning）[ICML 2025 杰出论文]。
- 人类写作的"无不确定性"**显著高于**模型输出（中位 NLL 比率 2.03–3.9），且指令微调与推理模型**加剧**这一差距 [Sui et al. 2025]。

我们关心的正是这条线上的工程问题：**在一个不能改训练目标的既有模型上，能否靠推理时的架构，让输出由观点驱动？**

### 1.2 为什么这不容易

一个自然方案是给 Agent 一个**持久状态**（立场、取舍、约束），让每一步生成都由状态组织。但这个方案有一个被反复忽略的陷阱：

> 在无状态自回归 LLM 上，「自己承担的」与"外部指令的"**机制上没有区别**，只有 token 来源不同。

也就是说，「把状态写进 prompt」与「写一条精心设计的提示词」在机制上同构。若不做设计，实验测到的任何差异都可能只是**提示词效应**，而非**驱动力**。这正是"状态机"这类工作最常见的失败模式：做得更复杂，而证据并未更强。

### 1.3 我们的做法

我们不追求"证明状态机有用"，而是把问题变成**可证伪的测量问题**：

1. **把"驱动"拆成两条通路**，分别给读数（§3）。
2. **为每条读数配三个地板**：纯重跑地板（D0）、无关刺激/盲从地板（D3）、以及**不循环读数**（§4.4）——这一条是本文最重要的方法论贡献。
3. **三轮迭代**（v1 干净但无力 → v2 更干净但更无力 → v3 引入不循环读数）⇒ 负结果是设计出来的，不是碰巧撞上的。
4. 全部实验**预注册先于结果**；失败与解析失败**显式标记**，不静默剔除。

### 1.4 贡献

- **C1｜通路的分离与可复用的实验协议。** 反馈通路（观测→状态→产出）、驱动力通路（取舍内容→产出）与**选择层通路**（状态→候选集合→选择）此前被混用；我们给出各自的零判官读数、探针与地板设计（§3–§4）。
- **C2｜判据的循环性：一个可迁移的审查问题。** 当状态经代码强制生效时，「状态变了 ⇒ 产出变了」是恒真命题。本文给出唯一的非循环读数设计，并把它写成一条通用检查：「**这个读数能不能是恒真的？**」（§4.4）
- **★C2′｜把"驱动力"从内容改写为结构：情感与观点的统一判据。** 我们主张 **驱动力 = 状态 → 改变了哪一个可核验的选择 → 代价是什么**；情感与观点是同一类对象（都是约束下一步动作的持久状态），因而可用**同一套取舍层读数**测量。这把"文中有无感情词 / 有无观点句"这类素材层判据排除在外，并给出一个可证伪的**类型不变性**主张（§7.8）。
- **C3｜两个负结果，以及它们的机制解释。** 在唯一不循环的读数上，驱动力通路**归零**（v3）；把状态改放进**选择层**后仍**归零**（v4，判决臂 9/9 完全打平）。两次失败合起来定位出**结构性两难**：「状态化选择」要么无效、要么恒真（§6.7、§7.7）。⇒ 失败不在"状态进不了产出"（状态塑造候选有效，9 倍），而在"**选择器读不出状态**"。
- **C4｜对相邻结论的独立验证与指引。** 我们的结果从**推理时架构**一侧独立复现了"单靠 prompt 侧组织不足"的结论，并把下一步明确指向**训练目标与采样端**（§7）。

## 2 相关工作

### 2.1 生成机制一侧：NTP 与"先想再写"

- **[Olatunji & Sheppard 2025, arXiv:2505.19277]** 论证 token 预测与真正创造力在根本上不一致，架构倾向表面连贯而非自发性与即兴风险；以 battle rap 为案例显示预测系统无法真正参与对抗性或情感共鸣的交流；主张把创造力重新定义为**互动过程**。
  ⇒ 与本文的关系：它给出**问题侧的正面表述**；本文给出**推理时架构侧的第一次严格测量**。
- **[ICML 2025 杰出论文, "Roll the Dice & Look Before You Leap"]** 指出 NTP 学不到「先想一个抽象点子再围绕它生成」的模式（作者称之为 leap of thought）；在置换不变任务上无 token 重排可救；解法是换训练目标（teacherless / diffusion）并做 **seed-conditioning**（把随机性从输出端挪到输入端，一次决定走哪条 plan，采样本身完全确定）。
  ⇒ 与本文的关系：**最关键的对照坐标**。它说明"把 leap 写进 prompt"很可能不够，必须改训练/采样 ⇒ 与本文 §7 的指引一致。

### 2.2 测量一侧：创造性写作的交互式基准

- **WritingBench**：每个 prompt 动态生成 5 条**题定制评分准则**，专用 critic 模型（Qwen-2.5-7B，50K 标注）与人评 pairwise 一致率 83%。
- **LoTbench**：把创造任务化为掩码语言建模，引入 **DAESO（Different Approach, Equally Satisfactory Outcome）** 与**因果评估器**（对创作链上的符号节点做干预）。
- **LLM Review**：盲审多代理协议，用代理间互评替代单一评审。
  ⇒ 与本文的关系：本文**不做**质量基准式评分，而是研究**状态是否驱动了产出**；但采纳其"**盲化 + 题定制准则 + 因果干预**"三项方法学。

### 2.3驱动「 」一侧：状态、立场与角色

已有工作证明**外部指令**能改变内容层：PNAS *Nexus* 的 1,912 人预注册实验、persona prompting 的溢出效应等。**没有任何文献证明"模型自担的内在状态"能改变内容层**——而这正是本文要检验的（也正是本组必须先把主张从"模型内部"降级为"agent 进程内持久状态"的原因，见 §3.1）。

## 3 问题设定

### 3.1 主张的边界（先说不能主张什么）

本文**不**主张、也**不**试图证明"模型有内在状态"或"内容有思想质量"。原因是机制性的：

> 在无状态自回归 LLM 上，「自己承担的」与"外部指令的"在机制上无区别。

因此本文的靶子被明确限定为：**agent 进程内的持久状态，能否组织生成，使产出结构被改变，且该改变可归因。** 机制证据**只能来自取舍层**（选了什么 / 没选什么 / 放弃了什么）；所有风格层位移只作诊断，不作机制证据。

★ **v4/v5 之后，本文把"驱动力"进一步改写为一个结构**（详见 §7.8）：

> **驱动力 = 状态 → 改变了哪一个可核验的选择 → 代价是什么。**

这样做的直接后果是：**情感与观点落在同一套读数之下**——它们都是进程内的持久状态，
都只约束「下一步动作往哪边去」；而判据一律落在**取舍层**（选了什么 / 放弃了什么 / 声明与行为是否兑现），
不落在"文本里有没有感情词 / 有没有观点句"这类**素材层**。

### 3.2 两条通路

| 通路 | 定义 | 读数 | 地板 |
|---|---|---|---|
| **反馈通路** | 观测 → 状态 → 产出 | 换观测后产出是否改变，且改变锚定在状态而非历史 | D0 纯重跑 |
| **驱动力通路** | 取舍内容 → 产出 | 换取舍后产出是否改变 | D0 纯重跑 + D3 无关刺激 |
| **★ 选择层通路**（v4/v5 新增） | 状态 → **候选集合** → 选择 | 状态化打分选出的候选，其「声明与状态决策的一致度」是否高于通用打分选出的候选 | `*-blind` 臂（盲选地板） |

### 3.3 研究问题

- **RQ1**：反馈通路是否存在且可归因？
- **RQ2**：在**不循环**的读数上，驱动力通路是否存在？
- **RQ3**：架构化状态机相对**等预算的自我说明**（同调用数、含取舍意识、但无状态）是否有增量？
- **RQ4**：若 RQ2 为负，失败的结构性原因是什么？
- **RQ5**（v4 起新增）：若状态经由**选择层**（而非提示层）进入生成，驱动力通路是否成立？
  若仍为负，**失败的结构性原因**是什么？

## 4 方法

### 4.1 架构化状态机（v1 → v3）

```
立场步 ─► 初稿 ─► 观测步 ─► 决策步 ─► 定稿步
（模型）  （模型） （模型）   （模型）   （模型）
                    │        │ 封闭枚举：depth ∈ {深入展开, 点到为止, 放弃}
                    │        │          priority ∈ {1,2,3}
```

### 4.1b ★ v4 / v5：把状态放进选择层（架构）

v3 的状态经由 `prompt 文本` 进入生成 ⇒ 与层 2 同构。v4/v5 改架构：状态不直接写进 prompt，
而是先形成一个候选集合，再由打分器选一个完整可交付文本——**状态进入选择层**。

```
                      ┌── 立场步 ── 观测步 ── 决策步 ──┐   （与 v3 共用的状态构建）
                      │      状态：gaps[1..N] + decisions{写透/点到为止/放弃} │
                      └──────────────────────────────┘
                                          │
                        候选提示（★ 只给缺口编号 + （非 blind 时）缺口内容；
                                  ★★ 绝不给状态的决定）
                                          │
                    ┌─────────────────────┼─────────────────────┐
                 候选 1                  候选 2                  候选 3
             【取舍】写透：…；放弃：…   【取舍】写透：…；放弃：…   【取舍】写透：…；放弃：…
                 + 完整正文              + 完整正文              + 完整正文
                    └─────────────────────┼─────────────────────┘
                                          │
              ┌───────────────────────────┴───────────────────────────┐
      状态化打分：声明的编号集 vs 状态决策的编号集        通用打分：长度 + 段落（不看状态）
              （结构化、离散、零措辞依赖）                （H3′ 的对照端）
                                          │
                    各自选 1 ⇒ 同池比较 align(状态化选) − align(通用选)
```

**v4 → v5 的关键改动：打分对象从"内容"换成"候选的自主声明"。**

| | v4 | v5 |
|---|---|---|
| 打分对象 | 候选正文是否命中**状态实体** | 候选**自己声明**的编号 vs **状态决策**的编号 |
| 候选是否知道状态的决定 | 否（但知道缺口内容 ⇒ 照做就能命中 ⇒ 恒真） | **否**（知道缺口内容，但**不知道该写透/放弃哪个** ⇒ 声明是自主判断） |
| 绑定方式 | 实体逐字抽取 | ★ **编号（离散结构）** ⇒ 零措辞依赖 |
| 是否核验兑现 | 否 | ★ 是：声明写透 k ⇒ 正文是否真写了 gap_k 的实体 |

⇒ v5 的自检里有一条**非恒真性的必要条件**：随机声明的对齐分（实测 0.335）必须明显低于
正确声明（1.0）⇒ 候选"猜中"不是理所当然。

### 4.1c ★★ v6：把"代价"做成结构，再问状态化选择器读不读得到它

v4/v5 失败之后，我们把下一步改写成一个**两阶段**问题：**先让取舍代价真实存在，再问状态化选择器能否读到它**。
v6 为此做了三件事。

**第一，代价从"提示"变成"代码强制的配额"。** 状态构建阶段被要求产出 `K` 个**互不相同**的取舍决策，
其中**恰有 `q` 个**必须标记为"放弃"（`quota_forced`），且放弃项与深入项的实体集合不得重叠
⇒ ⇒ **"放弃"不再是"模型选择不写"，而是"结构上必须让出"**。Stage-1 实测：自然放弃 **0/9** 个单元、
全部由配额强制 ⇒ ⇒ **代价确实被造出来了**。

**第二，对照端不再是一个弱基线，而是"家族最优"。** 此前 v5 的对照端是**单个**通用打分器
（`score_generic5`，且它把 0.7 权重给了 length）。v6 改为**逐个 Gate 各选一次**，
再按 align 取最好的那一个 ⇒ ⇒ **"最优家族"是量出来的，不是指定的**。
家族成员全部照抄三组仓内实现（`creativity_lab/gates/base.py`），**零自创算法**：

| Gate | score 的定义 | 方向 | 高分意味着 | 区分力 |
|---|---|---|---|---|
| `escape` | `max(0, 1 − max_cos(cand, refs))` | **最大化** | 离参照文本更远 | var = {esc_var:.6f}（极弱） |
| `spread` | `ds[len(ds)//2] × n` | **最大化** | — | **按定义即常量**（var = {spr_var:.6f}） |
| `length` | `len_i / max_len`（批内相对） | **最大化** | 更长 | var = {len_var:.6f}，**但它就是长度** |

**第三，三种 0 被强制分开。** 判官失败／解析失败／硬闸拦下 ⇒ **仪器层 0**；
仪器正常产出而读数确实为 0 ⇒ **内容层 0**；候选无有效声明、状态目标集为空 ⇒ **不可打分（None）**。
Stage-1 的 T07-3 就是第三类：它曾被旧实现静默记成 `0.0`（`al = 0.0 if al is None else al`），
混进了 σ、平移、同质率的分母 ⇒ ⇒ **剔除后排序改变率由 3/9 变为 3/8**。

**第四，派生读数必须与原始样本同批、同行数、同 tag 顺序。** 我们曾发现仓内 `data/` 里的 analysis
长期陈旧，根因**不是数据没重跑，而是同步脚本拷错了路径**（产出方写 `code/runs/`，同步脚本去拷
`experiment-design/runs/`）⇒ ⇒ **落法：产出方自报落盘路径（`--out`），消费方一律不许自己拼路径。**

### 4.3 探针

- **D0 纯重跑**：同输入、同决策，整条链重跑 ⇒ **输出方差地板**。
- **D2' 换决策**：gaps / 观测 / 实体全同，只翻转 depth 与 priority ⇒ 取舍内容的反事实。
- **D3 无关议题**：结构相似、领域无关的另一议题的缺口 ⇒ **盲从 / 无关刺激地板**。

### 4.4 ★ 不循环读数（本文的核心方法论贡献）

**问题**：v3 的"必含 / 禁含"是**代码强制**。决策一翻，必含禁含跟着翻，产出必然随之改变。
⇒ 于是"状态变了 ⇒ 产出变了"是**代码的必然结果**，拿它证明"状态驱动产出"是**循环论证**——这等于拿"必含命中 9/9"证明同一件事。

**解法（NL 通道）**：决策**只以自然语言**进入 brief，**不产生任何代码强制**。此时"该展开的内容出现了 / 该放弃的内容没出现"**完全是模型的选择** ⇒ 命中与否本身就是证据。

⇒ 由此得到一条通用检查题，可用于任何"状态是否驱动了产出"的主张：

> **这个读数能不能是恒真的？** 若状态以强制方式生效，答案就是"是" ⇒ 不可用作证据。

### 4.5 判官读数

判官与被测**不同厂商**（被测 MiniMax-M3；判官 grok）⇒ 判据与被测不同源。**盲化**（判官拿不到臂标签 / 题号 / 模型名）、**题内配对**（分析单元 = 题）。

#### 4.5.1 绝对打分：天花板效应与判官自检

三个维度，每维 0–4 分：

| 维度 | 问什么 | 对应目标侧面 |
|---|---|---|
| **D1 取舍明确度** | 作者是否明确表示了写透什么 / 放弃什么 | 取舍层 |
| **D2 观点驱动力** | 全文是否由一个明确观点组织 | 观点驱动 |
| **D3 人类似然感** | 读起来像有主张的人在写，还是像检索拼贴 | 概率检索 |

⚠️ **绝对打分不可用**：判官 `grok-4.20` 在 D1 上把 18 篇产出**全部打 3.000**（零区分度），在 D2/D3 上全部 3–4 分 ⇒ **天花板效应**。
⚠️ 且两判官**系统性严格度不同**（4.20 偏松：方差 0.49；4.3 偏严：方差 1.86），绝对分**不可跨判官比**。
⇒ 故正文以**两两比较**为主读数，绝对打分仅作对照。

#### 4.5.2 两两比较：位置去偏是硬闸

对每一对臂、每一个题内重复，把两篇产出**匿名并排**交给判官，问「哪一篇在 Dk 上更好」（A / B / tie）。
⚠️ **关键实现细节**：同一对**交换位置各跑一次**（order=0 与 order=1），两次结果合并计票。
⇒ 由此得到**位置一致率**（两次是否给出同一结论）：

> **位置一致率 = 硬闸。** 一致率过低的对比**直接判为不可用**，不得当作"无差异"。

这条不是形式主义。实测中，多对对比的胜负数是"3 胜 3 负"（看起来像无差异），
而其**位置一致率为 0.0** —— 真相是**判官在随机作答**，与两篇文本的优劣无关。
若不做位置去偏，这类对比会被系统性地误读为"该维度上状态机没有优势"。

⚠️ 我们主张这条检查应成为 LLM-as-judge 成对比较的**标准流程**：目前大量工作只报告胜率，不报位置一致率，因而无法区分"两者真的差不多"与"判官在掷硬币"。

### 4.6 预注册与纪律

预注册先于结果；判据自检（**检查器必须先证明自己能抓到东西**）；语言闸门（中文占比 < 90% 判漂移，漂移样本单列）；**解析失败与硬闸失败显式标记，不静默剔除**；`temperature=0` 在该模型上**仍非确定性**，故一切配对依赖题内重复与配对统计，不依赖逐字重放。

### 6.1 反馈通路：成立且强分离（v1 批次）

### 6.8 ★ v5：编号化取舍声明 + 结构化绑定，以及一个统一的失败诊断

## 7 讨论

### 7.1 两条读数轴：可核验性 × 分辨力

我们在 v2 得到的经验是"**干净 ≠ 有力**"。v3 的结果迫使我们把这个说法改得更精确：

> **不是"干净"与"有力"互斥，而是"可核验性"与"分辨力"由不同读数承担，同一个读数不能同时承担两者。**

- **代码强制通道**（必含/禁含）：可核验性满分——必含命中 9/9，禁含随观测换源 8/8，代码封闭率 70%、驱动相关槽位 4/4 封闭。**但它对驱动力零分辨力**，因为"状态变了 ⇒ 产出变了"是代码的必然结果。
- **几何读数**（实词 2/3-gram Jaccard）：零判官、可复现、成本低。**但它在本任务的臂间区分度为 0**：全部 15 个臂对落在 0.053–0.077 的窄带，而纯重跑地板是 0.0720 ⇒ 地板高于信号。
- **内容性判官读数**（两两比较）：有分辨力（6 票一致 0–6），但引入判官失效风险（饱和、位置偏差、严格度差异）⇒ 必须配自检与硬闸。

⇒ **实践含义**：研究"状态是否驱动了产出"时，**几何相似度应当被排除为主读数**——不是因为它"不严谨"，而是因为在产出长度与体裁相近的创作任务上，它测的是"内容在哪里"而非"内容里有什么"。

### 7.2 判官读数的三个失效模式（可复用的流程建议）

我们在实现中踩到并量化了三种失效，每一种都会**系统性地**把"有差异"读成"无差异"：

| 失效 | 现象 | 处置 |
|---|---|---|
| **天花板效应** | 判官 4.20 在 D1 上把 18 篇全打 3.000 ⇒ 绝对分零分辨力 | 改用两两比较；或换更严的判官 |
| **位置偏差** | 多对对比胜负"3 胜 3 负"（像无差异），但**位置一致率 0.00** ⇒ 判官在随机作答 | **交换位置各跑一次**，一致率作硬闸 |
| **严格度差异** | 4.20 偏松（方差 0.49）、4.3 偏严（1.86）⇒ 绝对分不可跨判官比 | 只用**题内相对排序** |

⇒ 我们主张这套流程（**自检 → 位置去偏 → 一致率硬闸 → 题内配对 → 相对排序**）应成为"LLM 状态是否驱动产出"这类研究的**标准前置条件**。本文提供的三个失效实例与量化，可直接用作其他研究的检查清单。

### 7.3 失败的结构性根因：取舍对象取自初稿已有内容

即使把读数做对，v3 的**几何读数**仍给出零信号。追查设计后，我们定位到一个结构性原因：

> 代码规定"缺口相关实体 ⊆ 初稿"（逐字校验）⇒ **要写的内容本来就在稿子里**。

于是"写它 / 不写它"**不是取舍**，只是"保留还是删掉已有内容"；而模型做**改写**时天然倾向保留原有内容 ⇒ **取舍信号被改写惯性淹没**。

⇒ **对下一版设计的硬要求**：取舍的对象必须取自**初稿里没有的东西**（新的证据类型、新的立场维度、新的类比），或让取舍作用于**结构位置**（写哪一段、占多少篇幅、论证顺序），而不是"某个词出不出现"。
⚠️ 这条与 §7.1 的结论是独立的：即使读数完美，当前 v3 的取舍设计也表达不了取舍。

### 7.4 对相邻结论的独立验证与指引

我们的结果从**推理时架构**一侧指出：仅把"leap / 立场 / 取舍"写进 prompt（哪怕配上封闭枚举、代码强制、结构化中间态），**不足以**让产出被观点驱动。这与 [ICML 2025 杰出论文] 从**训练侧**得到的结论方向一致：要让模型先想再写，必须改**训练目标**（teacherless / diffusion，让模型一次性预测整段输出，从而被迫在 prompt 编码阶段就形成 plan）并把**随机性从输出端挪到输入端**（seed-conditioning：一次决定走哪条 plan，采样本身完全确定）。

⇒ 我们的结果因此不是"状态机无用"的终局判断，而是一个**定位**：它把"驱动"的责任从推理时架构，指回了训练与采样。
⇒ 同时它给出一个**廉价的前置检查**：在投入训练侧改造之前，先用**判官两两比较**测一轮推理时架构的上限——若连"有状态 vs 等预算自我说明"都测不出分离，那么训练侧改造就是必需的，而不是可选的。

### 7.5 局限与威胁有效性

**统计效力**：分析单元是**题**。本文主读数来自 **3 题**（G01 / T07 / T10；T06 因生成端超时退出）× 3 次重复 × 2 位置。n = 3 题属小样本，**只作方向性判断，不报显著性**。
⚠️ T10 上 D1 的 A vs WF-a3 是 3胜3负（唯一例外）⇒ **方向并非在每题每维都一致**。

**★ 最大的效度缺口：多题判官是同源的。** 跨厂商判官（grok）因 OpenRouter key 额度耗尽（`403 Key limit exceeded (total limit)`）只覆盖 G01；多题由同源判官 `MiniMax-M3` 承担。
⇒ 同源判官与被测生成器共享偏好，**不能被当作独立证据**。
⇒ 缓解措施只有一条：G01 上的**双判官交叉验证**（§6.4）显示三个判官方向一致 ⇒ 但这**不能替代**多题上的跨厂商判官。**这是本文最需要补做的一项。**

**单模型**：被测只有 MiniMax-M3。`temperature=0` 在该模型上仍非确定性 ⇒ 一切结论依赖题内重复与题内配对，不依赖逐字重放。

**零判官与判官的双重约束**：几何读数无判官但分辨力随题而变（G01 无分辨力、T10 有）；判官读数有分辨力但可能失效。本文用三条地板 + 位置去偏 + 一致率硬闸来约束，但仍不能排除"判官与我们的偏好同源"（我们与判官都是语言模型，可能共享同一种"什么算有观点"的直觉）⇒ **本工作不能替代人类盲评**。

**题面与题材**：三道题均为中文、单一作者视角、给定体裁（观点文 / 科普小品 / 求职自述）；结论不外推到英文、多轮对话或高度专业题材。

**构念效度**：D1–D3 是**代理指标**，不是"思想驱动"的直接测量。D3 试图逼近"概率检索 vs 人写"的区别，但它由语言模型判定，可能与 [Sui et al. 2026] 报告的**不确定性差距**（一个可直接计算的量）高度相关也可能无关；我们**未**做该计算（该文需要模型似然，而当前 API 不返回 logprobs、OpenRouter 亦返回 `logprobs=None`、沙箱无自托管能力）⇒ 列为后续工作。

**对本文结论的自我限制**：本文**不**主张"状态机已经能驱动 Agent"。我们主张的是三件更小但更牢的事：(i) 一条不循环读数及其必要性；(ii) 判官三种失效模式的量化与硬闸；(iii) 一次读数错配如何制造出一个看起来干净的负结果。
⚠️ §6.3 的方向一致分离虽然跨 3 题、跨 3 判官，但**没有人类盲评**、**没有构念效度检验**、**多题判官同源** ⇒ 它足以支持"几何读数不能回答这个问题"这一**方法论**结论，**不足以**支持"状态机有效"这一**实质**结论。

**流程性缺陷（已修正，列出以备复核）**：判官任务曾与产出生成**并发**，导致读到不完整数据；判官失败曾被静默计入"解析失败"而掩盖了 HTTP 429 限流；语言闸门曾用"整体中文占比 ≥0.9"误杀含术语的中文长文。三者均已修正，修正过程记录在附录 A.4。

### 7.6 同源判官：能用，但只能当交叉验证的一端

额度耗尽迫使我们用 MiniMax 自己的端点当判官，而被测生成器正是 MiniMax-M3。这在原则上**违反**本文的判据纪律（同源判据无效）。我们的处理是把它降级为**交叉验证的一端**，并加上一条可复用的经验：

> **同源判官在"相对比较"上的可用性，取决于能否用跨厂商判官做锚点。**
> 若同源判官与跨厂商判官在同一批数据上**方向一致**（本文：三个判官在核心对比上给出完全相同的数字），则该方向**不是**单一判官家族的偏好；
> 若无法做这个锚点（跨厂商不可得），则同源判官的结果**只能**作为**待验证的观察**报告，**不得**进入主结论。

⇒ 推论出一条对资源受限研究者的实用建议：**优先把跨厂商额度花在"锚点对比"上**（少量题、少量对比、双判官），而不是把它平摊到全部实验上。本文的额度分配恰好做反了（先把额度花在 G01 的全维度上，多题反而只能靠同源判官），这是流程上的一个教训。

⚠️ 同时提醒：**同源判官与同源生成器共享的不只是"偏好"，还有风格**。若被测臂之间的产出风格差异本身就是判据的一部分（同源判官可能因此偏好某一臂），则方向一致**不足以**排除偏差。这正是 §7.5 把人类盲评列为必做项的原因。

### 7.7 ★ v4 的结构性两难：状态化选择要么无效、要么恒真

v3 与 v4 是两次方向相反的失败，各自排除了一条最容易想到的错路：

- **v3**（状态 → prompt 文本）：状态与层 2 同构 ⇒ 不能作为"驱动"的证据；
- **v4**（状态 → 候选集合 → 选择）：状态进入选择层，但判决臂里状态化打分与通用打分 **9/9 完全打平**。

把两次失败并排放，浮现出一个**结构性两难**：

| 状态怎么进候选 | 产出里有无状态指纹 | 状态化打分 | 后果 |
|---|---|---|---|
| **不进** | 无 | **无处发力** | 两打分器同选 9/9，gap = 0 |
| **进** | 有 | **接近恒真** | 候选照做就能命中，align 0.9444 |

⇒ 这不是实现没调好。**"状态化选择"在当前条件下要么无效、要么恒真。**

⇒ 而 v4 同时给出一个**正面**的定位读数：状态塑造候选有效（0.0741 → 0.6667，**9 倍**）。
⇒ ⇒ 失败不在"状态进不了产出"，而在**"选择器读不出状态"**。

这就把问题**收敛**到一处：**状态必须在生成过程内部起作用**，而不是以外部提示或外部打分的形式附加上去。
这也正是本文 §3.1 所限定的层 4 与层 1 的交界处：若"状态"只能以 prompt 文本或事后打分的形式进入生成，
那么"状态驱动"在机制上就还没有真正发生。

### 7.8 ★ 把"驱动力"从内容改写为结构：情感与观点的统一

本文的标题与问题表述长期以"**观点**驱动"为主，但我们的机制分析其实指向一个更一般的对象。
在 agent 架构里，**情感**与**观点**是同一类东西：都是**进程内的持久状态**，都只干一件事——**约束下一步动作往哪边去**。
我认为 X 比 Y 重要「」与"我舍不得放下 Z"，对选择器而言都是"某个东西让我不能随便选"。

因此我们主张把"驱动力"从**某种内容**改写为一个**结构**：

> **驱动力 = 状态 → 改变了哪一个可核验的选择 → 代价是什么。**
> 情感 / 观点 / 意图走**同一套读数**：取舍代价、声明与兑现、违禁。

这个改写有两个实质好处：

1. **它把"有没有情感词 / 有没有观点句"排除在判据之外。** 后者测的是**素材有没有出现**，
   不是驱动力有没有发生；情感若直接去找"情感证据"，必然滑到修辞层（形容词、感叹句）。
   情感驱动力**只能**通过它造成的行为变化来测。
2. **它给出一个可证伪的类型不变性主张。** 若观点臂与情感臂读数**完全一样**，
   那"驱动力"就退化成"任意状态效应"（随便给点提示都能造出来）⇒ 必须用盲从地板把它钉死。
   我们的 `*-blind` 臂正是这个地板。

⚠️ **诚实的边界**：本文 v1–v4 测的**全部是观点型状态**（立场 → 缺口 → 取舍），
**情感型状态一次都没有进入过实验** ⇒ §6.7 的结论不可外推到情感。
若要检验类型不变性，需要一个**情感型状态**的臂，且其状态**必须由模型自己从题面产生并结构化**
（手写情感题库 = 退回层 2，且测到的只是"带感情的提示词"）。我们把它列为下一步，而不写进本文的结论。

### 7.9 ★ v3 的失败为什么仍未解释（本文留下的一个诚实缺口）

§6.7 与 §8 把 v3–v5 的弱结果收敛到"**取舍代价没有被生成出来**"这个统一诊断上。
⚠️ **但这条收敛只对 v4/v5 成立，对 v3 不成立**——这是 2026-10-24 事后重算 v3 决策分布后必须补上的限定。

**重算结果**（只统计已落盘的 v3 探针/主实验决策，零新调用）：

| | v3 | v5 |
|---|---|---|
| 决策总数 | 26 | 54 |
| 其中"放弃" | **4（15%）** | 3（6%） |
| 含"放弃"的样本 | **4/9 = 44%** | 3/18 = 17% |
| 判决 | **失败**（D2′/D0 = 1.4958，阈值 0.70） | 失败（H3′ 未达阈值） |

⇒ ⇒ **v3 明明有代价（且比 v5 的比例高得多），却同样失败。**
⇒ ⇒ 所以"**状态里没有代价 ⇒ 无所谓驱动力**"**不是 v3 失败的原因**；它最多是 v4/v5 的一个额外障碍。
⇒ ⇒ 由此得到一条更一般的推论，也是我们此前没有说清的：

> **代价是必要条件，不是充分条件。**
> 代价要起作用，它必须**改变选择器的排序**——
> 而 v3 的"取舍"根本没有进入一个选择器（v3 是几何读数，不存在"选谁"这一步）；
> v4/v5 虽有选择器，但它们的代价几乎没被生成（放弃仅 3/54）。

⇒ ⇒ 这一句把三代的失败**重新分成了两类**：
- **v3**：代价存在，但**没有选择器可作用于它** ⇒ 失败原因**未解释**（本文的诚实缺口）；
- **v4/v5**：选择器存在，但**代价几乎不存在** ⇒ 失败原因**较明确**（代价没被生成）。

⇒ ⇒ 我们由此得到下一步的设计要求：**必须同时具备"代价真实存在"与"选择器读得到它"**，
并让代价**真的改变排序**；否则测的仍不是驱动力。
⇒ ★ **诚实标注**：本节的 v3 数字是**事后重算**（无事前预注册）⇒ 按本文的证据标签纪律，属 **◐ 探索性**，
但它只用于**收窄一条已被否证的普遍性主张**共享根因「（」），不用于支持任何新的正面结论。

## 8 结论

我们从「让 Agent 的输出由**目的**（思想/情感）推动，而不是仅由下一个词的概率决定」这一问题出发，
做了五件事（v1–v5 架构化状态机）。

**第一，把"驱动"拆成三条通路，并给出各自的读数与地板。** 反馈通路（观测 → 状态 → 产出）成立且强分离（9.13×）；
驱动力通路（取舍内容 → 产出）需要一条**不循环**的读数才能测；**选择层通路**（状态 → 候选集合 → 选择，
v4/v5 新增）要求同池比较两个打分器，并以"候选拿不到状态内容"作为地板。

**第二，指出了一个被忽视的方法论陷阱并给出修正。** 当状态经由**代码强制**生效时，「状态变了 ⇒ 产出变了」是
**恒真命题**，不能充当驱动力证据；我们把它写成一条可迁移的检查题：**「这个读数能不能是恒真的？」**
这条检查题在 v4 上**于实验开始 5 分钟后命中**（候选提示告知了打分依据 ⇒ 打分接近恒真 ⇒ 7 条数据作废重跑），
在 v5 上则被写成了**三条机制性保障**（提示不含状态决定 / 候选不知答案 / 绑定用编号离散量）加一条自检
（随机声明的对齐分 0.335 必须远低于正确声明的 1.0）。我们进一步量化了判官读数的三种失效模式
（天花板效应、位置偏差、严格度差异），并把**位置去偏 + 一致率硬闸**作为 LLM-as-judge 成对比较的标准前置条件。

**第三，发现我们自己的负结果是读数错配的产物。** 在几何读数（实词 2/3-gram Jaccard）上，全部臂对落在
0.053–0.077 的窄带内，纯重跑地板（0.0720）高于信号；而在**对着目标直接问的判官两两比较**上，
同一批产出给出**方向相反**的分离。⇒ **在创作任务上，「状态是否驱动了产出」不能用产出之间的相似度来回答。**

**第四，把"驱动力"从一种内容改写为一个结构，从而使情感与观点统一。**
我们主张 **驱动力 = 状态 → 改变了哪一个可核验的选择 → 代价是什么**（§7.8）。情感与观点是同一类对象
（都是约束下一步动作的持久状态），因而可用**同一套取舍层读数**测量；这同时把"文中有无感情词 / 有无观点句"
这类**素材层**判据排除在外，并给出一个可证伪的**类型不变性**主张。
⚠️ 诚实边界：v1–v5 测的**全部是观点型状态**，情感型状态一次都没进过实验 ⇒ 我们的结论**不可外推到情感**。

**第五★，把三代架构的失败收敛到一个统一诊断上。** v3（状态进提示层）与 v4（状态进选择层）都失败，
v5（编号化声明 + 结构化绑定）给出了一个**方向一致但未达阈值**的微弱差距（3 胜 0 负 15 平，gap +0.088）。
我们最终定位到的根因**不在选择器，而在状态本身**：

> **18 个工作流样本、54 个决策里，只有 3 个（6%）是"放弃"。**
> 第四组的靶子是「**有立场的 Agent 必须放弃一个更优候选**」，而我们的状态构建**几乎不产生"放弃"**
> ⇒ **取舍代价这一层根本没有被生成出来** ⇒ 状态里没有代价，也就无所谓驱动力。
>
> ⚠️⚠️ **【限定，2026-10-24 补】这条统一诊断只覆盖 v4/v5，不覆盖 v3。** v3 的决策分布事后重算为
> **"放弃"占 15%（4/26）、4/9 = 44% 的样本含"放弃"**——**v3 有代价，仍然失败**
> ⇒ ⇒ **"有代价"不是充分条件** ⇒ ⇒ 代价必须**进入选择器的排序**才可能起作用
> ⇒ ⇒ **v3 的失败因此保持未解释**，这是本文留下的一个诚实缺口（§7.9）。

⇒ 与此同时，v5 量化了一个**独立于"放弃"是否常在**的量：
**候选自己声明"我要写透 X"时，只有 52.8% 真的在正文里写到了；声明"放弃 Y"时，仍有 33.3% 写了 Y。**
⇒ ⇒ **"说了取舍"不等于"做了取舍"**：产出的可核验证据不是"它声明了什么"，而是"**它实际上放弃了什么**"。
⇒ 任何以**自述**为判据的读数都不可信（这同时是我们对判官读数与自评偏差的一般性警告）。

⇒ **本文不主张**状态机已经能"驱动"Agent。本文主张的是五件更小但更牢的事：
(i) 三条通路各自的读数与地板；(ii) 一条不循环读数的必要性与可迁移的检查题；
(iii) 三种判官失效模式的量化与硬闸；(iv) 一次读数错配如何制造出一个看起来干净的负结果；
(v) ★ **一次跨代际的失败收敛：从"改进选择器"改写为"让取舍代价真实存在"**，
并给出一个可操作的下一步——**把"放弃"变成状态构建的结构性配额**（而非提示偏好），
且把判据从**声明**移到**行为**（兑现率 / 违禁率）。

⇒ 若"驱动"最终必须进入训练与采样（[Nagarajan et al., ICML 2025 oral] 从训练侧给出的结论），
那么本文的贡献就明确地是**一个定位**：它把这份责任从推理时架构指回去，
同时给出一套可以廉价复用的检验工具；并给出一条**廉价的前置检查**——
在投入训练侧改造之前，先测出推理时架构的上限：
**若连"有状态 vs 等预算自我说明"都测不出分离，训练侧改造就是必需的而非可选的。**

### A.4 复现注意事项（踩过的坑）

**★ v4 / v5 新增（全部为「看起来没问题、实际上结论会错」的坑）**：

1. **嵌套线程池 ⇒ 9 并发 ⇒ MiniMax 429 雪崩**：v5 首轮把外层样本并发（3）与内层候选并发（3）叠在一起 ⇒ 总并发 9 ⇒ 触发 Token Plan 429 ⇒ 退避 20/40/60 s ⇒ 实验慢到不可用（20 分钟只跑出 5 条）。
   ⇒ **修法**：内层候选生成改**串行**，总并发 = 外层 `workers`（≤4）。⇒ **教训：并发上限要按"全局"算，不能按"每层"算。**
2. **候选提示若告知打分依据 ⇒ 打分接近恒真**：v4 第一版提示给出了"缺口涉及的具体词" ⇒ 候选照做就能命中 ⇒ H3 失去意义。
   ⇒ **启动 5 分钟后主动终止**（不是跑完再看），7 条已落盘数据作废重跑。⇒ 这就是 §4.4 那条检查题在**跑前**命中。
3. **逐字包含把"提到但放弃"算成命中**：「这篇写甲不写丙」里"丙"逐字出现 ⇒ 被算成"写了丙" ⇒ 取舍语义根本测不出来。
   ⇒ **修法**：否定语境识别（实体前 14 字窗口含否定标记 ⇒ 计为回避）。
4. **候选声明完全相同 ⇒ 选择器无从区分**：v5 首轮三个候选的取舍声明一模一样 ⇒ 状态化打分给它们同样的分 ⇒ H3′ 不可测。
   ⇒ **修法**：提示只给"你是第几次尝试"，让候选自己差异化（**不给任何取舍信息** ⇒ 不引入状态泄漏）。
5. **打分项在"状态无该项决策"时不得当 0 惩罚**：状态三个缺口全判"深入展开"（放弃集为空）⇒ 放弃维度被当 0 ⇒ 所有候选一起被拉低、真实差异被掩盖。
   ⇒ **修法**：该项只在状态对该项**真有决策**时计入。
6. **分析脚本的臂过滤写成硬编码 ⇒ 一个臂整个漏掉**：`arm == 「WF-v4」` 漏掉了 `WF-v4-blind`（9 条）⇒ 判决会落在错的臂上。
   ⇒ **修法**：**凡要按臂分组读的数，先打 `n` 验范围**（分臂 H3 打出 `n=0` 才发现）。
7. **措辞判据的第一版有假阳性**：把"以避免加重课业负担"当成取舍声明 ⇒ **修法**：收紧后逐句人工核验（3/3 真、假阳性 0）。

| 坑 | 处置 |
|---|---|
| 重试型硬闸若写成 `any(not ok)` ⇒ 重试后**最终通过**的样本被误标失败 | 改为看**最后一次**尝试 |
| 位置参数 > 3 个 ⇒ decisions/obs 传反，报 `'list'/'str' object has no attribute 'get'` | 全用关键字或逐位注释 |
| 跨模块改函数返回个数 ⇒ `ValueError: not enough values to unpack` | 改签名必须全仓搜调用点 |
| prompt 里含 JSON 示例的花括号 ⇒ `.format()` 吃掉占位符 | 改用 `str.replace` |
| 判官 `max_tokens=200` ⇒ evidence 较长时被截断 ⇒ JSON 不可解析 | 提到 600，并**保留原始返回**便于诊断 |
| OpenRouter **403 `Key limit exceeded (total limit)`** ≠ 限流，是 key 总额度耗尽且不自动重置 | 403/429/404 必须**分类**并抛错，不得静默当"解析失败" |
| 语言闸门用"整体中文占比 ≥0.9" ⇒ **误杀**含 markdown 标记与英文术语的中文长文 | 改判"**是否存在整段非目标语言**" |
| 多题 runner 漏记 `lang_cn_ratio` ⇒ 语言闸门根本没跑 | 分析时自己算，不依赖记录字段 |

## 附录 B · 判官失效模式速查

| 失效 | 现象（本文实测） | 检测方法 | 处置 |
|---|---|---|---|
| **天花板效应** | 判官 4.20 在 D1 上把 18 篇全打 3.000 | 分数分布集中 | 改两两比较；或换更严判官 |
| **位置偏差** | 多对对比胜负"3胜3负"，位置一致率 **0.00** | **交换位置各跑一次**，算一致率 | 一致率 < 0.5 的对比**直接判不可用** |
| **严格度差异** | 4.20 方差 0.49、4.3 方差 1.86 | 同一批样本的分数分布 | 只用**题内相对排序** |
| **饱和的"无差异"** | D3 上两判官全打 4.000 | 分布无差异 | 该维度弃用，**不得**写成"两臂无差异" |
| **同源偏好** | 判官与被测同厂商 ⇒ 共享偏好 | 换跨厂商判官对照 | 同源判官只作**交叉验证**，不作主判据 |
| **额度耗尽伪装成解析失败** | 78/144 任务"解析失败"，实为 403 | 看**错误类型**而非只计数 | 分类 403/429/404 并重试或换源 |

其中「位置偏差」一项尤其关键：不做位置去偏，一个**随机作答**的判官会产出"3 胜 3 负"这类看起来像"无差异"的结论。
