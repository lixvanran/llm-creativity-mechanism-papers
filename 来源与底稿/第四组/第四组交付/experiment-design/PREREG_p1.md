## 2 · 假设与判定（写定阈值）

### H1（事实层的因果性）— 主假设

> **H1**：**C2 的 D-1 换值同步率显著高于 C0**，而 **C1 的同步率接近 0**。

- **统计**：D-1 同步率是**二值配对**指标（每配对：同步 / 不同步）。
  - 对基线 0.5：**精确二项检验（双尾）**，n = 15 配对/臂。
  - 臂间：**McNemar 配对检验**（同题同样本下 C2 vs C0 的 2×2 配对表）。
- **支持条件**：C2 同步率 **> 50%** 且 McNemar **p < 0.05**（Holm 校正后仍 < 0.05）；且 C1 同步率 **< 25%**。
- **反对条件**：C2 同步率 ≤ 50%，或 McNemar 校正后不显著。
- **机制解释**（若支持）：C2 的事实层把"档案内容 → 正文痕迹"这条通路**建立**了；
  C1 缺该层 ⇒ 通路为零 ⇒ C1 的产出**不由档案的具体事实决定**。
  这与 Phase 0 的相关层证据（§3.6：取舍压缩丢事实）构成**因果 + 相关**的双重证据。

### H2（状态锚定 vs 跟随历史）

> **H2**：**C2 的 `swap_jaccard` 显著高于 S**（越大 = 换了初稿后约束越不变 = 越锚定在状态而非历史）。

- **统计**：题内均值 → 跨题配对 t，n = 5 题，Holm 校正。
- **支持条件**：Δ(C2 − S) > 0 且 Holm 校正后 **p < 0.05**。
- **反对条件**：Δ ≤ 0，或校正后不显著。
- **诚实声明**：n = 5 题，Cohen d = 1.0 的配对 t 检验功效约 **0.62** ⇒
  **本轮只对大效应有检出力**；不显著**不能**写成"无效应"。

### H3（极性编码）

> **H3**：**C2 的对齐极性分与 C0 同号的比例 ≥ 4/5 题**（Phase 0 的 C1 是 3/5）。

- **统计**：5 题的**符号一致性**（二项分布，基线 0.5）。
- **支持条件**：≥ 4/5 题同号，且 C2 的 aligned 极性分**绝对值**高于 C0。
- **反对条件**：≤ 3/5 题同号。
- **注**：C2 的极性锚是**显式注入**的，理论上应显著强于 C1 的隐式极性；
  若仍不成立 ⇒ 说明"极性锚"这种形式**不足以**把极性带进产出，**这是关于设计形式的结论，不是关于状态的结论**。

### H4（已排除选项的抑制）— C2 独有

> **H4**：**C2 的 `excl_suppressed` > 0**（终稿里"已排除"的关键词显著少于初稿）。

- **统计**：题内配对 t（同题内，C2 自身的初稿 vs 终稿），n = 5 题。
- **支持条件**：均值 > 0 且 Holm 校正后 p < 0.05。
- **反对条件**：均值 ≤ 0。
- **为什么这条重要**：**C0 结构上无法表达**"已排除"（一次性注入没有这个概念），
  ⇒ 它是**唯一**一条"只有状态机做得到、档案全文做不到"的可测判据。
  **若 H4 也不成立 ⇒ C2 的第③条改法（§3.6.5）失败，第四组当前没有状态机独有的优势。**

## 3 · 总判决规则（写定）

| 条件 | 判决 |
|---|---|
| **H1 ∧ H2 ∧ H3 ∧ H4** | **第四组当前形态成立**：状态机在机制层面与提示词**可区分**，且优于等强度提示词对照 |
| **H1 ∧ H4**（H2/H3 不成立） | **部分成立**：事实层与可选项抑制有效（机制层），但**极性编码**与**锚定强度**未获支持 |
| **H1 ∧ ¬H4** | **仅事实层有效**：C2 只是"把事实也带进去了"，**没有**状态机独有的优势 ⇒ §3.6.5 第③条改法失败 |
| **¬H1** | **失败**：C2 的事实层也没建立因果通路 ⇒ 第五节的方向作废 |

**全部不成立时的结论模板**（预先写好，避免事后找补）：
> 「当前形态的状态机臂未能在**因果层**（D-1 换值同步）与**结构层**（D-2 置换）上与等强度提示词对照区分开。
> 失败是**可分辨的负效应**还是**无检出力**，按 F18 判定：若 ≥60% 的题上 C2 落在对照臂噪声包络内 ⇒ 写「**不可分辨**」。」

## 4 · 统计纪律（写定）

1. **分析单元 = 题**，样本 = 题内重复测量。**绝不能**把「同 prompt 跑两次」当配对。
2. 题内先算臂均值，再跨题做**配对**比较（配对单元 = 题）。
3. **Holm** 校正，α′ 按**实际对比数**算，不硬编码。
4. **F18**：≥60% 的题上被测臂落在对照臂 `min−s ~ max+s` 包络内 ⇒ 写「**不可分辨**」，
   **不得**写「无效应」。
5. **D-1 同步率**是配对二值指标 ⇒ 用 McNemar / 精确二项，**不做**独立样本比较。
6. **长度必须报告**；长度与指标的 Pearson r > 0.3 ⇒ 标注需长度校正；
   若臂间长度差不显著 ⇒ 可写"臂间比较不受长度主导"。
7. **批次**：跨批只做 D-1（配对字符串判定）；主对比只在单批内做。批次混用单元 > 0 ⇒ 相关比较作废。
