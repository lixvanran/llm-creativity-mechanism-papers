### 1.2b 规范冲突：M2 在当前 API 下**没有合规实现**（不是"技术困难"）

红队 §10「打偏 8」一针见血：

> **打偏的是"用错了"，成立的是"自相矛盾"。** —— 第四组的红线表禁用了所有"离中心距离 / 困惑度 / 典型性"类量（因为人类偏好更典型的 ⇒ 这些是**反向指标**），**而 M2 的唯一实现恰恰就是这些量**。

叠加实测事实（**无 logprobs**、**无自托管**、**OpenRouter 401**）：

| M2 的候选实现 | 依赖 | 状态 |
|---|---|---|
| typicality = base-LM logprob/token | logprobs | ❌ API 不返回 |
| NLL / perplexity / PMI | logprobs | ❌ 同上 |
| 到参考作者模型的马氏距离 | logprobs + 英文作者风格模型 | ❌ 双重不可用（中文无对应物） |
| Biber 66 维文体签名位移 | 英文工具链 | ❌ 语言不适用 **且违反 A2**（风格层不能作机制证据） |
| **取舍代价（T1-b）** | **零外部依赖** | ✅ **唯一合规实现** |

⇒ **【结论】M2 的可测形式被规范逼成了「取舍代价」**：有立场的 Agent 必须**放弃一个更优的候选**。放弃即代价，代价即驱动力存在的证据。这既躲开了反向指标陷阱，也躲开了同源判据陷阱。

## §2 修订后的方案

### 2.1 为什么 L2/L3 不可用**不是**致命伤

**【结论】** 第四组的骨架从来不是解码层干预。骨架是三件套：

| 部件 | 形式 | L1 上能否实现 |
|---|---|---|
| **状态 S** | 先于生成存在、跨步骤持久的结构化对象 | ✅ 存在 agent 进程里 |
| **驱动函数 f** | 状态 → **取舍约束**（不是内容） | ✅ 渲染进上下文 |
| **转移律 g** | 观测 → 新状态，且新状态改变后续生成的可选项集合 | ✅ 在 agent 侧更新 |

L2（解码偏置）/ L3（采样重加权）是**词层干预**，与"内容层视角过滤"**不在同一层**——ESFP 已证 δAR（词层）与 δSCD（内容层）在 P0 处解离。**这两层混用，正是 A2 那个自相矛盾的来源。**

**代价必须写明**：L1 版只能说「**agent 进程内的状态**组织生成」，**不能说「模型内部的状态」组织生成**。这不是文字游戏——在无状态自回归 LLM 上，前者可测，后者不可测（见 A1）。

### 2.2 状态 S 的结构（采纳机制设计 §4）

7 个固定字段 + 1 个主控新增字段：

| 字段 | 内容 | 作用 |
|---|---|---|
| 立场核心 | 一句话，可被反驳，**必须在本题做出取舍** | 状态的语义核心 |
| 来历 | 一个具体事件（时间/地点/一个可追问的细节） | 「可被追问来历」的机器实现 |
| 取舍约束 | **恰好 3 条「不能牺牲什么」** | **f 的输出形式**——注意是"不能牺牲"，不是"必须说什么" |
| 拒绝 | 这条立场拒绝什么、不接受什么结果 | 划出不可越过的边界 |
| 语气 | 克制的、什么程度的语气 | 语用层约束 |
| 强度封顶 | 在什么条件下会被推翻（须是本题真实可能发生的条件） | **保证可证伪**，防止不可证伪的绝对立场 |
| 锚定问题 | 这条立场能回答、而通用回答答不出的那个问题 | 让立场有可检验的着力点 |
| **自选极性**〔主控新增〕 | **只能是 pole_a 或 pole_b 二选一** | **防伪②的机器实现**，见 §3.3 |

### 2.3 驱动函数 f：输出是「取舍约束」，不是「内容」

**【结论】** f 的输出必须能通过一条**可执行判别**：

> **若把 f 的输出从上下文中移除，产出应发生"该维度上"的变化；若移除后产出不变，说明 f 只是在"复述内容"而非"约束取舍"。**
>
> 附加判别：f 的输出**不得包含任何可被直接复述进正文的句子**（禁止"我认为/我的立场是/必须做到 X"这类可复述句）。

### 2.4 转移律 g 与「留缝机制」

**【结论】** 转移律必须包含"**改口要付代价**"的三项体现，且**驱动力不得是铁律**：

- 强度封顶是硬约束（立场可被推翻，但必须说明理由）
- 强度封顶必须写明"什么条件下会被推翻"
- 约束在本题无法满足时，允许**写出有代价的折中**（而不是假装约束不存在）

**留缝机制的机器实现**：f 渲染时必须包含一条「若某条约束在本任务里无法被满足，不要假装它不存在：写出一个具体的、有代价的折中，并说明代价是什么」。

### 2.5 L1 与「更好的提示词」的可操作判别 D1–D5

**【结论】** 边界不是"状态写进了 prompt"，而是以下可执行判别。**D2 与 D5 是最锋利的两道**：

| 判别 | 内容 | 判定 |
|---|---|---|
| **D1 因果活性** | 状态是否真的改变了输出 | 状态置空/替换后产出必须变 |
| **D2 状态历史置换**〔最锋利〕 | 同一最终状态、**不同更新历史** → 输出必须不同 | 若相同 ⇒ 状态只是一张静态卡片，**没有转移律** |
| **D3 转移律执行** | 观测是否真的改了状态 | 状态字段须可观测地更新 |
| **D4 转移律特异性** | 不同的转移律是否产生不同结果 | 若不同律同结果 ⇒ 律是摆设 |
| **D5 提示词强度配平**〔与 D2 并列最锋利〕 | **L0-strong 臂**（把状态压缩成最强的一段提示词）vs 驱动臂 | 若两者无差异 ⇒ 驱动臂**退化成了 L0** |
| **D6 计划效应 vs 状态效应** | 引入 **O 臂**（只做计划、不带状态）做分离 | 效应必须住在**任务结构**侧而非激励强度侧 |

**【结论】** 三组实测（roles/incentives 只移动行为 0–2%，任务重构可到 40%）的推论是：
> **第四组的效应必须住在「任务结构」这一侧。住在「激励强度」那一侧 ⇒ 判失败。**

## §3 修订后的实验

### 3.1 判官困境：这是本轮最大的约束

**【结论】** 三组铁律：判据与被测模型同源 ⇒ 判据无效。而 ESFP 式逐句立场标注（SCD/CPC/AR/PSI）**正是靠 LLM 做的**。当前环境：

| 跨家族判官路径 | 状态 |
|---|---|
| OpenRouter（GPT/Claude/Llama） | ❌ **实测 HTTP 401 `User not found`** |
| 本地开源模型（vLLM/transformers） | ❌ **sandbox 无 GPU、2 核 3GB、未装 torch/transformers/vllm** |
| 人类评委 | ⚠️ 可行但需人力，且"有思想"的人工一致性本身很低 |
| MiniMax M2.7（同家族） | ⚠️ 降级可用，须配 family-cross 矩阵 |

⇒ **裁决：主判据必须做到「零 LLM 判官」。** 这不是将就——三组已证"人类觉得更有思想"被来源标签与流畅度双重污染，本来就不能当效标。

### 3.2 主判据 T1：「选择—拒绝对」（采纳红队）

**【结论】** 这是目前**最强**的判据，因为它直接测量"取舍代价"，绕开了"测的是组织取舍还是复述"这一刀。

**协议**：
1. 在**基线臂**采样出 K 个都合格的候选续写（K ≈ 5–8）
2. 让**带状态**的模型从中**选**一个，并**说明理由**
3. 检验两条：
   - **T1-a 反事实翻转**：换一个状态（反极性档案），选择是否系统性翻转
   - **T1-b 取舍代价**：**被选者是否在「更流畅/更贴题」上输给被拒者** ⇒ 这就是 M2 的可测形式——**有立场时选了一个"更差但更符合立场"的选项**

**T1-b 的关键**：它要求被测模型**放弃**一个更优选项。放弃即代价，代价即驱动力存在的证据。**这不需要任何判官**：流畅度/贴题度可用统计代理（长度、词频、n-gram 稀有度、基础 prompt 相似度）。

**【结论 · 主判据最终定版】** 经 experiment-design 的 v2 复核，**主判据定为 δ_state（判据 6）**：

> `δ_state^臂 = mean(emb(臂,P0))·v − mean(emb(A,P0))·v`，做符号对齐
> —— **臂间直接位移，不经由框架翻转**，因此**不依赖「锚定 vs 放大」这个未验证假设**，符号也更稳健。

预注册规则：**判据 1（符号对齐版极性位移）与判据 6（δ_state）必须同时报告；若二者方向相反，以判据 6 为准并如实标注分歧。**

**【结论 · 升级为首选主判据】** 主控探针实测发现：**文档级 embedding 的噪声地板 0.293 与信号 0.21 同量级** ⇒ 任何依赖**跨臂绝对距离**的指标（PL、SC 的跨臂比较）都不可靠。
而 **T1-b 是同一候选集内的相对比较**（被选者 vs 被拒者），**天然免疫于尺度与地板问题**。
⇒ **T1-b 从"候选之一"升为首选主判据**；PL 降级为待重做。这是本轮探针最重要的产出——**它不是靠论证选出的，是靠实测排除法选出的**。

### 3.3 主判据 T2：极性位移 PL（主控提出，条件性）

**【结论】** PL 完全不需要判官，且直接对应 M2 的"偏离结构"：

每题独立构造极性轴 `v = normalize( mean(emb(P+)) − mean(emb(P−)) )`，各臂位移 `δ_臂 = mean(emb(臂,P+))·v − mean(emb(臂,P−))·v`。

**两处防伪（缺一即产生假阳性）**：
- **防伪①**：C 臂的立场档案生成**不得看到 `pp` 里的 P+/P− 极性陈述**。否则测的是"档案里的极性被复述到输出"。
- **防伪②**：C 臂的极性是**模型自选**的 ⇒ 必须按 `self_polarity` 做**符号对齐**（`δ_C^aligned = δ_C × (±1)`），对齐后 δ 才是"沿它自己选的方向的位移强度"。

**【结论 · 探针实测】PL 判据在当前实现下不成立，暂缓。**
主控亲跑探针（T01，6 次基线重复 + 4×2 极性重复 + embo-01 文档级 embedding）：

| 量 | 实测 | 判读 |
|---|---|---|
| 噪声地板（A 臂同输入独立采样的平均两两距离） | **0.2930** | 文档级 embedding 的分辨率极低 |
| δ_A（**纯提示**造成的极性位移） | 0.2118，**SNR = 0.72** | **连提示造成的极性位移都测不出来** |
| δ_C 对齐后 | 无效 | `self_polarity` 解析失败（探针 bug，见 §P2 U8） |
| 塌缩度 SC | A = 0.2930，**C = 0.1080（C/A = 0.37）** | **C 臂产出比 A 臂更同质**（与预期相反） |

⇒ **PL 降级为条件判据**，当前**不得作为主判据**。

**【结论 · 终局：PL 出局，不再是"待重做"】**
mechanism-design 用**句级集合距离**（不池化，绕开文档级饱和）重测 T01：

| 量 | 值 |
|---|---|
| 文档级余弦（A 臂内 / 跨臂） | 0.8306 / 0.8870（**不是 mech-study 说的 0.991** ⇒ 文档级是"高度饱和"而非"无分辨率"） |
| 句级集合距离 · 臂内 A | **0.3896** |
| 句级集合距离 · 臂间 A vs C | **0.3569** |
| **SEP（臂间 − 臂内）** | **0.00206** |
| 锚定命中 | A 0.855 vs C 0.888（区间完全重叠，Δ=0.0335） |

⇒ **连"最强的提示词干预"（A vs 档案提示词臂）都测不出几何分离。**
⇒ **PL 出局是终局，不是"等句级重做"。** 主文档原写的"PL 需在句级集合距离上重做后再定"**在此更正**。
⚠️ **但这个探针本身有边界**（它自己也标了）：n=1 题 / 8 篇 / 无极性对 / 未估 σ_d,true ⇒ **这是"排除一条路线"的下界探针，不是效应量估计**。它排除的是「几何距离类指标」，**没有**排除「离散结构量类指标」。

**【已撤回】** 原规划用"到参考作者模型的马氏距离"作 DEV 指标——该法需要英文作者风格模型，中文创作任务无对应物，**且依赖 logprobs 类参照系**，双重不可用。

### 3.4-2 ★ 主判据定版：离散结构量（终版）

三路独立收敛到同一个结论（mechanism v2 的句级探针 / 主控的文档级探针 / 红队的 M2 重写）⇒ **几何距离类指标退出，主判据换成离散结构量**。

| 判据 | 定义 | 依赖 | 角色 |
|---|---|---|---|
| **D-1 · CKF 痕迹 + 追问一致性** | 档案里放一个**可核数字/专名** → 正文是否留下痕迹 → 追问是否一致 → **换值后痕迹是否同步变** | 零判官、零尺度依赖、**二值可数** | **主判据**（须报 C1 vs C0） |
| **D-2 · 计划层结构** | 计划层**槽位的保留 / 省略 / 顺序** | 零判官 | **主判据** |
| **D-3 · 约束关键词命中** | 「取舍约束」中 3 条"不能牺牲"的关键概念是否在产出中命中 | 零判官 | **主判据**（排除复述后仍成立才算） |
| **D-4 · 分布层** | 极性位移 / 塌缩度 | embo-01 | **条件判据**（实测无分辨率：SEP≈0.002） |
| **F18 · 噪声包络** | ≥60% 的题上 C1 的题内均值落在 A 臂该题 `min−s ~ max+s` 包络内 | 零判官 | **必报**：写「不可分辨」而非「无效应」 |

**【结论 · 成功标准（无判官版，主控采纳 mechanism v2 并加严）】**

> **成功 ⇔**
> ① C1 相对 **A / S / B / C0 / O / R0 / R1** 全部显著（**Holm 校正**，α′ 按实际对比数算）；
> ② **计划层 / 文本层 / 分布层三层同向**（若校准显示分布层无分辨率 ⇒ 降为两层，**并如实写明**）；
> ③ 方向**可由状态内容预测**；
> ④ 在**极性翻转 / 事实换值 / 历史置换**三类反事实下，**按预测方向同步变化**；
> ⑤ **ST 风格臂不产生同向证据**（反例层）。
> **「人类觉得更有思想」不作为成功标准的任何部分。**

**为什么这样写不算降级**：机制性命题的真值条件是关于**原因与结构**的，用"是否更有思想"当判据是**换构念**，不是降级。
**但无判官方案的真风险是「量到了自己管线的账本」** ⇒ 必须有**从中间态到文本的传导链**（CKF 痕迹 + 锚定命中），且必须有**反例层**（O / ST），否则成功标准不可证伪。

**【结论 · 判据分层的依赖**】D-1/D-2/D-3 **全部零判官**；D-4 条件判据；ESFP 式逐句标注（SCD/CPC/AR/PSI）、PDS、精确版 ERR-DIR、人类盲评 **本轮不做或降级**；人类盲评只作**校准锚点**（建议最小版 240 次，**与主线并行、不阻塞**）。OpenRouter 若恢复，**建议只补 CPC/AR 一条**（不必全开）。

### 3.4-3 ★ 判据的实现版与实测修正（2026-10-20 下午，**本节内容全部来自实际跑通**）

§3.4-2 是**定版时的设计**。把判据真正写成代码、跑通管线、做完判据自检之后，
**三处定义必须改**，否则测出来的是别的东西。实现见
`experiment-design/metrics2.py`（判据 + 自检）与 `experiment-design/runner2.py`（管线）。

| 判据 | §3.4-2 的设计 | **实现版（实测修正后）** | 为什么必须改 |
|---|---|---|---|
| **D-1 CKF** | 档案放可核数字/专名 → 正文留痕 → 换值后痕迹同步变 | 锚点**检测键** = 从锚点串里抽出的数字/字母数字串（默认取全部 `2048` 这类 token），**不是整句** | 注入档案用整句（"她在省城省立医院看病时的病历编号是 2048"），但正文只会写 "2048"。用整句去正文里找 ⇒ **命中率恒为 0 且被误读成"锚点没落地"**（v1 冒烟实测踩中） |
| **D-2 计划层** | 计划层**槽位的保留 / 省略 / 顺序** | **状态历史置换探针**：同一状态 S₀、同一题，只把 g 步看到的**初稿**换成另一个样本的初稿，重跑 g 步，看约束②是否改变 | 原写法算的是「约束①（f 步产物）vs 约束②（g 步产物）的 jaccard」。**这两个本来就是不同步骤的输出，jaccard 低是平凡的**，测不出任何东西。必须换成**因果对照**：g 步输入只有 {S₀, 题面, 初稿}，置换后差异**只可能**来自初稿 |
| **D-3 约束命中** | 3 条"不能牺牲"的关键概念是否命中 | **双向覆盖率**：`cov_archive` = 档案有多少进了正文（**对长度不敏感**，主读数）；`cov_text` = 正文有多少来自档案（长度敏感，辅读数） | v1 冒烟实测：len 与 `cov_text` 的 Pearson r = **−0.82**，与关键词命中率 r = **−0.99** ⇒ 臂间差异可能**全是长度效应**。`cov_archive` 分母是档案（固定）⇒ 不受长度污染 |

**【结论 · 判据自检必须先过】**（三组铁律「检查器必须先证明自己能抓到东西」的具体实现）

`metrics2.py` 每个判据配**阳性 / 阴性**用例，自检 **9/9 全通过** 才允许跑数据：

| 用例 | 期望 | 实测 |
|---|---|---|
| D-3 覆盖率判别力（`cov_archive`） | 阳性 ≫ 阴性 | pos 0.2360 / neg 0.0000 |
| D-3 覆盖率判别力（`cov_text`） | 阳性 ≫ 阴性 | pos 0.7778 / neg 0.0000 |
| D-3 关键词判别力 | 阳性 > 阴性 | pos 0.10 / neg 0.00 |
| D-3 干扰项（拒绝项不得误命中） | 拒绝命中 ≤ 约束命中 | 通过 |
| D-1 换值同步（阳性） | 新值在、旧值不在、原版不含新值 | 通过 |
| D-1 未同步（阴性） | 不得误判为同步 | 通过 |
| D-1 同义写法（"2048 年" vs "2048年"） | 空格差异不影响判定 | 通过 |
| D-2 置换（阳性） | 不同历史 ⇒ 约束改变 | Jaccard 0.1471 |
| D-2 置换（阴性） | 相同历史 ⇒ 约束不变 | Jaccard 1.0 |

### 3.4 辅助判据 T3 / 地板校准 T4

| 判据 | 定义 | 角色 | 依赖 |
|---|---|---|---|
| **T3-a 约束关键词命中率** | 预注册的取舍约束关键词命中率（排除直接复述句） | 辅助 | 纯统计 |
| **T3-b 取舍签名** | 中文功能词/句法分布 20–40 维 | **诊断，不得作机制证据**（A2） | 纯统计 |
| **T4 塌缩度 SC** | 同臂同题 N 次采样的平均两两 embedding 距离 | **地板校准** | embo-01 |
| **LEN 长度** | 字符数/句数 | **必配报**（混淆控制） | 纯统计 |
| **RARE / LEX / FREQ** | n-gram 稀有度 / MTLD / 词频偏移 | 诊断 | 纯统计 |

**【结论】** 核心判据形式（可执行 if-then）：

```
判据 1（主·T1-b）：C 臂被选候选在「流畅度/贴题度」代理上 显著差于 被拒候选
判据 2（主·T1-a）：状态反事实翻转时，C 臂选择系统性翻转；R1 臂不翻转
判据 3（PL，【暂缓】）：δ_C^aligned > δ_A，且 δ_C^aligned > δ_R1^aligned
                  —— ⚠️ 探针实测 SNR=0.72，当前实现不成立；须在【句级集合距离】上重做后才可启用
判据 4（辅助）：C 臂取舍关键词命中率显著高于 A 臂
判据 5（模板检测，【方向已修正】）：SC(C) ≫ SC(A-2stage) ⇒ C 是模板化复现（判负）
                  ⚠️ 原写法「SC(C) > SC(A)」是【错的】——实测 C=0.108 < A=0.293。
                  真实机制：档案固定 ⇒ 同立场下产出收敛 ⇒ C 天然更同质。
                  ⇒ SC 【只用于检测模板化】，不得用作「个体更有个性」的证据；
                     跨臂比较必须先扣除管线深度（SC(C) − SC(A) vs SC(A) − SC(A-2stage)）
判据 6（负结果）：若 δ_C^aligned ≈ δ_A ⇒ 判定「状态未组织取舍」
                  —— 无论 C 臂文本读起来多有思想，照记负结果
判据 7（R 臂有效性）：R1 与 C 的差异必须显著大于 R1 与 A 的差异
                  —— 若 R1 ≈ A，说明 R1 太弱（立场未被使用），该题作废
```

### 3.4c 实验学结论（主控探针实测产出）

> **【结论】文档级 embedding 的分辨率不足以支撑跨臂绝对距离比较。**
> 地板 0.2930 与信号 0.2118 同量级（SNR = 0.72 < 1）。这不是本组的偶然，而是 embedding 池化后的固有饱和。
> ⇒ **指标分类必须按"是否依赖跨臂绝对尺度"重排**：

| 类型 | 指标 | 是否受影响 | 处置 |
|---|---|---|---|
| **配对/相对比较型** | **T1-b 取舍代价**、T1-a 反事实翻转、判据 7（C vs R1） | ❌ 不受影响（同一集合内比较） | **首选** |
| **跨臂绝对距离型** | PL 极性位移、SC 跨臂比较 | ✅ **严重受影响** | 降级为诊断；PL 需**句级集合距离**重做后再定 |
| **纯计数型** | 关键词命中率、长度、词频偏移 | ❌ 不受影响（无嵌入） | 保留为辅助 |

**这一条同时回答了红队对《测量方案裁决》的攻击**（"PL 到底在测什么"）：PL 没能通过自己的检出力检验，**裁决中把 PL 列为并列主判据是错的**，现已修正为 T1-b 首选、PL 待重做。

**判据 5 的方向也被实测推翻**：原写「SC(C) > SC(A) ⇒ C 不是模板化复现」，实测 **SC(C)=0.108 < SC(A)=0.293**。真实机制是**档案固定 ⇒ 同立场下产出收敛**。⇒ SC 只能用于**检测模板化**（SC(C) ≫ SC(A-2stage) ⇒ 判负），**不得用作「个体更有个性」的证据**。

⚠️ **这同时意味着「个体↔集体双轴」在当前数据下无法支持「个体更有个性」这一侧**：C 臂集体更同质，而个体侧无正向证据。**按三组共识「个体与集体反向 ⇒ 判负」，本轮对 C 臂的个体轴预期应下调。**

### 3.4d ★ 第二次试点（C-echo 臂 + 噪声地板）：**混合信号，不足以判定生死**

主控亲跑 `/workspace/g4_cecho_pilot.py`（T01；A / C 状态 / C-echo 回声三臂，每臂 N=4，temp=1.0）：

| 量 | 值 | 读法 |
|---|---|---|
| d(A,C) | **0.0113（最小）** | C 臂（真状态）与基线**最像** |
| d(A,E) | 0.0486 | C-echo（必须覆盖素材）偏离最大 |
| d(C,E) | 0.0466 | C 与 E **可区分** |
| SC | A=0.0758 / C=0.0977 / **E=0.1894** | E 最分散（覆盖方式各异） |
| 约束关键词命中率 | 全 0，**关键词列表为空** | **抽取失败 ⇒ 该指标本次无效** |

**两条必须说清楚的读法边界**：
1. **d(A,C) 最小 ≠ 状态没起作用。** C 臂的 system prompt 明确要求「不要在正文里复述上面任何一条，也不要出现『我的立场是』」——**压制立场表达本就会把产出拉近基线**；而 E 臂被要求"必须覆盖素材"，天然更远。⇒ **整体 embedding 距离是粗指标，测不到取舍层**，本次试点**没有测到该测的东西**。
2. **但有一条硬证据成立**：同题同臂的 SC，**这一轮 A=0.0758，上一轮 A=0.2930，差 3.9 倍** ⇒ **embedding 绝对距离的地板跨批次极不稳定**。⇒ 与 §3.4c 合并可得最终结论：

> **【结论】embedding 的绝对距离（无论跨臂还是跨批）都不可用。第四组的判据必须全部是「同一批次内的配对/相对比较」。**
> ⇒ T1-b 再次成为首选（它天然是同批候选内的相对比较）。
> ⇒ **T1-b 必须放弃"跨批比较"，在单次实验内一次性跑完所有臂。**

**T02 补跑后的完整两题结果**：

| 题 | d(A,C) | d(A,E) | d(C,E) | SC A | SC C | SC E |
|---|---|---|---|---|---|---|
| T01 | **0.0113** | 0.0486 | 0.0466 | 0.0758 | 0.0977 | 0.1894 |
| T02 | **0.0028** | 0.0031 | 0.0044 | 0.0127 | 0.0208 | 0.0135 |

**两个跨批/跨题的量级崩坏**（同一批、同一臂、同一题）：
- 跨题：T01 的 d ≈ 0.011–0.049，SC ≈ 0.076–0.189；T02 的 d ≈ 0.003–0.004，SC ≈ 0.013–0.021 ⇒ **差约一个数量级**
- 跨批：同题 T01 的 A 臂 SC 在两次运行中为 0.2930 与 0.0758 ⇒ **差 3.9 倍**

**但组间相对排序两题完全一致**：
> T01: **d(A,C) 最小** < d(A,E) < d(C,E)　｜　T02: **d(A,C) 最小** < d(A,E) < d(C,E)

⇒ **【结论 · 方法学铁律】**
> **embedding 绝对距离的量级由题目内容主导（跨题差 10 倍、跨批差 3.9 倍）⇒ 任何绝对距离阈值都无意义。可用的只有「同一批次内的组间相对排序」。**
> 而**相对排序也不足以定案**：「d(A,C) 最小」有两种读法——(i) 状态让取舍自然化、不显形于文本（乐观）；(ii) 状态**压制了**立场表达、因此内容层毫无痕迹（悲观）。C 臂的 system prompt 明确禁止复述立场与「我认为」这类声明，**乐观与悲观都会产生同样的距离**。
> ⇒ **必须用内容层指标交叉验证**（取舍关键词命中 / 取舍结构 / 方向性），否则整体语义距离**在原理上就分不开这两种情况**。

**本次试点未能给出生死判决**，原因有三：① 约束关键词抽取失败（关键词列表为空 ⇒ T3-a 本次无效）② 只跑 2 题、3 臂、每臂 4 采样，远低于 §3.5b 的检出力要求 ③ 整体语义距离**在原理上**测不到取舍层。**不得据此宣称第四组成立或不成立。**

**⇒ 下一步的判据必须是 T1-b**（同一批候选内的相对选择，**不依赖任何跨批绝对量**），且必须**单批一次跑完所有臂**。

### 3.4e ★ 主控补充：几何指标与「组织取舍」机制**错配**（探针数据里藏着这条）

把上面两组数字并排看：

| | 句级集合距离 |
|---|---|
| **臂内**（A 臂彼此） | **0.3896** |
| **臂间**（A 臂 vs C 臂） | **0.3569** |

⇒ **臂间距离比臂内距离还小。** 表面读数是"状态臂没有产生分离"，但真实机制是**更根本的**：

> **「状态组织取舍」在几何上的表现是"产出收窄到某个子空间"，而"收窄"表现为臂内距离变小；臂间距离衡量的是"整体位置有没有分开"，两者不是一回事。**
> ⇒ **用臂间几何距离去测"状态有没有组织取舍"，是指标与机制错配。** 无论 C 臂是"有效收窄"还是"模板化收窄"，臂间距离都给不出答案。
> ⇒ **这解释了为什么离散结构量才是对的方向**：它们测的是「**内容里有什么**」（可数、可匹配：CKF 数字/专名是否出现、计划层槽位是否被省略、约束关键词是否命中、追问是否一致），而不是「**内容在哪里**」（连续距离，受饱和与尺度支配）。

**【结论】** ⇒ 主判据换成**离散结构量**（与 mechanism-design v2 独立收敛）。但必须加一条**主控的硬约束**（见 §3.4f）。

### 3.4f ★ 主控的硬约束：所有离散结构量判据**必须与 C0 臂对比**

**CKF（可核事实守恒）单独用不成立。** 它的机制是"档案里放一个可核数字/专名 → 追问 → 正文痕迹 → **换值后痕迹必须同步变**"。
看着很强，但——

> **一个精心设计的提示词也能做到。** C0 臂（档案塞进 system prompt）里若写着"请务必提到 2048"，换值后模型同样会提到新值。
> ⇒ **CKF 只证明「状态被使用」，不证明「状态机 ≠ 提示词」。**

⇒ **【结论】C1 vs C0 才是第四组的核心对比。** 每一个离散结构量判据，都必须报 **C1 vs C0** 的差值；只有 C1 显著优于 C0，才支持"状态机"主张。
⇒ **反过来说**：若 C1 ≈ C0，**第四组当前的形态就死了**——不是"状态无效"，而是"**一个等强度的提示词就能复现全部效应**"（这正是 D5 要抓的东西）。

### 3.5 臂设计（修订后）

| 臂 | 定义 | 作用 |
|---|---|---|
| **A** | 直接调用（+ 长度配平的写作工艺说明） | 基线 + 塌缩地板 |
| **S** ★ | **等强度中性简报**：system 段与 C0 **token 等长**，内容为中性写作工艺说明、**无立场** | **H0 所说的「上下文强度」基准**——现臂清单里没有一条臂控制它。**三方独立收敛**（mechanism S / 红队 N2 / experiment N2） |
| **B** | role 标签（弱对照，故意弱） | 测「标签 vs 档案」 |
| **C0** ★ | **现 C 臂改名**：立场档案**一次性**进 system prompt | **等强度提示词对照 = D5**。⚠️ **它就是 L0**——第四组至今测的是它，不是状态机 |
| **C1** ★ | **真状态机臂**：agent 侧**权威状态副本** + 分步生成 + 每步 `f(state)→本步取舍约束` + **可观测中间态** | **主力。★ C1 vs C0 是第四组的核心对比** |
| **O** | 只做计划、不带状态 | 分离计划效应与状态效应（D6）；**反例层**，防止"量到了自己管线的账本" |
| **R0** ★ | **无关立场**（不同域）+ **强制采用** | H0 武器之一。**必须强制采用**，否则"立场被忽略"会被误读成"状态无效" |
| **R1** ★ | **同题立场** + **强制采用**（与 R0 极性相反） | H0 武器之二。**R1 必须与 C0 强度相当、仅立场来源不同** |
| **C-echo** | 与 C0 用**同一份档案**，但指令改为「这些是**必覆盖的素材**」 | 区分「组织取舍」与「复述档案」 |

**【结论 · F2 必须改双边】** 原 F2（C1 vs R2 单边）会让「R 越没用越成功」。改为：

> **C1 必须相对 A / S / B / C0 / O / R0 / R1 中的每一个都显著**，才判成功。
> 且 **R2（现有「同域异题」臂）不是 H0 武器**——它是**迁移性对照**，要另标用途。

**【结论 · 判官依赖分层的不对称】** 离散结构量判据（D-1/D-2/D-3）**全部零判官**；分布层（D-4）因无分辨率降为条件判据；ESFP 式逐句标注 / PDS / 精确版 ERR-DIR / 人类盲评 **本轮不做或降级**。

**【结论】** 记忆与长程架构的注入位置：**状态放在 system 之后的持久段，并在多步生成中保持同一份**（跨步骤持久 = M1 的可测形式）。

### 3.5a ★ C1 状态机臂的实现定版（**已跑通**，2026-10-20）

实现文件：`experiment-design/runner2.py`（**不修改** `runner.py` 一个字节，改为 `import runner as R` 复用全部基础件）。

**四步管线**：

| 步 | 做什么 | 模型看到什么 | agent 侧留下什么 |
|---|---|---|---|
| 1 | `f(S₀) → 约束₁` | 档案全文 + 题面 | 约束₁（3 条，叙述性） |
| 2 | 写初稿 `O₁` | 题面 + **约束₁**（**不含档案原文**） | `O₁` |
| 3 | `g(S₀, O₁) → 未落地 / 约束₂ / 可核事实` | 档案全文 + 题面 + `O₁` | `S₁` 的三个产物 |
| 4 | 写终稿 `O₂` | 题面 + `O₁` + **约束₂** | `O₂`（被测文本） |

**【结论 · C1 与 C0 的真区别不在「有没有状态」，而在「状态在步骤之间转移、且转移依赖观测」】**

> C0：档案 9 字段**全文**一次性进 system prompt，模型自己决定怎么用 ⇒ **状态在上下文里，没有转移**。
> C1：`S₁ ≠ S₀`，且 `S₁` 依赖 `O₁` ⇒ **状态历史置换因此可测**（这正是 D-2 的因果对照）。
>
> v1 冒烟实测：约束① 与 约束② 的 Jaccard = **0.0461**、identical=False、无 fallback
> ⇒ **状态转移确实发生了**（约束② 从"怎么写"变成了"必须回避/披露/不得用个人经历"）。

**★ 防伪断言（运行时强制）**：写作步的 prompt 里**不得出现档案字段标签**（`【立场核心】` 等）或状态块标记。
一旦这条断言失效，C1 就退化成了 C0，整个实验作废。实现里是 `assert_no_state_leak()`。

**★ S 臂必须与 C1 等调用数**：multi-mind v0.8 明确记着「成本-收益比（本轮固定 1:6~7 调用比，**未做等成本对比**）」。
C1 是 4 步 ⇒ **S 也必须是 4 步**（同样的 f→写→g→写，同样的 max_tokens），否则 C1 vs C0 的任何差异都无法排除
"只是多调了 3 次模型"这个解释。S 的"状态"是一份**等长的中性简报**（无立场）。

**★ 借 multi-mind v0.8 的强先验（这是本次借用最有价值的一条）**

multi-mind 的 v0.8 交付文档记录了实测：

| | T1 高考 | T2 骑行 | T3 作业 | T4 气质表 | 合计 |
|---|---|---|---|---|---|
| A 直调（1 次调用） | 1.0 | 2.0 | **2.0**→3.0 | 1.0 | **16** |
| B 旧工作流（7 次） | 0.5 | 0.5 | 0.5 | 0.0 | **3** |
| D 体裁自适应（6 次） | 0.0 | 0.0 | **3.0** | 1.0 | **8** |

（可核验事实条目命中数；T3 的 A 值随轮次在 2.0–3.0 间浮动）

> 「工作流的『生成 + 对抗 + 递进约束』结构，会强迫模型产出一个比原始输入更『高级』的叙事 ——
> 于是它把用户的问题降格成了一个待分析的对象。」
> 根因在 **N2 的 schema**（强制每个候选给出「综合价值 = 收益 − 技术代价 − 合规代价 − 不可逆代价 − 声誉代价」），
> 不是 N3。这类 refinement 型链路「适合决策题，**对分析/创作/指导题是灾难**」。

**⇒ 这条先验直接改写了 C1 的三条设计约束**：

1. `f` / `g` 的输出**必须是叙述性自然语言**，**禁止**评分表 / 对比表 / 编号字段 / 任何 schema
   ⇒ 已写进 `F_PROMPT` / `G_PROMPT` 的硬性要求。
2. C1 是 **generation 型**（展开）而不是 **refinement 型**（收敛）——`g` 步只做"指出未落地 + 给出下一轮约束"，不评分、不排序。
3. C1 必须加**体裁守恒门**与**对象守恒门**（产出必须仍以题面主体为对象），否则 C1 会把创作题降格成决策文档。

**【结论 · 第四组的问题因此更锐利】**

> 原问题：「状态机能否让内容更好」——**已被 multi-mind 的数据部分预答**：多步 refinement 链路在创作类题目上大概率**负增益**。
> 新问题：**状态机能否在多步管线里「保住」内容层——而不像通用工作流那样把体裁换掉？**
> **负增益是一个合法结局，必须能如实报出。** 第四组不能只准备"成功"的解释。

### 3.5b ★ 检出力：10 道题**功效不足 2–4 倍**（红队给出公式，主控采信）

**【结论】** 这是本轮被低估的硬约束。差异量 Δ 的方差近似：

```
Var(Δ) ≈ 4σ_w²/N + 2τ²
n（需要的题数） ≥ 7.85 · (4σ_w²/N + 2τ²) / Δ²
```

其中 `σ_w` = 采样间噪声标准差，`τ` = 题间方差分量，N = 每臂每题采样数。

代入示例（σ_w = 0.10、τ = 0.05、Δ = 0.05）：

| N（每臂每题采样） | 需要的**题数** n |
|---|---|
| 5 | **41** |
| 10 | **28** |
| → ∞ | **16**（地板） |

⇒ **当前 10 道题比所需功效不足 2–4 倍。** 且关键提醒：
> **应该买的是「题数」，不是「采样数」。** 加采样数 N 的边际收益远低于加题数——因为 N→∞ 也只能把 n 压到 16，**永远到不了 10**。

**【结论 · σ_w 已实测】** experiment-design 的最小 pilot（T01，13 次生成）给出：

| σ 估计 | 值 | 说明 |
|---|---|---|
| 各组 sd 的均方根 | **0.0482** | 中位/乐观估计，**用于定 N** |
| 各组 sd 的最大值 | **0.1474** | **保守端**（每组只有 2 个样本 ⇒ σ 本身估得很不稳） |

代入检出力表（Δ = 期望效应量，题数 n）：

| σ | N | Δ=0.02 | Δ=0.05 | Δ=0.10 |
|---|---|---|---|---|
| 0.0482 | 5 | >20（不可行） | **6** | 2 |
| 0.0482 | 10 | **10** | 2 | — |
| 0.1474 | 5 | — | >20（不可行） | 15 |
| 0.1474 | 10 | >20（不可行） | 15 | **4** |

⇒ **Phase 0 判定版取 N=6**：σ=0.0482、Δ=0.05 时需 **6 题**；保守端 σ=0.1474 时需 **15 题**。
⇒ **成本**：Phase 0 判定版 **100 次调用 ≈ ¥1.25**（五折）；Phase 1（10 题 × 5 臂 × N=5 = 580 次）**≈ ¥7.38**。
⇒ **迭代闭环（重要）**：σ 的估计只有每组 2 个样本，**本身很不稳**。⇒ **Phase 0 判定版跑完后，必须用它自己的真实数据重估 σ_w，再据此定 Phase 1 的 N 与题数**，而不是沿用 0.0482/0.1474。

**⇒ 处置更新**：① Phase 0 判定版 **N=6、6–15 题**（视重估后的 σ）② **σ_w 必须在 Phase 0 后重估** ③ 题数下限从"10 题"改为"**按 σ 重估后决定**"。

**【结论 · 主控裁决：题数不预设 24，现在定是错的】**
mechanism-design v2 给出**更严谨**的公式（把**题内相关 r** 显式建模，红队公式假设了独立）：

```
σ_d(k) = σ_d,true · √(1 + 2r²/k)
n ≈ 13.3 · (σ_d(k) / Δ)²        （α′ = 0.0042, power = .8）
```
代入 r=2：k=5→35 题、k=8→26 题、**k=12→21 题、k=16→19 题**。
⇒ 它建议：**主检验放计划层（k=12–16，输出便宜）、文本层 k=6 只做传导检查、题数下限 24**。

**主控的裁决：不采纳「24」这个数现在定死，理由三条**：
1. **r 从未测过**。上面的表全部建立在 r=2 这个**假设值**上，v2 自己也写了「现在还是纸面推演」。
2. **两套公式给不出同一个答案**：红队公式（σ_w=0.0482, N=6, Δ=0.05）⇒ **6 题**；mechanism 公式（α′=0.0042, r=2, k=12）⇒ **21 题**。差异来自 ① α′ 不同（0.05 vs 0.0042）② σ 的定义不同（臂内噪声 vs 配对差的 sd，含题内相关）③ **r 未知**。
3. ⇒ **正确的做法是让 Phase 0 判定版同时校准 `σ_d,true` 与 `r`**，再按实测值重算 Phase 1 题数，并**取两套公式的保守上界**。

**⇒ Phase 0 判定版的定版参数**：**现有 10 题 · N=6 · 校准 σ_d,true 与 r · 成本 ≈¥1.25**。它同时是"判成败"的一档和"量参数"的一档。

**【结论 · 必报双轨数字】** ① **分析单元 = 题**（独立重复单元），样本 = **题内重复测量**；**绝不能**把「同 prompt 跑两次」当配对（那是 A10 那个非确定性在骗人）。② α′ 按**实际配对对比数**算（Holm），**不硬编码 0.0042**。

**【结论 · F18：必须区分「无效应」与「无检出力」】**
> 若 **≥60% 的题**上，C1 的题内均值落在 **A 臂该题采样的 `min−s ~ max+s` 噪声包络**内 ⇒ 一律写「**不可分辨**」，**不得写「无效应」**。
> 这是「数据对、显示骗人」第 4 条（空输出被当成有效数据）在效应量层面的同族错误。

**【结论 · 判负 if-then】** 分布层不显著 **且** Holm 后各配对对比无一显著 ⇒ 判负，**并按分支改写措辞**：
- C1−O 不显著 ⇒ 「效应来自提纲，不是状态」
- C1−R0 不显著 ⇒ 「效应不来自立场相关内容」
- C1−C0 不显著 ⇒ 「**等强度提示词即可复现全部效应 ⇒ 当前形态死**」

**【结论 · 塌缩度 SC 必须改定义】** 主控的 SC 定义在**整段 embedding** 上，而文档级实测饱和 0.83 ⇒ **必须改句级集合距离**（不池化）。

**⇒ 红队与主控独立得出同一条第一步建议：先花 1 小时、¥3–5 做「C-echo 臂 + 噪声地板试点」，再决定是否展开 Phase 0/1。**

#### 3.6.2 ★ 三条裁决

**① 效应是真的，但归因是「取舍压缩」，不是「状态组织了取舍」**

> **C1 显著优于 S（等调用数、同 4 步管线的中性状态）** ⇒ 差异**不是**"多调了 3 次模型"造成的。
> **但 C1 显著劣于 C0（档案全文注入），且与 R1（同题·反极性·档案全文注入）不可区分。**
>
> ⇒ 把这三件事放在一起，唯一自洽的解释是：
> **C1 的可测效应来自"把档案压缩成 3 条取舍"**（压缩 ⇒ 落进正文的内容变少 ⇒ coverage 下降；
> 但压缩后的取舍**带不走事实**，也**带不走极性指向**）。
> **它不来自"状态组织了取舍"**——因为若真如此，C1 应当与 R1（同样有立场、同样 4 步）**可区分**。

**② D-2 置换探针：机制层面支持状态机，但与 R1 无差别**

> 置换敏感度（`swap_jaccard` 越大 = 换了初稿后约束**越不变** = **越锚定在状态而非历史**）：
> **C1 0.0414 > S 0.0176 > R1 0.0196**
>
> ⇒ **S 臂（中性状态）没有可锚定的东西，g 步只能跟着初稿走**（jaccard 最低）；
> **C1 有状态可锚定，g 步对初稿的依赖显著降低**（方向与"状态组织取舍"一致，p_raw=0.0328）。
> **但**：① Holm 校正后 p_adj=0.0656（n=5 题功效不足）⇒ 只能写"**方向与预期一致**"；
> ② **C1 与 R1 在这一维度同样不可区分** ⇒ **"锚定在状态上"这个能力，档案全文注入同样具备**，
> 不是状态机独有的。
>
> ★ 这也再次说明：**D-2 的方向必须读对**——`jaccard` 越小是"越敏感"，
> 而我们要的假设是"**状态让输出对历史不敏感**"⇒ **越大越好**。第一版差点把它读反。

| 成功标准 | 实测 | 判定 |

>

> 且这个差异**不能**用"调用次数更多"解释。**D-2 置换探针**进一步指向正确的机制方向
> （C1 的 g 步比 S 更锚定在状态而非初稿历史）。
>
> **② 不成立的部分**：C1 **显著劣于** C0（档案全文注入），且**与 R1 不可区分**。
> ⇒ **当前形态的 C1 尚未证明「状态机 ≠ 提示词」**。
> ⇒ 更准确的说法是：**"取舍约束式驱动"这个形态，其效应等于"把档案压缩过一遍"，
> 换不来"状态组织取舍"独有的东西。**
>
> **③ 因此下一步不是"再调参"，是改架构**（见 §3.6.5）。

#### 3.6.5 ⇒ 下一代 **C2** 的三条改法（由本次数据直接推出）

| # | 问题 | 改法 |
|---|---|---|
| **1** | 取舍压缩**丢事实**（C1 覆盖率显著低于 C0） | 状态**分两层**：`S = {取舍层, 事实层}`。`f` 步分别渲染 ⇒ 写作步同时拿到**取舍约束**（决定写什么）与**可核事实**（决定写什么时用什么具体细节） |

### 3.7 ★ C2 的工程实现与首轮验证（状态双层 + 极性锚 + 已排除选项）

§3.6.5 的三条改法已全部实现（`experiment-design/runner2.py`，臂名 **C2**），步数与调用数与 C1 完全相同（4 步）⇒ 与 C0/C1/S 直接可比、成本不变。

| C2 的三处改动 | 实现 | 防伪 |

| **① 事实层** | `f` 步输出多一段【事实提示】（2 条，**原样照抄**档案「来历」「强度封顶」里的具体事实），写作步注入 | 事实必须原样照抄 ⇒ 不能编 |

## P4 冒烟实测（T01 × 1 样本 × 5 臂 = 14 次调用，**这是过程，不是结论**）

> ⚠️ **n=1、单题、单样本。以下全部是过程性观察，任何一条都不构成结论。**
> 它唯一的作用是：**在花 ¥12 跑完整 Phase 0 之前，先确认管线跑得通、判据测得对。**

**跑出来的数据：**

| 臂 | 长度 | 锚点「2048」命中 | 档案覆盖率 `cov_text` | 状态转移 |
|---|---|---|---|---|
| A | 1797 | ✗ | — | — |
| **C0** | 1552 | **✓** | **0.0890** | — |
| **C1** | 1491 | ✗ | 0.0538 | **Jaccard 0.0461 / changed=True** |
| S | 1982 | ✗ | 0.0118 | — |
| R1 | 1484 | ✗ | 0.1150 | — |

**观察到三件事：**

**① 状态转移确实发生了（正面）**
约束① 从"这一轮要写什么、避开什么"变成了"**必须在报价前回避本案谈判**、孩子任职关系**必须披露并记入会议记录**、
本轮只能以可审计的基金影响为依据"。Jaccard 0.0461、无 fallback。
g 步对初稿的诊断也很具体：「她虽用审计数字压住报价，却没有处理孩子就在这家公司工作这一利益冲突」。

**② 但 C1 在「档案内容落地」上输给了 C0（负面，且方向明确）**
C0 把档案全文塞进 prompt ⇒ "病历编号 2048"直接被复述进正文（锚点命中）。
C1 只有 3 条取舍约束 ⇒ **"2048"这种具体事实进不去**。

> **这不是实现 bug，是「取舍约束式驱动」的必然代价。**
> C1 的设计初衷就是"驱动函数输出取舍约束而非内容，避免退化成提示词"——
> **而取舍约束天然不携带可复述的事实。**
> ⇒ **D-1 CKF 在 C1 上可能天然失效**：它测的是「档案**内容**落地」，
> 而 C1 的机制说"档案**内容**不该直接落地，只该影响取舍"。
> **这是判据与机制错配，与 §3.4e 的几何量错配同型。**

**③ 由此，第四组的问题被推到了更精确的位置**
- 现在的 C1 = **取舍驱动，但丢事实**
- C0 = **内容驱动（全文），但无状态转移**
- **真正要问的是：能不能既做取舍驱动，又不丢事实？**（下一代 C2：状态同时携带"取舍"与"可核事实"，
  f 步分别渲染）—— 但**这是下一版的问题，本轮不解决**。

**④ R1 覆盖率 0.1150 > C0 0.0890**
（★ **后续已用 n=5 题 × 4 样本复核**：这个模式**稳住**了，且发展成完整判决 ⇒ 见 **§3.6**）
R1 是同题**反极性**的档案，也走全文注入路径。覆盖率高于 C0 **在 n=1 下完全可能是噪声**，
但它提醒一件事：**覆盖率这个指标区分不出"用的是哪一份档案"**——
R1 与 C0 的档案内容不同（不同极性 ⇒ 不同理由/来历/约束），覆盖率自然不同。
⇒ **覆盖率只能做"有没有被使用"的指标，不能做"用得对不对"的指标。**
后者要靠 D-1 的**换值同步**（同一份档案换值 ⇒ 正文痕迹跟着变）。
