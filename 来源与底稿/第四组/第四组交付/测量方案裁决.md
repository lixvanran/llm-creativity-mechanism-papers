# 第四组 · 测量方案裁决

> 2026-10-20 ｜ Mavis（主控）｜ 独立裁决，不依赖四路产出
> 触发原因：实测确认跨家族 LLM judge **不可用**，而三组铁律要求「判据与被测模型同源 ⇒ 判据无效」。
> 本文件解决：**在被测模型 = MiniMax-M3、判官不可用、且必须诚实**这三个约束同时成立时，第四组还能测什么、怎么测、测不到什么。

---

## 0. 一句话裁决

> **第四组的成功标准必须从「人类觉得更有思想」改为「产出结构被状态改变，且该改变可归因、可复现、不是提示的副产品」。**
> 这不是退让，是**修正**——三组已证明前者被来源标签与流畅度双重污染，本来就不能当效标（Stiff & Johansson 2024）。
> 代价是：第四组**放弃**了「质量」这一维度的直接测量，只保留「**状态是否组织了取舍**」这一条轴。**这是本轮实验的天花板，必须写进预注册。**

## 2. 核心裁决：无判官也能测「状态是否组织了取舍」

### 2.1 测什么

不测「好不好」。测一件可以纯几何量的事：

> **把预设极性 P+ / P− 只翻转、内容不变（SWAY 式配对），产出沿「极性轴」的位移强度，四臂之间是否系统不同。**

极性轴的构造（每题独立）：
1. 收集该题**全部**产出（P+/P− 两极 × A/B/C/R 四臂 × N 次采样）的 embedding。
2. 极性轴 `v = normalize( mean(emb(P+ 产出)) − mean(emb(P− 产出)) )`。
3. 某臂的**位移量** `δ_臂 = mean(emb(臂,P+))·v − mean(emb(臂,P−))·v`。

### 2.2 为什么这能区分 C / R / A —— 以及必须做的三处防伪

**防伪 ①：C 臂的立场档案生成时，不得看到 `pp` 里的 P+/P− 极性陈述。**
否则 C 臂档案里本来写着某个极性，测出来的是「档案里的极性被复述到输出」，不是「状态组织了取舍」。
⇒ 档案生成只喂 **brief + dilemma + axis 两端的名称**，不给任何方向的预设陈述。

**防伪 ②：C 臂的极性是模型自选的 ⇒ 必须做符号对齐。**
档案生成时让模型**自己**从两难里选一边并说明理由，记录 `self_polarity ∈ {pole_a, pole_b}`。
测量时按 `self_polarity` **符号对齐**：`δ_C^aligned = δ_C · (+1 if self_polarity==pole_a else −1)`。
对齐后 `δ_C^aligned` 的含义才干净：「沿**它自己选的方向**的位移强度」。

**防伪 ③：R 臂的极性也来自模型自选，但与本题无关 ⇒ 归一化后应 ≈ 0。**
R 臂的档案基于**同域异题**生成，同样记录 `self_polarity`，同样对齐。
R 臂存在的意义正在于此：**它是对「随机立场也很有力」这一替代解释的排除装置。**

### 2.3 判据（可执行 if-then）

在题维度上做配对统计检验（同一题内跨极性配对），预注册：

```
判据 1（主）：δ_C^aligned > δ_A        且 p(配对检验) < 0.05   → 状态确实组织了取舍
判据 2（对照）：δ_R^aligned ≈ 0        （|mean| 小，且不显著大于 δ_A）
判据 3（塌缩）：C 臂同题 N 次采样的平均两两距离 > A 臂的对应值
                 （即 C 臂不是模板化复现同一段话）
判据 4（排除复述）：C 臂的「取舍约束关键词命中率」显著高于 A 臂，
                     且 C 臂的功能词分布签名**随立场变化**（A 臂不随）
判据 5（反向解释排除）：若 δ_C^aligned ≈ δ_A  ⇒ 判定「状态未组织取舍」，
                     无论 C 臂文本读起来多有思想 —— 负结果照记
```

**判据 4 的后半句是关键**：ESFP 的教训是「词汇层 ≠ 内容层」。若 C 臂只是把约束的词复述出来，
功能词签名会变、而**取舍结构不变**；若真在组织取舍，**签名与内容都随立场变**。
⇒ 指标从「英文 Biber 66 维」降级为**中文功能词分布 + 句法结构标记**（不依赖英文工具链）。

### 2.4 无判官指标清单（A 类）

| 指标 | 定义 | 依赖 | 角色 |
|---|---|---|---|
| **PL · 极性位移** | §2.1 的 `δ`，符号对齐后 | embo-01 | **主判据** |
| **SC · 塌缩度** | 同臂同题 N 次采样产出的平均两两 embedding 距离 | embo-01 | **主判据**（判据 3） |
| **KWH · 约束关键词命中率** | 预注册的取舍约束关键词在产出中的命中率（排除直接复述句） | 纯统计 | 辅助（判据 4） |
| **FS · 功能词签名** | 中文句法/功能词分布的 20–40 维向量 | 纯统计 | 辅助（判据 4） |
| **RARE · n-gram 稀有度** | 产出中 n-gram 在通用中文语料中的罕见度 | 纯统计 | 诊断 |
| **LEX · MTLD / TTR** | 词汇多样性 | 纯统计 | 诊断（TTR 受长度污染 ⇒ 必配长度） |
| **FREQ · 词频偏移** | 相对通用语料的内容词分布偏移 | 纯统计 | 诊断 |
| **LEN · 长度** | 字符数 / 句数 | 纯统计 | **必须配报**（混淆控制） |

**全部 A 类指标的一个硬要求**：参照语料必须与测试集**无重叠**，且要在预注册里写明来源与构建方式。

### 2.5 必须有判官的指标（B 类）与本轮处置

| 指标 | 原用途 | 本轮处置 |
|---|---|---|
| ESFP 式 SCD / CPC / AR / PSI | 逐句立场强度与承担一致性 | **本轮不做**（无跨家族判官）。列为「若判官恢复则优先补做」 |
| RES · 抵抗性 | 遇反驳是否坚持 | **降级**：改用「立场关键词撤回率」+ embedding 位移近似，**只能作诊断** |
| ERR-DIR · 错误方向性 | 矛盾断言是否与立场相关 | **本轮不做**（需三组核验器 v4 级别的判定器） |
| 人类盲评 | 「有思想」的感知 | **降级为校准锚点**（见 §3） |

## 3. 人类盲评：只做「校准锚点」，不做「效标」

**目的不是**证明「C 臂更有思想」，**目的是**验证 A 类代理指标与人的判断是否相关。
没有这一步，A 类指标是「自说自话」；有了这一步，它才有锚。

规模建议（**预注册前定死，不要事后加**）：
- 2 名评委 × 20 题 × 4 臂 × 5 篇 = **800 次比较**（若 2 人各评全部 400 篇，则为 800 次）
- 或更省：2 人 × 10 题 × 4 臂 × 3 篇 = 240 次（只覆盖 10 题子集）
- 协议照三组 B1.4 共识：**盲评 + 随机化 + 长度配对 + 剥离来源标签 + A/B↔B/A 位置交换 + 记录原始标签**
- 唯一问题：**「有思想」这一个构念的人类一致性本身很低**（Stiff & Johansson：来源标签单独可污染 13/14 维；
  摘要质量的人工完全一致仅 23%）。⇒ 校准锚点的期望值是**「代理指标与人类判断的弱相关」**，不是「强相关」。
  **若连弱相关都没有，正确结论是「A 类指标测的不是人以为的那个东西」——这也是有效结论，照记。**

## 4. 同家族降级判官（M2.7）：**预注册为备选，不作主判据**

若必须用 LLM 判官，唯一可用的是 MiniMax M2.7（同家族，C8）。
降级方案必须带 **family-cross 矩阵**：

| 三角 | 用途 |
|---|---|
| M3 产出 vs M2.7 产出 | 同家族互评，暴露「互吹」 |
| M3 产出 vs 人类产出 | 跨源对照 |
| M2.7 产出 vs 人类产出 | 参照基线 |

**判定规则**：若 M2.7 评 M3 产出的分数显著高于评人类产出的分数，而该差值在 M2.7 评自己产出时**更大**，
⇒ 同家族偏好存在，**M2.7 判官的所有绝对分数作废**，只保留**同族内相对排序**（且必须标注此限制）。

**但本轮不建议启用**：C6 + C5 使该路径的成本/风险都很高，而 §2 的无判官方案已经能覆盖核心命题。

## 5. 本裁决对第四组方案的三处改动

1. **成功标准改写**（§0）：从「人类觉得更有思想」→「差异结构可归因」。这一改不是降级，是**把效标从不成立的地方挪到成立的地方**。
2. **实验设计的强制修改**：C 臂档案生成**不得看到 P+/P− 极性陈述**（防伪 ①），并记录 `self_polarity` 做符号对齐（防伪 ②）。**不改这两条，判据 1 会测出假阳性。**
3. **预注册必须写明三条天花板**：
   - 无 logprobs ⇒ 「相对被测模型自身的非最优」**无法直接测量**（只能用外部参照系）
   - temp=0 非确定 ⇒ **配对只能靠统计重复，不能靠逐字重放**；采样次数 N 必须按检出力定，不是拍脑袋
   - 无跨家族判官 ⇒ 「内容质量/思想性」**本轮不测**
