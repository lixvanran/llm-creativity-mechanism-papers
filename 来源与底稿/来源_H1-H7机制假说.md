## 0. 这一层要回答什么（以及**不**回答什么）

**要回答**：为什么 LLM/Agent 会把搜索空间**越走越窄**、为什么会在**该继续探索的时候停下**？
⇒ 必须给到**机制层面**的解释，不能只停在行为现象（"它没想出别的"不是解释）。

**不回答**：不回答"哪个架构更好"。层2/层3 的效果由它们自己证明；层1 的职责是让那些效果
**可解释、可推广、可证伪**。

### 0.1 ★ 先把两个词分开（混在一起就量不出来）

| 词 | 定义 | 行为表征 | 层1 的问题 |
|---|---|---|---|
| **搜索空间** | 系统能产出的答案的**集合** | 结论集覆盖、维度数 | 这个集合**为什么**会变小？ |
| **过早闭合** | 搜索**提前停止**探索（还没用完就收敛） | 边际利用率提前掉零 | 为什么会**提前**停？ |
| **塌缩** | 多样性在下降（Vendi/N 曲线掉） | 跨 rep 交集率上升 | —— |

⇒ **塌缩 ≠ 过早闭合**：塌缩是"空间在缩小"（可以一直缩到很小），过早闭合是"提前停止探索"
（空间可能还很大，但不再往里走）。**二者的机制未必相同** ⇒ 本文件的假说**分别**给。

### 0.2 ★ 本层的**硬边界**（先说清楚，免得把不可测的东西写成结论）

| 我们拿不到 | 后果 |
|---|---|
| **attention weights**（API 后无） | ⇒ 不能直接测"注意力熵塌缩" ⇒ 全部改用**文本级代理量** |
| **logits / logprobs**（实测 `logprobs` 被静默忽略 ⇒ NLL/perplexity/PMI 全族作废） | ⇒ 不能直接测"logit 低熵" ⇒ 改用**跨 rep 结论集交并**代理 |
| 内部激活、注意力图 | ⇒ 假说只能写成"**机制 + 代理量 + 代理量↔机制的推理链**"三段式 |

⇒ **每条假说都标注了「代理量的效度边界」**：
*代理量动了 ≠ 机制成立*（可能是代理失效）；*代理量没动 ≠ 机制不成立*（可能是层级不对）。
⇒ **可失败预测**是唯一的判决依据。

## 1. 机制假说清单

> 每条的结构固定为：**部件 → 分布/信号 → 机制链 → 代理量 → 怎么算 → 可失败预测 → 效度边界 → 我们能不能算**。
> ★ **硬要求（合同）**：不许只给假说 ⇒ 每条都有「可测量的代理量」+「可失败的预测」。

### H1 · **前缀自洽诱导**（premature closure 的首选机制）

| 项 | 内容 |
|---|---|
| **部件** | 解码步的**自注意力对已生成前缀**的质量分布 |
| **信号** | 注意力质量过度集中在**最近生成**的内容上（而不是题面/依据/更早的候选） |
| **机制链** | ① 前缀被写进上下文 ⇒ ② 每一步的注意力质量有一部分压在**它自己刚写下的内容**上 ⇒ ③ 下一个 token 的分布被前缀约束 ⇒ ④ 后续内容是对前缀的**续写**而非新探索 ⇒ ⑤ **有效支撑集变小** ⇒ ⑥ 早闭合 |
| **代理量** | **P1a 后段新信息率** = 答案后 70% 里"全文首次出现"的新实体/新断言占该段断言的比例；<br>**P1b 前缀复述率** = 后 30% 的实词 n-gram 落在前 70% 的比例 |
| **怎么算** | ① 机械切句（同一套切分器，中文标点）⇒ ② 算每条断言的"首次出现位置" ⇒ ③ `P1a = (后 70% 段中首次出现于后 70% 的断言数) / (后 70% 段断言数)`；`P1b` 用 2-gram 集合交并（**必须先过语言闸门：中文占比 ≥ 90%**，中英 n-gram 集不相交 ⇒ 漂移会伪装成"信号消失"）|
| **可失败预测** | **F-H1**：① 在同一臂内，`P1a` **随生成位置单调下降**；② 在臂间，`P1a` 与**步数/前缀长度负相关**（步数多的臂，后段新信息率更低）。<br>⇒ **两条都不成立 ⇒ H1 被否证**（"过早闭合"另有来源） |
| **效度边界** | 代理量测的是**文本层**的自洽性，不等于注意力质量分布 ⇒ 若 `P1a` 不降，也可能是模型本来就写不长 |
| **我们能不能算** | ✅ **能**（答案文本 + 每臂的步数元数据；`slot_records` 里有每槽位长度） |
| **★ 判读陷阱** | 单调性要在**臂内**检验（同一臂的前 30% vs 后 30%），不要在臂间比（臂间差异混着格式与预算） |

### H2 · **logit 低熵 ⇒ 采样没有分支**（塌缩的采样层机制）

| 项 | 内容 |
|---|---|
| **部件** | 采样分布的熵（比注意力**更早**的信号：注意力塌缩常常是熵塌缩的结果，不是原因） |
| **信号** | 每步的分布熵接近 0 ⇒ 采样几乎确定 ⇒ **生成过程没有任何分支** |
| **机制链** | 低熵 ⇒ 采样确定 ⇒ 多次采样产出几乎相同 ⇒ 跨 rep 的答案**高度重合** ⇒ 表现为"中庸"、"没想过别的" |
| **代理量** | **P2a 跨 rep 结论集交集率** `common_rate`（协议已在 `workflow.py:415` 实现）；<br>**P2b 跨 rep 实词 2-gram Jaccard**（语言闸门后）|
| **怎么算** | 每份答案跑同一套卡片抽取 ⇒ 取承重结论集合 ⇒ 交集率 = \|∩\| / \|∪\|（**同时报绝对分子分母**）|
| **可失败预测** | **F-H2**：① 塌缩臂的 `common_rate` 显著高于发散臂；② **`common_rate` 与 `P1a`/步数正相关**（低熵 ⇒ 越到后面越重合）。<br>⇒ **若行为上中庸但 `common_rate` 不高 ⇒ 塌缩不在采样层**（⇒ 往注意力/任务表示层找，优先看 H6）|
| **效度边界** | 结论集交集率**同时**受"承重判据"影响 ⇒ 判据变了读数就变 ⇒ 必须带 `measure_version` |
| **我们能不能算** | ✅ **能**（R=3 的重复产出 + 卡片结论集） |

### H3 · **头间冗余**（多头塌成同质 ⇒ "多视角"是假的）

| 项 | 内容 |
|---|---|
| **部件** | 多个注意力头 / 多个子代理的**功能分工** |
| **信号** | 不同头/不同槽位的注意力或产出**同质** ⇒ 看似多路并行，实则一路 |
| **机制链** | 头间同质 ⇒ 多槽位产出重合 ⇒ "发散"是**名义上的** ⇒ 维度数上不去，但**看起来**槽位很多 |
| **代理量** | **P3a 槽位两两结论集 Jaccard**（`slot_records` 已有每槽位断言）；<br>**P3b 槽位两两实词 2-gram Jaccard**（结构距离，不依赖 embedding）|
| **怎么算** | 逐槽位跑卡片抽取 ⇒ 承重结论集合 ⇒ 两两 Jaccard ⇒ 报**中位数 + 极差 + 槽位数**（**极差比均值更能暴露"一个槽位塌了"**）|
| **可失败预测** | **F-H3**：① 在"去权威化/先独立后汇总"的臂里，`P3a` 显著低于基线（⇒ 多样性来自**结构**，不是来自注意力）；② 若 `P3a` 在所有臂上都很高 ⇒ **架构再怎么改都改不动**，瓶颈在模型内部（层1 成立且**层2/层3 的天花板由此确定**）|
| **效度边界** | 槽位级 Jaccard 混着"同题不同槽位的自然重合" ⇒ 必须在**同题内**比较 |
| **我们能不能算** | ✅ **能**（`CollapseFixWorkflow` 的 `slot_records` 已落盘每槽位断言） |

### H4 · **位置/内容混合 ⇒ 长程依赖被截断 ⇒ 早期决策被锁定**（过早闭合的结构性来源）

| 项 | 内容 |
|---|---|
| **部件** | 位置编码（RoPE 类）+ 注意力的**局部性偏好** |
| **信号** | 远距离位置的影响被相对位置衰减 ⇒ **长程依赖弱** |
| **机制链** | ① 早期决策的 token 距后续 token 很远 ⇒ ② 其影响随距离衰减 ⇒ ③ 但后续 token 与早期 token **共享局部上下文**，局部一致性更容易维持 ⇒ ④ ⇒ **"局部一致"不等于"全局探索"**（这是本条最反直觉、也最可检验的推论）⇒ ⑤ 早期决策被锁定 ⇒ 过早闭合 |
| **代理量** | **P4a 早期决策保持率** = 出现在答案前 1/3 的承重结论，在后 2/3 中仍被支持的比例；<br>**P4b 早期被推翻率** = 前 1/3 出现、后 2/3 不再出现的承重结论数 |
| **怎么算** | 按断言在答案中的**位置**切段 ⇒ 结论级（不是措辞级）追踪 ⇒ 用**族签名**（`conclusion_set` + `decision_point`）跨段对齐，**不用字符串相似度**（措辞级绑定已实测不可用：keep-Jaccard 地板 0.000）|
| **可失败预测** | **F-H4**：① 同一题内，**长答案**的 `P4a` 显著高于短答案（长度放大局部一致性）；② `P4a` 与"前 1/3 的承重结论数"正相关（结论越多越锁定）。<br>⇒ **若 `P4a` 与长度/结论数都无关 ⇒ "早期锁定"不是机制**（⇒ 闭合发生在别的层，例如任务表示，见 H6）|
| **效度边界** | 位置切段依赖**答案长度** ⇒ 跨臂比较必须同题配对 |
| **我们能不能算** | ✅ **能**（答案文本 + 卡片） |

### H5 · **矛盾是"早闭合的残影"**（解释我们已观察到的现象）

> 我们已观察（W 臂，层2）：发散带来了 `C_t` 之外的候选维度（验收门槛 / 在线监控 / 寿命管理 / 故障 runbook），
> **但也混进了一句事实性矛盾**（`①③④正确，②错误`，而直调是 `②正确`）。

| 项 | 内容 |
|---|---|
| **部件** | 自注意力在**自身前缀**上的质量 + 后续步骤对前缀的"遵从" |
| **信号** | 早期断言（含**错误**的早期判定）进入后续的注意力支撑集 |
| **机制链** | ① 发散 ⇒ 断言更多 ⇒ ② 更多断言进入上下文 ⇒ ③ 后续步骤倾向于**与已有断言保持一致**（前缀自洽）而不是回到依据重新核对 ⇒ ④ **早期错误被放大成最终矛盾** ⇒ ⑤ ⇒ "发散带来更多维度，**也**带来矛盾"不是设计缺陷，是**同一个机制的两面** |
| **代理量** | **P5a 矛盾的方向性** = 矛盾断言与**该臂自己的早期断言方向一致**的比例（随机基线 50%）；<br>**P5b 矛盾的位置分布** = 矛盾断言出现在答案的早段还是晚段；<br>**P5c 断言数→矛盾率** = 跨臂回归 |
| **怎么算** | ① 卡片级 `verdict=矛盾` 的卡 ⇒ ② 在**同一臂的早期部分**（前 1/3）找方向相反/相反结论的断言 ⇒ ③ 统计一致比例（**必须报分子分母**）|
| **可失败预测** | **F-H5**：① 发散臂的矛盾率高于直调臂，**且** ② `P5a` 显著高于 50%（即矛盾是"自洽坚持"而不是随机错）；③ **删除反事实**：把该臂的早期矛盾断言去掉后重生成 ⇒ 后续矛盾消失。<br>⇒ **若 `P5a ≈ 50%` ⇒ 矛盾与前缀无关 ⇒ H5 被否证**（矛盾来自别处：例如判官错、依据错、任务本身有两难）|
| **效度边界** | ⚠️ **本条最容易变成"自说自话"**：矛盾率与断言数可能只是**共同**由"产出更多"导致 ⇒ 必须做 ③（删除反事实）才够 |
| **我们能不能算** | ⚠️ **部分能**：① ② 能（卡片 + 位置）；③ 需要**中间步骤落盘**（`slot_records` 有槽位断言，但要做"删除后重生成"需要跑一次消融 ⇒ **成本项**）|

### H6 · **可枚举的任务表示把生成空间写死**（★ 把"我们只是填空"落到机制上）

| 项 | 内容 |
|---|---|
| **部件** | 不是 transformer 内部，而是**任务表示**（题面 + 依据包 + `C_t` 清单）|
| **信号** | 生成侧的输入把可选结论写成**有限清单** ⇒ 注意力质量自然集中到清单里的少数项 |
| **机制链** | ① 输入里有一份可枚举清单 ⇒ ② 模型的注意力质量自然落在清单项上 ⇒ ③ 采样熵低、头间同质（⇒ H2/H3 是**症状**）⇒ ④ **有效支撑集 = 清单** ⇒ ⑤ ⇒ **"锚外发现"在结构上不可能** |
| **代理量** | **P6a 锚外维度率** `VD_anchor_out / (VD_anchor_in + VD_anchor_out)`（实测见 `eval/vd_anchor_out.py`）；<br>**P6b 清单内集中度** = 承重结论落在 `C_t` 内的比例（= 1 − P6a）|
| **怎么算** | 用 `vd_anchor_out.py` 的两栏读数（锚内 = 原判据，锚外 = 新判据 + 独立复核 + 族级留一）|
| **可失败预测** | **F-H6**：**同一题**，**不给依据包/清单**的臂（`B0_noev`）的 `VD_anchor_out` 显著高于**给了清单**的臂。<br>⇒ **成立 ⇒ 我们的"发现"能力是被任务表示卡住的**（⇒ 层2/层3 的正确靶子不是"更多架构"，而是"**更宽的任务表示**"）；⇒ **不成立 ⇒ 锚外不是被清单卡的**（⇒ 换原因）|
| **效度边界** | ⚠️ "不给依据包"同时改变了**信息量**与**空间形状** ⇒ 这是**混淆对照**，不是干净消融 ⇒ 结论只能写成"**与依据包绑在一起**"，不能写成"**由清单造成**" |
| **我们能不能算** | ✅ **能**（DEV 批：`B0_direct`（给依据） vs `B0_noev`（不给依据） vs `W_div`（给依据+多视角））|

### H7 · **塌缩与过早闭合的分离**（层1 与层2/层3 的**归因路由表**）

| 项 | 内容 |
|---|---|
| **部件** | 流程层（不是模型层）：轮数、预算、装配顺序 |
| **信号** | **边际利用率**（第 k 轮/组件带来的新承重结论数 ÷ 累计承重结论数）**提前掉零** |
| **机制链** | 掉零早 ⇒ 提前停止探索 ⇒ 但这可能**与注意力无关**，只是**轮数/预算用完了** |
| **代理量** | `marginal_util(k)`（`workflow.py:425` 已实现）、`coverage_saturation(k)`（`workflow.py:469`）、`common_rate`（`:415`）、`dist_to_modal`（`:446`）|
| **可失败预测** | **F-H7（★ 归因路由）**：把 `marginal_util` 的**掉零位置**与 (a) 预算/轮数、(b) 步数、(c) 答案长度做比较：<br>① 若掉零位置**强依赖预算/轮数** ⇒ "过早闭合"是**流程/架构问题**（层2/层3 的靶子）⇒ **层1 在这里不适用**；<br>② 若掉零位置**与预算无关、只与步数/长度有关** ⇒ 与 H1/H4 一致（注意力/局部性）⇒ 层1 适用；<br>③ 若与两者都无关 ⇒ 是**判据/口径**造成的（我们自己的问题）|
| **效度边界** | 归族规则一变，`marginal_util` 就变 ⇒ 必须带 `aligner_version` |
| **我们能不能算** | ✅ **能**（`workflow.py` 已有四个实现；⚠️ 它们的**输入**需要每轮的结论集合 ⇒ 需落盘）|

## 2. "我们能不能证伪它"的总清单

| 假说 | 判决式 | 若成立 ⇒ 下一步 | 若不成立 ⇒ 下一步 |
|---|---|---|---|
| **H1** 前缀自洽 | 臂内 `P1a` 单调降 **且** 臂间与步数负相关 | 去查"谁能打断前缀"（去权威化/先独立后汇总）| 闭合不在局部自洽 ⇒ 看 H6 |
| **H2** 低熵无分支 | 塌缩臂 `common_rate` 更高 **且** 与 `P1a`/步数相关 | 低熵可诊断 ⇒ 采样侧改造（温度/多样化）| 中庸不在采样层 ⇒ 看 H3/H6 |
| **H3** 头间冗余 | 去权威化臂的槽位 Jaccard 显著下降 | 多样性来自结构 ⇒ 层2/层3 有戏 | 瓶颈在模型内部 ⇒ **层2/层3 的天花板确定** |
| **H4** 早期锁定 | `P4a` 与长度/结论数正相关 | 早期决策可被干预 ⇒ 需要"可回溯"机制 | 锁定不成立 ⇒ 看 H6/H7 |
| **H5** 矛盾是残影 | `P5a > 50%` **且** 删除反事实后矛盾消失 | 矛盾可预测 ⇒ 进 R1 预算 | 矛盾与前缀无关 ⇒ 矛盾来自判官/依据/两难 |
| **H6** 任务表示写死 | 无依据臂 `VD_anchor_out` 更高 | **靶子换人**（不是加架构，是加宽任务表示）| 锚外不是被清单卡的 |
| **H7** 归因路由 | 掉零位置与预算的关系 | 归因到层2/层3 | 归因到层1 或 判据 |

> ★ **每条都有"若不成立则去哪里"** ⇒ 这不是清单，是**路由表**。
> ⇒ 这是层1 真正的交付形态：**让层2/层3 的每个设计动作都能被指认它到底在动哪个自由度。**

### 3.1 "发散带来更多维度，也带来矛盾"

### 3.2 层1 对层2/层3 的三个直接后果

1. **H6 若成立 ⇒ 我们的靶子换人**：不是"加更多架构"，而是"**加宽任务表示**"
