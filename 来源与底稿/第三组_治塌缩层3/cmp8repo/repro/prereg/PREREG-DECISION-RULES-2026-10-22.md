## 1. 分析单元与统计口径（不可协商）

| 项 | 规定 | 为什么 |
|---|---|---|
| **分析单元** | **题**（DEV 的 D01/D02） | 同题多步 rollout **不是**独立样本 |
| **重复** | R = 3（**事前固定**，三臂一致） | "跑够为止" = p-hacking |
| **主读数** | **承重维度数（绝对）** 与 **净维度增益（双边）** | 比率必须配绝对分母 |
| **聚合** | 题级读数取**中位数**；臂间差按**题配对** | best-of-N 单点读数会被 n 抬高 |
| **显著性** | 题数 ≤ 3 ⇒ **不做显著性检验**，只报**逐题配对差 + 中位数 + 区间** | n 太小，p 值是噪声 |
| **有效性** | `valid/total` 如实报；**不许**因解析失败而重跑 | 解析失败率是读数的一部分 |
| **不可分辨** | 差值落在**噪声地板**内 ⇒ 写「**不可分辨**」，**不写"无效应"** | 见 §3 |

## 2. 四个待判命题（每个都有明确的"成立"与"不成立"）

### P1 · 层2（认知帧解耦 + 机械汇总）**相对直调**有增益吗？
- **主判据**：`VD_net(W_design_L2 − B0_bestof3) > 0` 的**题数**（配对，按题）
- **等预算前提**：★ **必须**与 `B0_bestof3` 比（调用数相同），**不能**与 `B0_direct` 比
  （后者只花 1 次生成 ⇒ 任何差异都可能只是"多花了钱"）
- **不成立**：配对差中位数 ≤ 0 ⇒ 写「层2 未显示增益」
- **附加**：★ `B0_direct` vs `B0_bestof3` 的差 = **"多花的钱买到了什么"** ⇒ 这本身要报

### P2 · 层3（自修改）**相对层2**有增量吗？
- **主判据**：`VD_net(W_train_L3 − W_design_L2) > 0` 的题数（配对）
- ⚠️ **层2 与层3 只差 `evolve` 一个开关、共用同一份代码与同一条测量管线**
  ⇒ 差值**只能**来自"自修改"⇒ 这是我们最干净的对照（照 AgentSquare 的 `w/o module evolution` 范式）
- **不成立**：配对差中位数 ≤ 0 ⇒ 写「自修改未显示增量」
- ⚠️ **注意动作空间**：当前实现是**在我手画的 36 格网格上学 softmax** ⇒
  ⇒ 若 P2 成立，**只能**声称"在设计好的空间里自修改有增量"，
  ⇒ **不能**声称"架构由训练产生"（那是 AgentSquare+B\* 那一层的事，见 §6）

### P3 · 锚外发现成立吗？★ 这是**主命题的可失败判据**
- **主判据**：`VD_anchor_out` 在 `W_train_L3` 上 **> 0 且跨 3 次重复稳定**
- **不成立**：任一重复为 0，或全部重复为 0 ⇒ **写「主命题不成立：我们做的是检索，不是发现」**
- ⚠️ **必须用锚外判官（不给 `C_t`）测** ⇒ 普通判官拿着 `C_t` 打分 ⇒ 锚外**永远不可见** ⇒
  恒为 0 **不代表**没发现 ⇒ 只代表"判据测不到"
- **报数**：锚外条目**原文 + 它依赖的依据编号**（`uses_evidence`）⇒ 必须可人工复核

### P4 · 代理奖励迁移到真实判据了吗？
- **主判据**：`train_policy_w.py` 的代理奖励排序 vs **完整判官**下的承重维度数排序
  ⇒ **Spearman ρ**（题级，n 很小 ⇒ 只报 ρ 与散点，**不报 p 值**）
- **不成立**：ρ ≤ 0 ⇒ 写「**代理奖励未迁移**」⇒ 这本身是有价值的发现
- ⚠️ **已知偏倚风险**（训练时已观察到）：代理奖励含 `λ_cover·覆盖` 项，
  而"覆盖"是**去冗余后的断言族数** ⇒ **可能奖励啰嗦** ⇒
  ⇒ 若 ρ ≤ 0，**优先怀疑这一项**，并如实写明"代理奖励疑似奖励啰嗦"

## 3. 噪声地板 δ 的用法（已修的坑）

- 主门槛 = **`δ_judge`**（**同提示词、重复判定**的读数波动）**与** `δ_total` 的**较大者**
- ⚠️ **2026-10-23 更正**：原写"跨判官版本/模型"⇒ **实测证明那个方向错了** ⇒
  ★ **"temp=0 ⇒ 判官确定"这个前提不成立**（简单任务 3/3 一致，多步卡片判定 [3,3,0]）
  ⇒ ⇒ **δ_judge 必须用「同提示词重复判定」测**（跨版本只测得到"版本差异"，测不到"同版本内的不确定性"）
  ⇒ ⇒ **修法也随之改变**：不是"换判官版本"，而是**加「判官逐条 verdict 一致性检验」作检测器，
  把不一致的判定标为 invalid 并重判**
- ⚠️ **种子地板在判官 temp=0 下恒为 0** ⇒ **不许单独拿它当门槛**
- 硬闸门：种子地板退化且未提供判官变体 ⇒ **该批次不出数**
- **本题目的批次**：`judge_same_vendor=true`（被测与判官同为 MiniMax）⇒
  ⇒ 本批次读数**只作内部对照**；**对外主张必须补跨厂商判官交叉**（见 §5）

## 4. 必报的"绝对分母"清单

| 读数 | 分母 |
|---|---|
| 承重维度数 | 每份答案的**可核验断言总数**（不是百分比）|
| 解析失败率 | 该臂抽取出的**断言条数** |
| 锚外比例 | 该臂的**承重卡总数** |
| 矛盾数 | 该臂的**承重卡总数** |
| 调用数 | 每臂的**实际 API 调用次数**（含重试）|

## 5. 必须补、否则结论无效的对照

| 对照 | 状态 | 不做的后果 |
|---|---|---|
| **等预算臂**（`B0_bestof3`）| ✅ 已实现 | "增益"可能只是"多花了钱" |
| **跨厂商判官交叉**（ToT 式）| ❌ **未做** | 判官同源 ⇒ 读数不可对外主张 |
| **同预算 best-of-k**（ToT 式，轴=调用数）| ✅ 由 `B0_bestof3` 覆盖 | — |
| **格式对称化审计**（同模板/同字数上限/同标题结构）| ❌ 未做 | 判官可能给"结构化程度"打分 |
| **DEV 集最小准则筛选**（POET 式）| ❌ 未做 | 题可能全平或全饱和 ⇒ 无区分力 |

⇒ ⇒ **跨厂商判官交叉**是唯一"不做就不能对外主张"的 ⇒ ★ **优先级最高**（OpenRouter 已授权）。

## 6. 关于"架构由训练产生"这句话的措辞纪律

| 观察到的 | **最多能写** |
|---|---|
| P2 成立（层3 > 层2）| "在**我们设计的**动作空间里，自修改带来了增量" |
| + 动作空间可增长（模块池化，`B* = B ∪ A*`）| "**动作空间本身**在训练中增长" ⇒ 才可以接近"架构由训练产生" |
| + 目标函数是有效信息维度数 | "我们搜的是**答案不再中庸**的架构"（区别于 AgentSquare 的任务正确率） |

⇒ ⇒ ⚠️ **当前实现只能支撑第一行。** ⇒ 论文里**不得**出现"我们实现了自动的 Agent 架构搜索"
（AgentSquare 早已做过）⇒ **只能**说"我们证明了『用思维面当目标的自修改』在小规模设置下的可行性/不可行性"。

## 7. 中庸度四指标的判读（若采用）

| 指标 | 方向 | 注意 |
|---|---|---|
| ① 交集率 | 越低越不中庸 | 跨臂比 ⇒ 必须同时报绝对分母 |
| ② 边际利用率 | 骤降 = 过早闭合 | **须按轮次报曲线**，单点没意义 |
| ③ 中庸距离 | 越大越不中庸 | ★ **只比同批内相对序**（绝对距离跨题差 10×）|
| ④ 覆盖饱和度 | — | ★ **饱和是好事**（空间穷尽）；**塌缩/闭合才是坏事** ⇒ 三者必须分开报 |

⇒ ⇒ ★ **中庸度指标本身可能有先例**（正在查）⇒ 若找到既有口径，**优先换成/对齐他们的**，
并把"我们自造"写成一条**方法学说明**而不是卖点。

### ★ 附：一句必须写进论文的自我纠正

> **"标量 argmax 的档案规模必然 = 1" 是定义，不是发现** ⇒ 用它当对照是**同义反复**。
> ⇒ ⇒ **真正的证据必须是下游效应**：Pareto 训出的策略在**真实判官**下
> **承重维度不降、而多样性指标（Self-Sim / 碰撞比）更好**。
> ⇒ ⇒ "档案规模 > 1" 只能作为**机制存在性**的证据，**不能**当效果证据。
