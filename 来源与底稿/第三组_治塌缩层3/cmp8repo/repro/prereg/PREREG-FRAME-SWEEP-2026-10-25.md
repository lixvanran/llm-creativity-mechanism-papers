## 1. ★ 四处必须照办 —— 逐条落到执行

### ① ★ 必须先做解耦改动（**这是本实验能不能归因的前提**，不是可选准备）

**问题**：`run_dev.py:300/305` 把帧选择的 seed 设为 `seed=rep` ⇒ ⇒ **`select_frames(k, seed)` 与 run seed 是同一个** ⇒ ⇒ 「放开 seed」会**同时**动题序 / rep 抽样 / 候选组合 ⇒ ⇒ **多因子一起动 ⇒ 跑不出归因。**

**改动（只动这一个参数）**：
```python
# workflow.py
def select_frames(k: int = 4, seed: int = 0, frame_seed: int | None = None) -> List[str]:
    rng = random.Random(seed if frame_seed is None else frame_seed)   # ★ frame_seed 独立
    ...
# run_dev.py（新增 CLI）
--frame-seed <int>   # ★ 不传 ⇒ 行为与现在逐字节一致（回归要求）
# 调用处
W.select_frames(slots, seed=seed, frame_seed=args.frame_seed)   # ★ run seed 不动
```
* ★ **回归要求**：`--frame-seed` 不传时，**同一 seed 产出的 frame 组合必须与现在逐字节一致** ⇒ ⇒ 改完跑一次 `--frame-seed` 不传的对照，比对 `paths[].frame` 序列。

### ② ★ 必须另起一批，**绝不许混进正在跑的留出批**

* 理由 ①：留出批的题集 / 题序 / seed 序列（seed = rep ∈ 0..7）**按预注册写死** ⇒ ⇒ 插臂 = 改预注册的批
* 理由 ②：概念层 —— **【策略维度】与【候选维度】混在一批**
* ⇒ ⇒ **本实验的输出目录 = `runs/framesweep/`（全新）**，与 `runs/holdout13/` 物理分离

## 3. ★★ 判据（写死）

**主读数 = 路径间 Self-Sim**（`space.py::path_diversity`，★ **零 embedding、零阈值**，n 基线平坦 ⇒ 可跨批比）

**判死门**：
> **组间差**（不同 `frame_seed` 组合之间的 Self-Sim 差异）**显著大于** **题内 rep 间差**（同一 `frame_seed` 下不同 rep 之间的 Self-Sim 差异）
> * **显著大于** ⇒ ⇒ **「候选多样性影响宽度」成立**
> * **不显著** ⇒ ⇒ **「候选多样性无效应」**（★ **这是合法结论，如实写**）
> * ★ **判据版本锚 = `4589225c7ce87a108019a0482a97af93b6b73d24`**

* ★ **每格带绝对分母**（n）｜★ **两种 0 分列**（仪器层 / 内容层）｜★ **候选组合逐个列出**（实际 frame 组合，不只报"3 候选"）｜★ **★ 报【实际组合数】**（★ 通则 §㊗：名义参数必须同时报实际取值分布）
