## 摘要

LLM Agent 在开放问题上倾向于给出**中庸**答案：结论落在分布中心，缺少能改变决策的具体信息。
我们把这一现象拆成两个可分离的机制——**搜索空间塌缩**（可产出的解集在收缩）与**过早闭合**（探索提前停止）——
并提出把「思维面」操作化为**有效信息维度数**（evidence-bearing dimension count）而不是角度多样性、字数或表面新颖性。

在此基础上我们给出一套可运行的干预：
（i）**设计层**（层2）—— 用**认知帧解耦**替代共享稠密结构、**机械装配**替代模型汇总、**离散去冗余**、以及基于行为空间的照明式档案；
（ii）**自迭代层**（层3）—— 动作空间从**失败信号**中演化，失败信号含一个**零判官成本**的矛盾检测器。

我们同时报告三项**测量学上的失败**及其修正，因为它们会系统性地伪造出"有增益"的结论：
判官在 `temperature=0` 下的种子噪声地板**恒为 0**（定义造成的，不是仪器稳）、
MiniMax 自适应思考会**吃光 `max_tokens`** 导致正文为空且**静默**、
以及沙箱中 `.pyc` 缓存会让我们**运行旧代码却以为在跑新代码**。

**本稿的结论分两层，且必须分开说**：

1. **判官读数不支持任何架构级优劣结论** —— **同一批答案上，同一判官重复判定 3 次的波动可达 3 分**（与是否强制 thinking 相关），而承重维度数本身只有 1–5 ⇒ ⇒ **任何 ≤1 的架构级效应在原理上看不见**
   ⇒ ⇒ ★★ **更强的否证（§6.1b）：两个判官对同一批设计给出【相反】的架构结论**⇒ ⇒ **架构级结论不成立** ⇒ ⇒ ★ **本文不主张任何架构级优劣**，只主张测量学与机制边界。
   （层3 相对层2：`grok-4.3` 给 **+0.75**、`MiniMax-M2.5` 给 **−1.00**）；
   且我们实测判官读数的**中位波动 = 1**，而维度数本身只有 1–5 ⇒ **任何 ≤1 的架构效应在原理上就看不见**。
2. **零判官的空间指标给出正向证据**（**已过 n 基线 + 嵌套子集校准**）：**3 次独立直调的分支彼此重叠 0.43–0.48，
   而任何"用认知位置"的臂彼此重叠 0.11–0.18** ⇒ ⇒ **"独立采样"其实并不独立**（共享同一 prior）
   ⇒ ⇒ ★ **限定**：本条**只**由 Self-Sim（比率口径）支撑；**同批的"模态数"是另一个口径且已降级**（§6.2b）
   ⇒ ⇒ **限定**：该结论**在 Self-Sim（比率）口径、3 支等 n** 时成立；计数口径的绝对值随 n 变化 4–5 倍
   ⇒ ⇒ **认知位置真的把 prior 改掉了 —— 搜索空间确实被拓宽了**（零判官、零噪声）。

★ 并且我们把**代价精确定位到了"合并"这一步**：逐帧各跑一遍＋投票的臂**同样宽、而且信息量最高**
（承重维度中位 **4.50**），而我们的**机械汇总**臂**同样宽、但信息量最低**（**2.50**）
⇒ ⇒ **拓宽搜索空间来自「发散」，信息量的损失来自「合并」** ⇒ ⇒ **下一个该动的地方是合并方式**
（⇒ DCI 的 decision packet：保留未决异议与少数意见）。

★ **而最直接的机制指标（零判官、纯文本正则）给出**：
在**诱导钻牛角尖**的理科题上，**认知位置臂的钻牛角尖率是基线的一半（50% vs 80–100%）**，
而**"增加独立采样次数"（3 次直调）是 100%** ⇒ ⇒ **增加采样次数不降低钻牛角尖率；换认知位置才降**
⇒ ⇒ 且这**只在"解法路径多样"的题上成立**（路径单一的题上四个臂全部踩坑）
⇒ ⇒ ⇒ **"该不该发散"由题型的路径空间决定** ⇒ ⇒ **这正是层 3 应当学出来的决策**。

## 1 引言

### 1.1 现象

给定一个开放问题，LLM Agent 的答案常常**安全、完整、而空洞**：它列出正确的类别，引用常识，
却不给出任何**能改变决策**的具体信息。工程上这表现为"读起来像专家写的"，
但拿它做决策时，它与一个没有上下文的通用回答差别不大。

我们把「答案有多空」这件事叫做**中庸**（medianity），并主张：
**中庸不是模型能力问题，而是搜索过程在结构上过早收敛的结果。**

### 1.2 我们与已有工作的边界

| 工作族 | 它改什么 | 它不触及什么 |
|---|---|---|
| 一般 Agent 搜索（ADAS、AgentSquare）| 搜**解**（或 agent 代码结构）| 问题空间**由任务给定** |
| 推理树/图搜索（ToT、GoT）| 搜**解路径** | 路径空间**由问题给定** |
| 反思机制（Reflexion、Re3、Self-Reflection）| 修**已有答案** | 不增**维度**；Re3 自陈"故事常偏离提纲"⇒ 注入计划 ≠ 计划承重 |
| **我们** | 改**哪些候选维度算问题的一部分** | —— |

★ 关键区分：前几族**都在一个给定的空间里搜**。我们的命题是
**"连该考虑哪些维度都不知道时，能否主动发现原先未被纳入的维度"**。
而这一命题**必须可失败**（§3.6），否则它只是一句漂亮话。

### 1.3 贡献

★ **本文的自我定位（摘要同款表述）**：**不主张任何架构级优劣**，只主张**测量学与机制边界**。

1. **操作化**：把「思维面」定义为**有效信息维度数**，给出可机械复核的**承重检验**（§3.2），
   并指出"维度数"与"角度多样性"、"字数"、"断言数"**不可互换**。
2. **可失败的主张**：提出**锚外新增维度数** `VD_anchor_out`（§3.6）——
   首个把"发现原先未被纳入的维度"变成**可证伪标量**的读数；并给出它恒为 0 时立论即不成立的判据。
3. **一个可运行的干预架构**：认知帧解耦 + 机械装配 + 离散去冗余 + 行为照明（层2），
   与失败驱动的动作空间演化（层3）（§4、§5）。
4. **三项测量学失败的公开报告**（§6.5）：它们会**静默**地伪造出"有增益"的结论，
   我们给出可复现的诊断与修正。
5. **负结果的边界**：我们**不**声称已实现自主发现（§8）。

## 3 度量：什么是"有效信息维度"

### 3.0 ★★★ 方法学通则：**任何宽度/多样性度量，先判定它是「计数型」还是「比率型」**

> **通则**：在把一个宽度/多样性度量用于**跨臂比较**之前，必须先回答一个问题：
> **它是不是一个「计数」？**
>
> | 类型 | 例子 | 随 n 的机械行为 | 跨臂比较前必须做什么 |
> |---|---|---|---|
> | **计数型** | Vendi Score（谱熵的指数）、模态数（族去重数）、聚类簇数、distinct-n | **绝对值随 n 系统性变化** | ★ **必须**先测 **n 基线**（零假设 + 嵌套采样）⇒ 否则效应可能被机械增长吃掉（**假阴性**）|
> | **比率型** | Self-Sim（两两 Jaccard 均值）、self-BLEU、Distinct-n（占比）| **n 基线曲线平坦** | 可直接跨臂比（但仍建议留 n 基线曲线作附件）|
>
> ⇒ ⇒ ★★ **两者都要校准，但校准结论方向相反** ⇒ ⇒ **不能互相套用**：
> · **计数型**的 n 基线**随 n 上升** ⇒ ⇒ 原始读数里"更大"的一部分是机械的 ⇒ ⇒ **要降级**
> · **比率型**的 n 基线**平坦** ⇒ ⇒ 原始读数里的差异**不是**机械的 ⇒ ⇒ **不用降级**
>
> ⇒ ⇒ **本项目自己的实证（零 API 成本，`nested_calib_self.py`）**：
> | 臂 | n 基线曲线 k=2 → 12（Self-Sim，比率型）| 判定 |
> |---|---|---|
> | `B0_bestof3` | 0.213 → 0.213 | **平坦** |
> | `B0_frames_vote` | 0.079 → 0.079 | **平坦** |
> | `W_design_L2` | 0.067 → 0.067 | **平坦** |
> | `W_train_L3` | 0.071 → 0.071 | **平坦** |
>
> 而**计数型**（模态数，同一批数据）：`B0_bestof3` **8.0 → 46.0**（k=2→12）⇒ ⇒ **绝对值变化 4–5 倍**
> ⇒ ⇒ ★ **同一批数据、同一个 n 基线测法，两类度量的结论方向相反** ——
> ⇒ ⇒ **这解释了为什么"计数型度量上的宽度提升"必须降级，而"比率型度量上的宽度差异"不用**。
>
> ⇒ ⇒ ★★ **可推广的三道门**（我们对自己每个宽度结论都走一遍）：
> **① 指标定义上能检出**（它有没有 n 依赖？有没有恒等式？）
> **② n 基线**（零假设：同一分布下换 n 会怎样？）
> **③ 嵌套子集校准**（真实数据：从大样本抽小样本，比"实测"是否超出"机械"范围）
> ⇒ ⇒ **"发现口径错误" ≠ "结论成立"** —— 三道门都过，才是结论。



### 3.1 为什么不能用量、角度数、新颖性

我们在早期实验中反复撞到三件事：

- **断言数 ≠ 维度数**：一条断言可以复述、铺陈、免责，**不改变任何决策**（§3.2 的 C3）。
- **角度多样性 ≠ 维度数**：ADHD 项目的 15 个认知帧产生的是**语义多样性**；
  其 `trap` 字段是"**被否决**的信息"，**不承重** ⇒ trap 多 ≠ 维度多。
- **字符数 / token 数 ≠ 维度数**：我们实测过同一答案在判官提示词版本变动下，
  承重维度读数在 `0/+1/−1` 与 `+1/+4/0` 之间跳 ⇒ **带宽 > 信号**。

⇒ ⇒ **唯一能站住的是"这条信息改变了哪个决策"。**

### 3.2 承重检验（我们的核心判据）

对每条陈述 `c` 判定它是否**承重**：

| 条 | 要求 | 排除了什么 |
|:-:|---|---|
| **C1** 决策岔口可指名 | 写得出一个**具体**的决策/结论（属于**预注册**的结论空间 `C_t` 或其子集）| 复述、铺陈、寒暄、免责 |
| **C2** 删除反事实成立 | 删掉 `c` 后，`C_t` 中**至少一条结论**从"可支持"变为"不可支持" | 看似有用但改了也不影响结论的信息 |
| **C3** 在结论空间内 | 影响的是 `C_t` 里的结论 | 免责声明、健康科普、性格描述、延伸阅读 |

> ⚠️ **C3 是我们最大的自伤点**（§3.6）：它使"发现原先未被纳入的维度"在结构上不可能。

**维度数** = 去冗余后的**承重族**数；族键 = 该卡支撑的结论集合（`family_key`）。
⇒ **主指标永远是两个数一起报**：承重维度数（绝对）+ 净维度增益（双边）。

### 3.3 净维度增益（双边）

```
VD_net(arm) = |新增承重族| − |丢失承重族|     （相对参照臂 B0）
```

⚠️ **必须双边**：只报净值会掩盖"新增很多 + 丢光基线"。
⇒ **必须配绝对分母**：本项目早期一次读数里全部 84 份答案只有 **21 条**可核验断言，
每臂 1–6 条；5 个非零矛盾率样本的**分母都 = 1** ⇒ 那些比率**不可分辨**。

### 3.4 中庸度：换成有出处的口径（★ 先例审计后的改动）

我们原先自造了四个指标。先例审计的结论是：**三个的"形"已经被做过了** ⇒
继续用自造名字会被当作"不知道有前人工作" ⇒ ⇒ **正确动作不是"换掉"或"不换"，
而是「换口径 + 引用，保留我们的数据组织（`family_key` 等价类）」**。

| 我们的旧指标 | 换成 | 出处 | 保留的声明 |
|---|---|---|---|
| 交集率 | **多数票份额** + **#distinct answers** + **离散语义熵 DSE** | Self-Consistency (ICLR'23, arXiv:2203.11171) / Kuhn, Gal & Farquhar (ICLR'23 Spotlight, arXiv:2302.09664) | DSE 的等价类**来源不同**（他们用 NLI，我们用决策指纹 ⇒ 零外部模型）|
| 边际利用率 | **ESS**（`1/Σw²`，w = 每轮新发现族数）+ 逐轮曲线 | ePF (arXiv:2510.05825) | ESS 上界 N / 下界 1 ⇒ 边界可解释；**必须权重，不能只用布尔** |
| 中庸距离 | **Self-Sim**（字元集合两两 Jaccard 均值，N=5 口径）+ **碰撞概率 C / N₂ / 碰撞比 R** | Lake, Choi & Durrett (NAACL'25 Main, arXiv:2406.17692) / Skobelev, Fithian & Han (arXiv:2609.16454, preprint) | ★ Self-Sim 原文读数 0.11–0.45 是**英文**的 ⇒ 我们的中文读数**不可与之比大小**，只比同批内相对序 |
| 覆盖饱和度 | **保留**，改名 "coverage over a **pre-registered** conclusion space" | 形式同 OvertonScore (ICLR'26, arXiv:2512.01351) | **分母不同**（我们 = \|C_t\|，他们 = 人类观点集）⇒ 必报 \|C_t\| 作绝对分母 |

★ **三处必须自己定口径的地方**（不能直接抄英文文献）：
① **"词干"在中文里没有对应物** ⇒ Self-Sim 的"唯一词干集合"⇒ 我们用**字符 2-gram 集合**（另提供决策指纹版）；
② **DSE 的等价类** = 我们的 `family_key`（决策指纹）⇒ 零 NLI 模型，**但不是同一个等价类**；
③ **碰撞比 R 的分母是"目标分布"** ⇒ 我们**没有人类目标分布** ⇒ 用**批内自参照** ⇒
⇒ **R 只能读"同批内相对中庸"，不能读"相对人类"**。

**保留自造的三项**（先例审计确认**参照系无先例**）：
- **`VD_anchor_out`（锚外新增维度数）** ＋ 其判定链
  （承重 ∧ 被依据支持 ∧ 写得出决策岔口 ∧ 岔口 ∉ `C_t`，且判官**不知道 `C_t`**）
  ⇒ 形式有先例（集合覆盖率口径），**参照系无先例**（最接近的三个：PSFA 用 GOMS 问题空间、
  DiscoveryBench 用已发表文献、OvertonScore 用人类观点集）⇒ 论文必须写"**形式有先例、参照系是新的**"
- **承重检验 C1/C2/C3**（与 `C_t` 预注册成对保留）
- **覆盖饱和度**（保留 + 改名对齐）

⇒ ★ **全部离散结构量、零 embedding**：我们实测的 `embo-01` 在中文句级无分辨率（27 条断言被压成 1 条），
且**措辞级相似度在改写型环节彻底失效**（keep-Jaccard = 0.000）。

### 3.5 行为刻画：新颖度与多样性的载体

按 Novelty Search 的要求，行为刻画（BC）必须**敏感**且**不冗余**。
我们取 **（认知帧组合 × 操作序列）** 作 BC ⇒ 离散、哈希、可复算。
★ 附带收益：它同时回答"我们到底探索了几种东西"——**行为格数**。

### 3.6 ★ 锚外新增维度数：让主命题可失败

**问题**：`C_t` 事前写死 + C3"锚外一律不算维度" ⇒ 我们做的不是"发现原先未被纳入的问题空间"，
而是"**在人事先划好的答案空间里检索得更全**"。⇒ 评审一句"你只是填空"，主命题即废。

**最近读到的一篇正好撞在这里**：PSFA（Wray / Kirk / Laird，
*"Eliciting problem specifications for LLM-Modulo cognitive systems"*，
Cognitive Systems Research 94:101409 (Elsevier, 2025)；arXiv:2405.12147 全文可读）
——它发现的"漏掉项"**参照系是人类专家的问题空间分解（Newell 1980 / GOMS）**，
候选槽位**先验封闭**；它自己承认 *"...the least successful of all the nodes we included"*，
把"生成 novel problem spaces"列为**开放问题**，并写下 *"strong attractor effect"* 与
*"parrot similar problems and solutions"*。
⇒ ⇒ **我们与它有量纲差异的位置，正是"锚外"。**

**定义**：

```
VD_anchor_out(arm) = |{新出现的承重族：其支撑的结论 ⊄ C_t}|
```

**判据（预注册）**：
- `VD_anchor_out > 0` 且跨重复稳定 ⇒ 支持"能发现锚外维度"
- `VD_anchor_out ≡ 0` ⇒ **主命题不成立**（我们做的是检索，不是发现）——**如实写"不成立"**

**判定方法（零预注册白名单）**：
① **leave-one-out**（Curiosity Search）：某条信息是不是独立维度 = **拿掉它之后结论是否改变**；
② **agent×依据 影响矩阵**（MAME）：把"agent 自报置信度"换成"**这条反馈实际引用的依据 ID**"
⇒ 离散、不依赖 embedding、不依赖措辞相似度。

> ⚠️ 本节是**待验证**的：实现与读数由第二组交付（§5 交付物 2）。

## 4 层2：用设计的手段优化

### 4.1 三个失败 ⇒ 三个干预

| 失败 | 现象 | 干预 | 出处 |
|---|---|---|---|
| **横向收敛** | 多槽位产出趋同 | **认知帧解耦**：每槽位挂一个**认知帧**（vantage operator，**非** persona）| Diversity Collapse (ACL 2026 Findings) §4.3 + 附录 I/M |
| **纵向早熟** | 搜索提前停止 | **动作空间可演化**（层3，§5）| B\* Expansion (Expert Systems 2026 43(8) e70333) |
| **产出中庸** | 答案落在分布中心 | **行为空间照明**（每格留最优）| MAP-Elites (Mouret & Clune 2015) + Novelty Search |

### 4.2 认知帧：为什么是"帧"而不是"角色"

Diversity Collapse 证明**专家权威 persona 压多样性**（Interdisciplinary 的 Vendi 最低 4.65，
Horizontal 最高 8.08，而质量只差 0.62）。**但这不能直接推论到"帧"**：
ADHD 项目的 15 帧是 **vantage operator**——*"a deliberate distortion that forces the generator
into a corner it would not naturally drift toward"*——**它们是重新摆出问题，不是扮演身份**。

⇒ 我们逐字取用 15 帧的 id/label/prompt/tags（MIT），**英文提示词逐条重写为中文**，
但**保持"重新摆出问题"而非"扮演身份"**的定位。
★ 并且**修掉了原项目的一个缺陷**：它用 `Math.random()`（**无 PRNG**），
文档却声称 *"deterministic per-seed"*（自相矛盾）⇒ 我们用 `random.Random(seed)`，
**种子真的可复现**；并保留"**必含 1 个 wild 帧**"的原始逻辑（发散的主要来源）。

### 4.3 机械装配，不是模型汇总

我们最初实现的是"模型汇总"（把各槽位草稿合并）。**实测它把信息丢了**：
在 `temperature=0` 之外的自适应思考下，汇总调用**预算被吃光、返回空串** ⇒ 整条答案承重维度归零。
⇒ ⇒ 改为**机械汇总**：各槽位分别抽断言 → **离散去冗余** → 直接装配（**不让模型再总结一遍**）。
★ 这既更快、又不丢，且**符合我们既有的纪律**（装配必须机械，不由模型重写）。
（"模型汇总 vs 机械汇总"保留为**消融臂**，用于单独测净损失。）

### 4.4 ★ 层2 的代价：发散带来更多维度，**也带来矛盾**

实测（D01）：层2 产出 1056 字符 / 9 条，比直调（128 字符 / 4 条）**多出四条操作性维度**
（验收门槛 / 在线监控 / 寿命管理 / 故障 runbook）——**这四条完全在 `C_t` 之外** ⇒ **锚外**。
**但它同时混进一条事实性矛盾**：层2 写「①③④正确，②错误」，而直调写「②正确」。

⇒ ⇒ 这是本项目**最重要的单条观测**：
> **扩展思维面与保持结论一致，在当前设计下是直接冲突的。**
> ⇒ 层3 的学习信号由此而来（§5）。

⇒ ⇒ ⚠️ **★ 但我们后来的设计（"检测到矛盾就删掉"）被先例直接反对** ⇒ 必须改：

| 先例 | 逐字 |
|---|---|
| **2602.16565**（EMNLP'25）| 显式一致化 *"risks extinguishing critical diversity"*；并引 Smaldino 2024：**"transient diversity, delayed convergence improves problem-solving"** |
| **2603.11781**（DCI）| *"Disagreements are **preserved** in the shared workspace, not flattened by majority rule"*；交付物 = **decision packet**（选定项＋**未决异议**＋少数意见报告＋重启条件）；*"The convergence guarantee is **procedural, not epistemic**"* |
| **2508.12355** | 模型失败模式恰恰是 *"evade exposing conflicts by selecting a single answer"* |

⇒ ⇒ ⇒ **所以正确的机制不是"消解矛盾"，而是"把矛盾显式化、并且让闭合可控"**：
① **层2 默认 `mark`（标注不删）** ⇒ **不收窄搜索空间** ⇒ 保住拓展的收益
② **层3 学 `resolve`** ⇒ **仅当双方都无依据时**（真矛盾）才收窄 ⇒ **该学的学、该留的留**
③ **交付物形态 = decision packet**（DCI）：**未决异议**与**少数意见**要**进交付物**，不能被碾平

⇒ ⇒ ★★ **这恰好就是"优化搜索空间过早闭合"的可操作定义**：
**闭合必须是显式、可控、且只在必要时**；**把分歧碾平本身就是失败模式**。

⇒ ⇒ ★ **顺带一个支持我们架构的先例**：**"多帧 ⇒ 多维度"本身有反例** ——
DPT（**2610.29501**）在 1,156 个并行块上测得 **61.81% 路径对相似度 ≥0.9**，并命名为 **path mode collapse**；
Artificial Hivemind（**2510.22954**, NeurIPS'25 D&B Oral）*"model ensembles may not yield true diversity
when their constituents share overlapping alignment and training priors"*。
⇒ ⇒ ⇒ **"N 次独立直调"其实不独立**（共享同样的 prior）⇒ ⇒ **这正是我们观测到的
"B0_bestof3 常低于 1 次直调"的原因，是已知现象，不是怪事**
⇒ ⇒ ⇒ **而这恰恰说明"认知位置"是必要的**：**帧改变 prior** ⇒ ⇒ ⇒ 我们的**路径间多样性**优势有了机制解释。

### 4.5 ★ 等预算对照臂：增益可能只是"多花了钱"
★ 我们的 `B0_direct` 只花 **1 次生成调用**，而 W 花 **6–16 次**（3 槽位 × 生成+抽取，第二轮再一遍）
⇒ ⇒ **任何"增益"都可能只是"多花了钱"** ⇒ ToT 的同预算 best-of-k 对照是**必答项**。

⇒ **`B0_bestof3`**：**3 次独立直调**（可并行）+ **机械去冗余** ⇒ **调用数与 W 同量**
⇒ ⇒ 差集恰好是 {认知帧解耦 + 机械汇总 + 动作演化} ⇒ **一臂同时解决"等预算"与"ToT 同预算 best-of-k"**
（★ ToT 的轴是**节点数**；节点轴在成本上不等价 ⇒ 我们用**调用数**）。

⇒ ★★ **更强的对照臂 `B0_frames_vote`（Self-Discover 的教训，必加）**

Self-Discover（**arXiv:2402.03620**）逐字：
> *"superior performance against … CoT + Self-Consistency and **majority voting of every module**
> while requiring **10-40x fewer inference compute**"*

⇒ ⇒ **"多帧 ⇒ 多维度"必须与"每帧各跑一遍再投票"比**，否则结论不成立
（Self-Discover 的卖点正是：**组合结构** 优于 **逐模块投票**）。
⇒ ⇒ 我们的 `B0_frames_vote` = **每个认知帧各跑一遍独立答案 → plurality 投票**
（**用 plurality 不用概率加权** —— Self-Consistency 原文：概率加权**不如** plurality，因概率未校准）
⇒ ⇒ **★ 它与我们的"路径间多样性"指标完美配套**：
若我们的**组合结构**（各帧各写各的 + 机械汇总）比"每帧各跑一遍再投票"**更分散**
⇒ ⇒ **Self-Discover 的结论在我们这里复现了**（组合 > 逐模块投票）⇒ ⇒ **这是本稿架构主张的干净证据**。
⇒ ⇒ 且它用**与 W 臂完全相同的帧**（同 seed）⇒ 公平比较。

⇒ ★ **一个待验证的观察**：实测 `B0_bestof3` 在 D01 的 rep1 读到 **0 维**、rep2 读到 **3 维**
⇒ ⇒ **不是系统性归零，是 run-to-run 波动** ⇒ ⇒ 这本身就是 **R 必须 ≥2 且主读数取中位数**的直接证据。
⇒ ⇒ 若最终读数显示"3 次直调取并集"经常**低于**"1 次直调"，其机制是
**多份独立答案的并集容易互相矛盾**（判官判矛盾 ⇒ 承重维度归零）
⇒ ⇒ **"等预算并不免费"** ⇒ ⇒ 而这恰是层2 要解决的问题（认知帧解耦 + 机械汇总 ⇒ 避免矛盾）。

### 4.6 行为空间照明

行为格键 = hash(帧组合, 操作序列)；每格留表现最好的解。
⇒ 读数：**格数**（探索了几种东西）、**格内承重数**、**格间方差**。
⚠️ 若每格承重数几乎相同 ⇒ 说明**帧没被用上** ⇒ 退化到中庸。

## 5 层3：用训练/自迭代的手段优化

### 5.1 我们对"层3"的定义

层2 = 架构先验设计好、运行时**不自我修改**；
层3 = 系统**根据自身经验修改自己**。
⇒ ★ **层2 天然就是层3 的消融臂**（只差"演化"这一个自由度）⇒ 我们把两者实现为**同一个 `evolve` 开关**，
**共用同一份代码与同一条测量管线** ⇒ 消融对照不被代码分叉破坏。

### 5.2 动作空间：从"查表模板"到"可组合的一族"

★ **自查发现**：我们最初的"失败类型 → 预写好的动作模板"（6 个硬编码）**本质上是"设计的手段"** ⇒ **是层2，不是层3**。

⇒ 动作改成**三个正交因子的组合**：

```
action = (repair_type 6 种, scope 2 种, strictness 3 种)   ⇒ 36 个可组合动作
```

★ 关键：**提示词由三个因子拼出来**，不是为每种失败预写一段话
⇒ "选哪个动作"成为**有限取值空间的决策问题** ⇒ 可以被策略学出来。

**策略 = 因子化 softmax，47 参数**：`u[repair] + v[scope] + t[strict] + m[failure][repair]`
⇒ ★ **交互项 `m` 是唯一让"当前失败类型"影响动作选择的通道**
（我们实测过：与 op 无关的状态特征对选择**零作用**）
⇒ ★ **查表策略** = 把人手写的映射编码成因子权重（`from_lookup()`）⇒ 与学出来的**在同一动作空间** ⇒ 可直接消融
（⇒ 且它属于**层2**，因为权重是手挑的大数，不是学出来的）。

### 5.3 失败信号：一个零判官成本的矛盾检测器

层3 最初的卡点：失败信号只有"空输出"一种（判官结果没进循环），
而语义失败（矛盾/未提及/承重为 0）需要判官（**每次 ~50–110 秒**）⇒ 成本是拦路虎。

⇒ 我们先找一个**零成本但语义相关**的失败信号 —— **手上有真实观测可用**（§4.4）：
`detect_conflicts()` ① **选项判定冲突**（同一选项被同时判成立/不成立 ⇒ 正是 D01 的案例）
② **数字冲突**（共享内容词但数字不同）⇒ 纯结构、零模型、零判官、可复算
⇒ 涉事槽位拿到新动作 `act_conflict`（"凡是与别的句子或与依据冲突的直接删掉"）。

### 5.4 目标函数：从标量到二元（**设计形式；当前实现是加权奖励，证据未完成**）

**先例审计给出的答案**：AgentSquare 与 B\* **都撑不起"架构由训练产生"**
—— 前者的动作空间仍是**人划的 4 个槽位**、目标是任务正确率；
后者的动作空间确实自己长，但**生成器被刻意与性能隔离** ⇒ **开环追加**。
⇒ 两者加起来仍是"LLM 开环提议 + 任务分闭环选择" ⇒ **仍会收敛到单一最高分解 ⇒ 那正是中庸**。

⇒ ★ **缺的不是第三个算子，而是：把「多样性」写进目标函数、让它参与选择**
⇒ 形态取自 **EoT（arXiv:2412.7779）** 的二元 MOO + NSGA-II 非支配排序、
**MOAE（arXiv:2609.05992）** 的 Pareto 保持档案、**SetPO（arXiv:2602.1062）** 的集合级多样性。

⇒ **我们的二元目标**：

```
quality  = −(矛盾 + 空产出 + 兜底 + 成本)      （越高越好）
diversity= 与"历史中其它样本"的平均差异度        （越高越好）
⇒ 档案保留全部**非支配**解，而不是 argmax 那一个
```

⇒ ★ **多样性必须是种群级的**（EoT/MOAE 的原意），**不是单个候选的属性**
⇒ 我们先用"样本内去冗余覆盖量"当多样性分量 ⇒ 实测**它与矛盾数强负相关** ⇒ **两分量共线**
⇒ **二元目标退化成标量** ⇒ Pareto 前沿只剩 1 个点（9 样本实测）⇒ **改成种群级后才分离**。

⇒ ★★ **一句必须写进论文的自我纠正**：

> **"标量 argmax 的档案规模必然 = 1" 是定义，不是发现** ⇒ 用它当对照是**同义反复**。
> ⇒ ⇒ **真正的证据必须是下游效应**：Pareto 训出的策略在**真实判官**下
> **承重维度不降、而多样性指标（Self-Sim / 碰撞比）更好**。
> ⇒ ⇒ "档案规模 > 1" 只能作为**机制存在性**证据。

### 5.5 ★ 我们与 AgentSquare 的关系（诚实的定位）

AgentSquare（arXiv:2410.06153，官方实现 `tsinghua-fib-lab/AgentSquare`）是
"自动搜 Agent 架构"的直接前作 ⇒ **我们的贡献不能写成"我们也会搜架构"**。
差别在三处：

| | AgentSquare | 我们 |
|---|---|---|
| **动作空间** | 人划的 4 个槽位（新模块由 LLM 写，但被塞回同一槽）| **三因子可组合动作 + 失败驱动扩展** |
| **目标函数** | 任务正确率（标量）| **（承重, 多样性）二元向量** ⇒ 非支配选择 |
| **选择** | "性能 > incumbent 就换"（精英保留 1 个）| **保留全部非支配解** ⇒ 广度是结构保证 |

⇒ ★ **而我们多出来的一块是**：**用什么目标去长**（有效信息维度数 / 不再中庸）
—— 没人做过（AgentSquare 的目标里 `novelty`/`entropy`/`coverage` 一次都没出现，
它引了 LLMATIC 却没采用 ⇒ **"QD 目标 + 架构搜索"这条路它留空了**）。

⇒ ★ **我们的一个真实优势**：AgentSquare 的模块池**很大** ⇒ 任何增益都可能来自"多试了几种组合"
⇒ **归因不干净**；⇒ 而我们**把"人设计的部分"压到最小**（只留"认知位置"一个自由度 + 固定装配 + 固定判据）
⇒ ⇒ **这样当层3 让空间增长时，增量几乎只能来自"自修改"本身**。

### 5.6 ★★ 层3 的真正学习目标：**何时该发散**

我们把**架构的两个自由度**也交给策略（不是人写死）：
* **`nf`（发散程度 1–4 档）** ⇒ 「**这一题该不该发散、用几条分支**」
* **`mm`（合并方式：mechanical / packet / vote）** ⇒ 「**怎么合并**」

⇒ ⇒ ★ **为什么要交出去**（两个实测理由）：
1. **代价在「合并」**：逐帧投票的承重维度 **4.50** vs 机械汇总 **2.50**（§6.4.4）⇒ 合并方式值得学
2. **收益在「发散」但有条件**：认知位置在**路径多样**的题上把钻牛角尖率 80–100% → **50%**，
   却在**路径单一**的题上**四个臂全踩坑**（§2.2）⇒ ⇒ **"该不该发散"是题型决定的** ⇒ ⇒ **它必须被学出来**

⇒ ⇒ ★ **代理奖励因此被重写为**（事前写死权重）：
```
r = −λ_trap(6.0)   × 陷阱命中        ← 局部不钻牛角尖
    +λ_width(4.0)  × 分支分散度       ← 整体思维面更宽（Self-Sim 原口径，零 embedding）
    −λ_conflict_pairs(0.8) × 跨槽位矛盾对数
    −λ_cost(0.02) × 调用数
```
⇒ ⇒ ★ **前两项在旧版里都没有** ⇒ ⇒ **上一轮训练"没学出偏好"的根因就在这**（奖励与目标没对齐）。
⇒ ⇒ 且**训练题集必须混合**（DEV 9 题 + 对抗 6 题 = 15）⇒ 因为**陷阱命中只在带指纹的题上可测**。

### 5.7 信用分配：哪个动作在什么情况下有用

按 MAME 的思路把"自报置信度"换成"**这条反馈实际引用的依据 ID**" ⇒ **agent×依据 的离散表**
⇒ 让"动作 → 收益"的归因**不依赖 embedding、不依赖措辞相似度**。

### 6.2c ★★★ 把"不可分辨"变成一个**可算的规模问题**

**δ_judge 的最有利估计**（用**非 thinking、最理想**的判官 `MiniMax-M2.5`，n = 12 份答案 × 3 次重复）：

| 逐份读数波动（极差） | 1 | 1 | 0 | 0 | 0 | 1 | 1 | **3** | 1 | 2 | 2 | 2 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| | ← D01 B0bestof3 1 ｜ D01 B0bestof3 2 ｜ D01 B0direct 1 ｜ D01 B0direct 2 ｜ D01 L2 1 ｜ D01 L2 2 ｜ D01 L3 1 ｜ **D01 L3 2 = 3** ｜ D02 B0bestof3 1 ｜ D02 B0direct 1 ｜ D02 L2 1 ｜ D02 L3 1 |

⇒ **中位波动 = 1.0，最大 = 3，读数全同的份只有 3/12（25%）**。

⇒ ⇒ ★★ **于是"不可分辨"不再是一个消极结论，而是一个规模条件**：

* 我们能测的维度数本身只在 **1–5** 之间；
* 而**单份读数的噪声极差中位就是 1** ⇒ ⇒ **任何 ≤1 的架构级效应在原理上就看不见**
  （即使换成最理想的判官）；
* ⇒ ⇒ **要检出 δ_e = 1 的效应，配对比较的样本量必须让配对差的标准误 ≲ δ_e/2**
  ⇒ ⇒ 按每份读数极差 ≈ 1（σ ≈ 0.5–1）估算，**需要 O(10–16) 份/臂**
  （题数 × 重复数）⇒ ⇒ **我们本稿只做了 4 份/臂（2 题 × 2 rep）**
  ⇒ ⇒ **差了一个量级 —— 这就是本稿不能给架构级结论的定量原因。**

⇒ ⇒ ★ **这条比"我们测不出来"有用得多**：它把下一步变成了一个**有预算数字的实验设计**
（⇒ 8 题 × 2 rep 或 4 题 × 4 rep），而不是"多跑几次"。

⇒ ⇒ ⚠️ 但**还有一层**：即使扩到 16 份/臂，也**必须同时**满足 §6.1b 的跨判官一致
⇒ ⇒ ⇒ **"扩规模"与"换判官"必须一起做**，否则只是把噪声测得更精确。

### 6.3 矛盾观测：跨槽位矛盾是"发散的代价"，且可零判官判定

1. **槽内的"删掉与依据冲突的"在架构上不可能生效** —— 一个槽位删不掉另一个槽位的说法
   ⇒ ⇒ 修复必须在**汇总层**（§5.3 的仲裁）
2. **矛盾必须与"承重维度"分开报** —— 它是**机制属性**，不是效果属性

⇒ ⇒ **零判官的矛盾计数**：`detect_opposite_pairs()`（同一决策标记 + 相反极性，纯文本）
⇒ ⇒ 与"钻牛角尖率"（§6.4）并列，**都不需要判官**。

#### 6.4.3 ★★ 结论一：**"用认知位置"确实拓宽了搜索空间**（零判官证据）

> **3 次独立直调，彼此重叠 0.43–0.48；任何"用认知位置"的臂（组合结构 0.110–0.145 / 逐帧投票 0.140–0.169），彼此重叠 0.11–0.18。**
> ⇒ ★ **限定（已过 n 基线 + 嵌套子集校准，见 §6.4.4c）**：该比较**各臂等 n=3**，且 Self-Sim 是**比率**口径（n 基线曲线平坦）⇒ ⇒ **不含机械成分**。
> ⇒ ⇒ **重叠度差约 4 倍** ⇒ ⇒ **"独立采样"其实并不独立**（共享同一 prior）
> ⇒ ⇒ **认知位置真的把 prior 改掉了。**

⇒ ⇒ ★ 这条同时**在我们自己的数据上复现了两条已知结论**：
- **DPT**（arXiv:2610.29501）：1,156 个并行块上 **61.81% 路径对相似度 ≥0.9** ⇒ 命名 **path mode collapse**
- **Artificial Hivemind**（arXiv:2510.22954, NeurIPS'25 Oral）：*"model ensembles may not yield true diversity
  when their constituents share overlapping alignment and training priors"*

⇒ ⇒ ⚠️ ★ **但我们必须诚实说明归属**：`B0_frames_vote`（**不是我们的架构**）的路径间 Sim 同样是 **0.123**
⇒ ⇒ ⇒ **所以"拓宽搜索空间"这个功劳属于「认知位置」本身，不属于我们的装配方式**
⇒ ⇒ ⇒ 我们**不**主张"我们的架构更宽"，只主张"**认知位置会拓宽搜索空间**"（这本身是可发表的、可复现的）。

| `B0_direct`（1 次生成）| 3.00 | — | — |
| **`W_design_L2`**（组合结构）| **2.50** | **0.119** | **同样宽、但信息量最低** |

⇒ ⇒ ★★ **Self-Discover 的结论在我们这里没有复现**（逐帧投票的维度数最高）⇒ ⇒ **如实写**。
⇒ ⇒ ★★ **但这反而把代价精确定位了**：

> **拓宽搜索空间**来自「发散」（认知位置）—— 两类用帧的臂都宽；
> **信息量的损失**来自「**合并**」—— 只有我们的**机械汇总**这一种合并方式掉了维度
> （`W_design_L2` 2.50 vs `B0_frames_vote` 4.50）。
> ⇒ ⇒ ⇒ **要同时"保宽 + 保多"，合并方式就是关键变量。**
> ⇒ ⇒ ⇒ 而这**正是 DCI 的 decision packet**（保留未决异议与少数意见）该上场的地方
> ⇒ ⇒ ⇒ **这是我们下一步那个具体实验的设计依据**（§5.3 的仲裁机制）。

⇒ ⇒ ★ **这一节的净贡献**：不是"我们赢了"，而是
**"我们把「拓宽搜索空间」与「保住信息量」这两件事拆开了，并精确定位了代价发生在合并那一步"** ——
⇒ ⇒ 这比一个"我们更好"的结论**更可用**，因为它指出了下一个可动的地方。

### 6.4.4c ★★ 自有宽度的 **n 基线 + 嵌套子集校准**（三道门，自查用）

层2 用嵌套子集校准发现：「8 支 vs 5 支」的宽度提升 **81% 是采样量增加的机械产物**
⇒ ⇒ **任何随 n 变化的多样性度量，都必须先测出它的 n 基线再判效应**。
⇒ ⇒ **我们对自己的宽度数做了同一件事**（`nested_calib_self.py`，**零 API 成本**，K=200 嵌套子集）：

**门① 各臂分支数相等吗？**
⇒ ✅ **全部 3 支**（`main_big` 各臂 `3×4` 份、`adv` 各臂 `3×4`/`3×5` 份）⇒ ⇒ **层2 的「8⊃5」嵌套陷阱不适用于我们**
（我们**没有** 5 支 vs 8 支的对比）。

**门② 指标定义上会随 n 漂移吗？（n 基线曲线）**
| 臂 | k=2 | k=3 | k=6 | k=12 | 判定 |
|---|---|---|---|---|---|
| `B0_bestof3` | 0.213 | 0.217 | 0.214 | 0.213 | **平坦** |

⇒ ⇒ ★ **根因说清楚了**：**层2 的 Vendi / 模态数是「计数」** ⇒ 定义上随 n 涨；
**我们的 Self-Sim 是「比率」**（两两 Jaccard 的均值）⇒ **定义上不随 n 漂移**。

**跨臂差不依赖 n；跨 n 的绝对值比较无意义。**

⇒ ⇒ ★★ **本稿宽度的三件套写法**（原始读数 + 机械基线 + 限定后的表述）：
1. **原始读数**（等 n=3）：`B0_bestof3` **0.433–0.479** ｜ `B0_frames_vote` 0.154–0.169 ｜
   `W_train_L3` 0.132–0.176 ｜ `W_design_L2` **0.110–0.145**
2. **机械基线**：n 基线曲线**平坦**（比率口径）＋ **各臂分支数相等**（3=3）⇒ ⇒ **无机械成分**
3. **限定后的表述**：
   > **「3 次独立直调的分支彼此重叠 0.43–0.48，而任何"用认知位置"的臂彼此重叠 0.11–0.18」**
   > —— **限定**：**在 Self-Sim（比率）口径下**、**3 支等 n** 时成立；
   > **换到计数口径（模态数）绝对值随 n 变化 4–5 倍，只能比同 n 下的相对序。**
   > ⇒ ⇒ **原表述「0.41–0.61 vs 0.10–0.13」保留，但必须带上这个限定。**

⇒ ⇒ ★ 与层2 的关系（**互补，不冲突**）：
层2 发现的是「**加支数**带来的宽度提升是机械的」⇒ ⇒ **对「加支数」这个动作，我们与层2 同意要降级**；
⇒ ⇒ 而我们主张的是「**换认知位置**带来的宽度差异不是机械的」⇒ ⇒ **两者是不同动作，各自的校准结论不同**。

#### 6.4.5 消融（其余）

| 消融 | 关掉了什么 | 期望读数方向 |
|---|---|---|
| 层2 = 层3 − 演化 | 动作空间不自修改 | 层3 若更好 ⇒ 增益来自"自修改"而非"设计" |
| 模型汇总 vs 机械汇总 | 换回模型汇总 | 机械汇总应**不丢**维度 |
| 去冗余开/关 | 去掉离散去冗余 | 维度数应**虚高**（同一信息被计入多次）|
| **仲裁 `mark` vs `drop_one`** | 闭合的激进程度 | `mark` 应保住更多维度，`drop_one` 应更少但更一致 |

### 6.5 ★ 三项测量学失败（公开报告）

**(a) 判官种子噪声地板恒为 0。** 判官跑 `temperature=0` ⇒ **同一 `measure_version` 内判定确定**
⇒ "只换判官种子"的 δ **恒为 0**（**定义造成的，不是仪器稳**）。
而我们真实栽的跟头是**跨 `measure_version` 的漂移**（净增益读数 `0/+1/−1` → `+1/+4/0`）。
⇒ **修**：新增 `δ_judge_version`（跨判官版本/跨判官模型）+ **硬闸门**
（种子地板退化且未提供变体 ⇒ `optimization_allowed=False`）+ 可信门槛 `max(δ_total, δ_judge_version)`。
★ 这条若不修，**任何非零增益都会被判为可信**。

**(b) 自适应思考吃光 `max_tokens`，正文为空，且静默。**
实测 `MiniMax-M3.1-Flash-Preview`（强制 adaptive thinking，`thinking:{type:"disabled"}` 会 400）：
`max_tokens=2000` ⇒ **两次尝试都 `finish_reason=length`、`content_len=0`** ⇒ **返回空串**；
`8000` 才出正文。⇒ **2000/4000 这两档不是"可能失败"，是"必然失败"。**
⇒ **空串在读数上被误读成"这条臂什么都没产出"** ⇒ **仪器故障伪装成行为结果**。
⇒ 修：预算阶梯从 8000 起；空输出**抬预算重试并计数**；
`finish_reason` 与完成 token 数**必须落盘**（否则事后无法区分"臂写得短"与"预算烧光被截断"）。
⚠️ 我们早期 84 份答案的日志**没记** ⇒ 那个"A5a/A5c 中位 116 字符"的归因**至今无法排除预算截断** ⇒ **如实标为未决**。

**(c) `.pyc` 缓存让我们运行旧代码却以为在跑新代码。**
实测：源码已改、`grep` 可见新代码，但 `import` 拿到**旧模块** ⇒ 自检检测的是旧代码。
⇒ 修：跑批前清缓存 + `python3 -B` + `sys.dont_write_bytecode=True`。
★ 教训：**"改了没反应"先怀疑环境/缓存，再怀疑代码逻辑**（否则会误导向"回滚"这种错误决定）。

**(d) ★★★ 判官读数不可复现：同一答案、同一判官、同一提示词 ⇒ 读数 0 ↔ 3**

**这是本文最重要的方法学发现，也是我们全部读数的上限所在。**

| 答案（D01 / rep1）| 旧解析器 | 宽松解析器 |
|---|---|---|
| `B0_direct` | dims=**0**（n_cards=0, parsefail=**1.0**）| dims=**3**（n_cards=4, parsefail=0.0）|
| `B0_bestof3` | dims=**3** | dims=**0** |

⇒ ★ **两个方向都变** ⇒ **判官读数在 0 与 3 之间随机跳**。

**根因**：解析器只认"行首是 `{`"⇒ MiniMax 的卡片输出**偶发**不合规
（实测出现过 ```` ```json ```` 包裹、行内有前导文字、一行多个对象、尾逗号）
⇒ ⇒ **100% 解析失败** ⇒ 而 `parsefail_rate` 只在"卡片条数不够"时才体现
⇒ ⇒ **静默变成 `dims=0`** ⇒ **看起来像"这条臂没有承重信息"，实际是"测不出来"。**

**修**：① **两级解析**（strict：行首 `{`；loose：**配平括号抽块** + 剥 code fence + 容忍尾逗号）
② **卡片级降批重试**（解析不足 ⇒ 对半分再判）
③ **解析路径（strict/loose/none）单独记录** ⇒ 解析器选哪条路必须可诊断。

**判读后果（这条最要紧）**：
我们的维度数**上限就是 3–4**（DEV 题的结论空间就这么大），而**判官噪声是 0↔3**
⇒ ⇒ **任何架构的效应量都不可能大于这个噪声**
⇒ ⇒ **P1 / P2 的正确判读只能是「不可分辨」** ——
**不是"我们的架构没增益"，而是"在当前判官可靠性下，任何架构的增益都测不出来"。**

**(f) ★★★★ "temperature = 0 ⇒ 判官确定" —— 这个前提是错的**

★ 我们在前一版设计里**明确依赖**过这个前提（"判官 temp=0 ⇒ 同一 measure_version 内确定
⇒ 种子噪声地板恒为 0 ⇒ 只需跨版本测 δ"）。**实测证明前提不成立。**

| 判定任务 | 提示词 | temp | 重复 3 次的读数 |
|---|---|---|---|
| 简单事实 | "2+2 等于几" | 0.0 | **3/3 完全一致**（"4"、"4"、"4"）|
| **多步卡片判定** | 依据 + 题面 + 结论空间 → 逐条 JSON | 0.0 | **`[3,3,0]`**、**`[0,0,3,2]`** ⇒ **波动 3** |

⇒ ★ **不是"temp=0 就不确定"**（简单任务确定）⇒ **而是"确定性随判定任务的复杂度下降"**。
⇒ ⇒ 更可能的机制：**adaptive thinking 引入了一个不受 `temperature` 控制的随机源**
（思考路径本身可能因内部采样而不同 ⇒ 结论随之翻转）。
⇒ ⇒ ⚠️ **诚实交代**：这**只排除了"模型整体不确定"**，**没有**排除"长提示词 / JSON 输出格式 /
批次组成 / 抽样条数"等其它解释 ⇒ ⇒ 我们把它写成**待区分的候选机制**，不是定论。

⇒ ⇒ ★★ **由此得到一条领域级的方法学主张**（比"我们架构无效"值钱得多）：

> **"temperature = 0 ⇒ 评测可复现"是一个不成立的假设（至少对启用 adaptive thinking 的模型）。**
> ⇒ ⇒ **任何基于"判官 temp=0 所以噪声可忽略"的评测 —— 包括我们此前的设计 ——
> 都可能低估自己的噪声。**
> ⇒ ⇒ **判官侧的可复现性必须被【实测】，不能被【假设】。**

⇒ ⇒ ★★★ **跨厂商对照（同一批答案 · 同提示词 · temp=0 · 重复判定）**

| 判官 | 同一答案逐次读数 | 逐份波动 | 卡片数 | 解读 |
|---|---|---|---|---|
| **OpenRouter `x-ai/grok-4.3`** | `[2,2,3]` / `[3,3,3]` | **0–1** | 4–6 | **基本可复现** |
| **MiniMax `MiniMax-M3.1-Flash-Preview`** | `[3,3,0]` / `[0,0,3,2]` | **3** | 4–6 | **完全不可复现** |

⇒ ⇒ ★ **读数差异是真的**（grok 稳定、MiniMax 抖）⇒ 且 **不是**我们代码的问题
（两边的代码路径完全相同）；同时这与 **E5 的独立发现一致**：
同厂商两个判官的 CR 可差 **55 个百分点**（Qwen3-4B 83.60/91.41/70.56 vs Qwen2.5-Coder-3B 58.57/65.75/50.36）
⇒ ⇒ **"决定性变量是判官个体（含其模式），不是厂商"** 这一条是稳的。

⇒ ⇒ ⚠️ ★ **但"波动来自 adaptive thinking"这个归因，我们**不能**单独成立** ——
文献给出**三条竞争解释**，其中两条已被充分证实：

| 解释 | 证据 | 对我们的适用性 |
|---|---|---|
| **批不变性 / 浮点归约序** | **E2**（Thinking Machines, 2025-09-10）：temp=0、Qwen3-235B、**1000 次 ⇒ 80 个唯一补全**，第 103 token 分叉；**E3**（arXiv:2506.09501v2）：reasoning 模型 top-2 token 概率间隙极小、R1-Distill-Qwen-7B 准确率标准差 **9.15%** vs non-reasoning 1.71% | ⚠️ **对所有模型成立、与 thinking 无关、在托管 API 上不可控** ⇒ **我们的读数不能排除它** |
| **自适应思考** | reasoning 模型的思考路径可能不同 | ★ **需要 thinking on/off 对照才能分离** |
| **温度其实不起作用** | **E12**（Liu 2026, SSRN 6432598）：把 temperature 当 G-theory facet 做方差分解（**64,800 观测**），"**temperature contributing effectively zero**"，方差主要来自 item×evaluator 交互 | ⇒ 必须正面处理，不能装作没看见 |

⇒ ⇒ ⇒ ★★★ **我们补上了文献里空着的那一格：同厂商的 thinking on/off 对照**

| 判官 | 模式 | 逐次读数（同一批答案 · temp=0） | 波动 |
|---|---|---|---|
| `MiniMax-M3.1-Flash-Preview` | **强制 adaptive thinking**（`thinking:disabled` 会 400）| `[3,3,0]` / `[0,0,3,2]` | **3** |
| **`MiniMax-M2.5`（同厂商、同 API、同一切片）** | **non-thinking**（实测 `reasoning_content` 长度 = 0）| `[3,3,3]` | **0** |
| `x-ai/grok-4.3` | — | `[2,2,3]` / `[3,3,3]` | 0–1 |

⇒ ⇒ ★ **同厂商、只差"是否强制 thinking" ⇒ 波动 3 → 0**
⇒ ⇒ ⇒ ★★ **这是文献里空着的一格**：E2 明确标注其实验是 "(non-thinking mode)"；
E1 明确把 reasoning 判官**排除**在温度扫描之外 ⇒ ⇒ **没有人做过这一对照**
⇒ ⇒ ⇒ **我们从"复述已知"变成了"新增"**。
⇒ ⇒ ⇒ 且它**同时说明"批不变性底噪"不是主因**：grok 与 M2.5 都稳定
⇒ ⇒ **底噪存在，但不产生 0↔3 的翻转；翻转是 thinking 特有的。**

⇒ ⇒ ⇒ **由此得到一条可直接执行的评测规则**：

> **判官不要用强制 adaptive thinking 的模型**（或至少必须**实测**它的可复现性）。
> ⇒ 实测：`MiniMax-M3.1-Flash-Preview` 波动 3 ／ `MiniMax-M2.5` 波动 0 ／ `grok-4.3` 波动 0–1。

⇒ ⇒ ⇒ ★★ **本稿因此主张"现象存在性 + 方向性 + 一个有对照支撑的归因（thinking）"**：

我们补的 **thinking on/off 对照**（**同厂商 MiniMax**：`M3.1-Flash-Preview`（强制 adaptive thinking）
vs **`M2.5`（non-thinking，已实测 `reasoning_content` 长度 = 0）**）
是**从"复述已知"变成"新增"的唯一一步** ——
因为 E2 明写其实验是 non-thinking mode、E1 明写把 reasoning 判官排除出温度扫描
⇒ ⇒ **文献里这个对照是空的。**

⇒ ⇒ ★★ **由此得到一条可操作的评测规则**：

> **判官必须选在 `temperature=0` 下可复现的模型** —— 实测 `grok-4.3` 波动 ≤1、
> `MiniMax-M3.1-Flash-Preview` 波动 3。
> ⇒ ⇒ **或**必须加**判官逐条 verdict 一致性检验**作检测器，把不一致的判定标为 invalid 并重判。

⇒ ⇒ ⚠️ ★ **一个必须写进论文的自我限制**：
**我们此前所有以 MiniMax 为判官的读数（含 cmp8 的 84 份、U1 的 12 份）都带着 δ≈3 的噪声**
⇒ ⇒ **那些读数本来就不该支持任何架构层面的结论**
⇒ ⇒ **我们一直给出的"不可分辨"判断是对的 —— 现在它有了定量依据。**

⇒ ⇒ ★ **可操作的后果**：我们此处的噪声**不是不可修的** ——
它的根因是"多步判定的输出不稳定"，而**判官自带的 verdict 一致性检验**（同一批卡片判两次，
逐条比对 verdict）就是它的**检测器** ⇒ ⇒ **把不一致的判定标为 invalid 并重判**，
是比"加重复次数"更有效的降噪手段。

⇒ ⇒ ⇒ **由此得到一个领域级的方法学主张**：

> **"搜索空间过早闭合"在测量层有一个对应物：判官读数塌到 0。**
> ⇒ 而我们证明：**测量层的塌缩可以独立于被测行为存在。**
> ⇒ ⇒ **任何关于"被测系统更聪明"的结论，都必须先排除测量层的塌缩。**

⇒ ⇒ 这比"我们的架构有效"值钱：它是**可复现、可归因**的诊断链，
而且它是 §1 那个命题（**中庸不是模型能力问题，而是搜索过程的收敛**）在**测量侧**的镜像。

**(g) ★ 锚外判定器（`VD_anchor_out` 的自动判定）**松紧两端都错** ⇒ 该判据目前不可用**

我们的 `VD_anchor_out` 需要判定"判官给出的决策岔口是否在预注册的 `C_t` 里"。
第一版用**决策指纹**（选项标记 + 数值 + 内容词）做匹配 ⇒ 实测**两个方向都错**：

| 样本 | 真实归属 | 判定的 | 错在哪 |
|---|---|---|---|
| 「顺序读取标称峰值为 7450 MB/s」| **锚内**（就是 `C_t` 的 ①）| **锚外** | **假阳性**：C_t 内的内容被判成锚外 |
| 「当 SMART 的 Critical Warning 非零即换盘」| **锚外** | 锚外 ✔ | —— |
| 「RTO≤5 分钟、RPO≤60 秒」| **锚外** | 锚外 ✔ | —— |

⇒ ★ **诊断**：假阳性来自"**锚内的也认不出来**"——指纹的三个判据
（选项标记相同 / 数值集合**完全**相等 / 内容词交集 ≥3）**同时**过不了
⇒ ⇒ 指纹匹配这条路**在语义判断的位置上用结构量代替了语义** ⇒ **不该继续调阈值**。

⇒ ⇒ ★ **正确做法（下一步，我们没有在本稿实现）**：
把"这个岔口是不是 `C_t` 里已有的决策"**交给模型**：
判官 A（**不给** `C_t`）输出岔口 ⇒ 判官 B（**给** `C_t` + 该岔口）回答"是否等同于 `C_t` 中的某一条"
⇒ ⇒ 一次额外调用，换掉整个脆弱的指纹层。

⇒ ⇒ ⇒ **本稿对 P3 的结论是：「该判据在当前实现下不可用，且我们给出了它的失效模式与正确做法」**
—— **不是**"锚外发现成立"，**也不是**"锚外发现不成立"。

| # | 症状 | 静默成了什么 | 修法 |
|:-:|---|---|---|
| 1 | 判官 temp=0 ⇒ 种子地板恒为 0 | "增益 > δ ⇒ 可信" | `δ_judge_version` + 硬闸门 |
| 2 | 自适应思考吃光 `max_tokens`（两处）| "这条臂没产出" | 预算阶梯从 8000 起 + 空输出计数 |
| 3 | 双阶梯嵌套（外层 × 客户端内层）| "跑不动"（实测 40 分钟/批次）| 阶梯独占 + 批次并行 |
| 4 | **判官输出偶发不合规 ⇒ 解析 100% 失败** | **"这条臂没有承重信息"** | 两级解析 + 降批重试 + 解析路径可诊断 |

⇒ ⇒ ★ **共同形状**：都是**仪器故障伪装成行为结果** ⇒ ⇒ **所以"读数"必须带着"仪器健康度"一起报。**

### 6.6 跨厂商判官交叉

按 ToT 的换评估模型交叉实验（同源 74% / 换评估器 64% / 31%）：
换判官后若增益塌掉 ⇒ **结论无效**。

★ **我们把"换判官"做成了两项独立的事**：
① **可复现性对照**（§6.5(f)）⇒ 同提示词重复判定 ⇒ 量化"这个判官自己稳不稳"
② **主批次判官切换**（生成侧仍 MiniMax、$0 ⇒ 只换判官 ⇒ 唯一变化是"谁在判"）

⇒ 主批次的跨厂商读数见 §6.2（判官 `x-ai/grok-4.3`，`judge_same_vendor=false`）。

⚠️ **换判官时踩到的两个坑（都属于"静默变 0"家族）**：
① **抽取侧没跟着换模型名** ⇒ 拿 MiniMax 的模型名打 OpenRouter ⇒ `400 not a valid model ID`
   ⇒ 旧代码把它吞成空串 ⇒ 读数 0 ⇒ **看起来像"grok 不确定"** ⇒ **结论会完全颠倒**
② **OpenRouter 上的 `MiniMax-M3.1-Flash-Preview` 已下架** ⇒ 任何仍在引用它的配置都会静默失败
⇒ ⇒ **修法**：① 客户端**全部尝试失败 ⇒ 抛错带原因**（状态码 + 响应体）
② 抽取侧的模型名**必须跟着判官走**

### 6.7 ★ 判读规则是**预注册**的（写于读数产出之前）

我们把四个待判命题（P1 层2 vs 等预算臂 · P2 层3 vs 层2 · P3 锚外发现 · P4 代理奖励是否迁移）
**在看到读数之前**写死在 `routes/PREREG-DECISION-RULES-2026-10-22.md`，
并留了「口径变更记录」栏 ⇒ **R 由 3 改 2 这件事也登记在里面**（附动机与影响）。
⇒ 理由：我们一路栽过两次 —— ① 拿恒为 0 的 δ 当"增益 > δ ⇒ 可信"的门槛；
② "短产出"是臂的行为还是预算烧光，**当时日志没记 `finish_reason`，事后无法区分**。

### 6.8 统计纪律

分析单元 = **题**；同题多步 rollout 不是独立样本；
差值必须 vs **种子噪声地板**，落在地板内写「**不可分辨**」而非"无效应"；
不因解析失败率高或样本少而重跑（p-hacking）；invalid 如实报 valid/total。

## 7 讨论

### 7.1 ★★ C1 跨组冲突的裁决：**不是口径问题，是「处理变量不是同一个」

第二组（层2）与我们曾就"认知多样性是否有效"给出相反结论。**根因不是指标口径、不是题型、不是天花板 —— 是两边测的"帧"根本不是同一类东西**：

| | 第二组的「认知框架」| 我们的「认知位置」|
|---|---|---|
| 来源 | 仓内 `creativity_lab/prompts.py::FRAMES`（**7** 条，中文）| ADHD 项目 `src/packs/core.ts`（**15** 条）|
| 内容 | 长时段尺度 / 系统承载力 / 反面案例 / 无利害观察者 / 亲历者视角 / 硬约束 / 二阶效应 | 十岁小孩 / 蚁群 / 反转 / 去假设 / 速通者 / 凌晨三点 on-call / 跨域生物学 … |
| **机制** | **换【分析角度】** —— 同一问题上的不同看法 | **换【问题表述】** —— 重新摆出问题本身 |
| 效果 | 分析角度变多，但**推论链还是同一条** ⇒ **模态数不变** | 问题被重述 ⇒ **推论链本身变了** ⇒ **模态数涨** |

⇒ ⇒ ★★ **⇒ 这就是完整机制**：
> **「表层分化 ≠ 路径分化」成立，而且现在有了机制解释**：
> **分化到哪一层，取决于帧是"换分析角度"还是"换问题表述"。**
> ⇒ ⇒ 而且**两边都对** —— 层2 测到的是"换分析角度不增路径数"，我们测到的是"换问题表述增路径数"。

⇒ ⇒ ★ **并且这与我们的题型分层读数完全一致**（§2.2 / §6.4.4b）：
> **在「路径多样」的题上**：换问题表述有效（钻牛角尖率 80–100% → **50%**）
> **在「路径单一」的题上**：换问题表述**无效**（D01 四臂**全踩坑**）
> ⇒ ⇒ ⇒ **⇒ "该不该发散"由题型的路径空间决定 ⇒ ⇒ ⇒ 这正是层 3 应当学出来的决策**（§5.4）

⇒ ⇒ ★ **一个必须自己承认的降级**：
> 我们原来说"认知位置真的把 prior 改掉了" —— 在**对比基线也变了**的情况下这**不严格**。
> **严格版**：「**把基线多样性水平提升后，支间重叠度随之下降**」= 事实
> （我们的 4 个基线就是一条单调曲线：0.454 → 0.154 → 0.128）；
> 「**认知位置本身**有独立贡献」= **需要与分析角度型帧（B2 臂）对照**才能断言。
> ⇒ ⇒ 我们把 B2 臂的必要性写进了 §6.4.4b 的判读。

⇒ ⇒ ★ **对文献的诚实交代**：我们与 ToT 的 "samples vs nodes"（best-of-100 **49%** ≪ exploring more nodes b=5 **74%**）**同构** ⇒ ⇒ 凡引用处**一律标「ToT 复述」**，不得在同一份材料里既当引文又当发现。

### 7.2 与既有工作的关系

**7.2.1 AgentSquare（arXiv:2410.06153）** —— "自动搜 Agent 架构"的直接前作。
⇒ ⇒ **我们的贡献不能写成"我们也会搜架构"**。差别在三处：动作空间（可组合 + 失败驱动扩展）·
目标函数（有效信息维度数，而非任务正确率）· 选择（Pareto 保留多个解，而非 argmax 一个）。
⇒ ⇒ ★ 且它的目标函数里 `novelty`/`entropy` 一次都没出现 ⇒ ⇒ **"QD 目标 + 架构搜索"这条路它留空了**。
⇒ ⇒ 我们多出来的一块是**用什么目标去长**。

**7.2.2 PSFA（Wray / Kirk / Laird, arXiv:2405.12147 / Cognitive Systems Research 94:101409）**
—— 最接近我们主命题的工作。它发现的"漏掉项"参照系是**人类专家的问题空间分解（Newell 1980 / GOMS）**、
候选槽位**先验封闭**；它自陈 *"...the least successful of all the nodes we included"*，
把"生成 novel problem spaces"列为**开放问题**，并写下 *"strong attractor effect"* 与
*"parrot similar problems and solutions"*。
⇒ ⇒ ★ **它与我们同病**：都是在"人先划的格子里"工作 ⇒ ⇒ **⇒ 我们与它的差异点正是「锚外」**。

**7.2.3 Diversity Collapse（arXiv:2604.18005, Findings of ACL 2026）** —— 提供测量侧的对称证据：
**Vendi/N 从 1.03 跌到 0.47**，而绝对 Vendi 单调上升（3.09→3.32，+7.4%，paired t=5.46，p<0.0001，17/20 增长）
⇒ ⇒ **"多样性利用率随 N 降、绝对量随 N 升"是已发表的普遍陷阱** ⇒ ⇒ 我们的方法学主张不是孤例。

**7.2.4 DCI（arXiv:2603.11781）** —— "**可控闭合**"的交付物形态：
*"Disagreements are preserved … not flattened by majority rule"* + **decision packet**
（未决异议 + 少数意见 + 重启条件）+ *"convergence guarantee is procedural, not epistemic"*。
⇒ ⇒ 我们层2 的"容忍分歧"与层3 的"学何时收窄"直接沿用这一形态。

**7.2.5 ToT（arXiv:2305.10601）** —— 我们的"认知位置 vs 重复采样"与它的 "nodes vs samples" 同构（见 7.1）。

**7.2.6 判官可靠性（E1/E2/E3/E5/E9/E10/E12）** —— 全部已逐条核过题录，列于 §9。



**7.1 与 PSFA 的差异**（§3.6）：PSFA 在 GOMS 先验格子里填，**我们要求锚外可数**。
⇒ 这不是"我们更好"，而是**可证伪性**的差异：我们给了一个它没给的、**会让我们自己失败**的数。

**7.2 与 Diversity Collapse 的关系**：该文的贡献是**诊断**（多样性崩塌 + 权威吸引子 + 强吸引子效应），
我们的贡献是把它接到**承重**判据上：*多样性*不等于*维度*，*权威*必须从判官身上剥掉。

**7.3 与 AgentSquare 的关系**：它证明**模块化设计空间**是可搜的；
我们的**第五模块 E（承重检验）** 在它的四模块框架里**无处安放** ⇒ 既是风险也是差异化。

**7.4 与 ToT 的关系**：ToT 搜解路径；我们搜"该考虑哪些维度"。
★ 但 ToT 的同预算对照提醒我们：**没有 best-of-k 对照，"架构有增益"可能只是"多花了钱"**。

## 10 结论

我们把「答案不中庸」拆成了**可测量的量**（承重维度数、净维度增益、中庸度 —— 全部换成有出处的口径），
做了一套**可运行**的干预（层2 认知帧解耦 + 机械汇总 + 行为照明；层3 失败驱动动作演化 + 二元目标 + Pareto 档案），
并**公开报告了评测层本身的塌缩**：

> **同一批答案上，同一判官重复判定 3 次，读数波动可达 3 分**（与是否强制 thinking 相关）。
> ⇒ ⇒ **在跨判官一致达成之前，架构级结论不成立** —— 这不是"我们的架构不好"，
> 而是"**当前评测的分辨力不足以支撑架构级结论**"。

⇒ ★ **三条可执行的防护规则**（本稿最具可操作性的产物）：
1. **判官必须实测其可复现性**，不能假设 `temperature=0` 就够 —— 实测同厂商
   `M3.1-Flash-Preview`（强制 thinking）波动 **3**、`M2.5`（non-thinking）波动 **1**、`grok-4.3` 波动 **0–1**
   ⇒ **判官不要用强制 adaptive thinking 的模型**；
2. **必须区分"两种 0"**：仪器层（卡片没出来）与内容层（卡片在、判定翻转）—— 在主指标上**完全一样**；
3. **跨判官一致是任何架构级结论的前提**。

⇒ ★ **一句自我限制**：本稿**不**支持"我们的架构让答案更宽"；我们支持的是
"**当前评测口径会把架构级效应吞掉，而且我们能指出它在哪一步被吞掉**"。
⇒ ⇒ 而这恰好把"搜索空间过早闭合"从**生成侧**（答案趋同）延伸到**测量侧**（读数塌 0 / **同一判官重复判定即波动**）——
⇒ ⇒ **两者是同一个现象的两面**，⇒ ⇒ **层 1（注意力机制层面的原因）应当能同时解释这两面。**

⇒ ⇒ **一条不能让自己失败的主张，不值得写进论文** ⇒ 所以我们把
**`VD_anchor_out` 的实现失效模式**（假阳性来自"锚内的也认不出来"）与**正确做法**
（把语义判断交回模型：判官 A 不给 `C_t` 出岔口，判官 B 给 `C_t` + 岔口 判是否等同）
一并写下——**哪怕它现在还不可用**。

### 10.1 ★ 而零判官的空间指标给出了**正向**的那一半（§6.4）

> **3 次独立直调的分支彼此重叠 0.43–0.48；任何"用认知位置"的臂彼此重叠 0.11–0.18**（**等 n=3，已过 n 基线校准**）。
> ⇒ ⇒ **"独立采样"其实并不独立**（共享同一 prior）⇒ ⇒ **认知位置真的把 prior 改掉了**
> ⇒ ⇒ **搜索空间确实被拓宽了** —— 零判官、零噪声、可复现。
⇒ ⇒ ★ 并在我们自己的数据上复现了 **DPT 的 path mode collapse**（61.81% 路径对相似度 ≥0.9）
与 **Artificial Hivemind 的 shared prior**。

★ **但归属要诚实**：`B0_frames_vote`（**不是我们的架构**）的路径间 Sim 同样是 **0.123**
⇒ ⇒ **功劳属于「认知位置」本身，不属于我们的装配方式** ⇒ ⇒ 我们**不**主张"我们的架构更宽"。

### 10.2 ★★ 而代价被精确定位到了「合并」这一步（这是本稿最可用的结论）

| | 搜索空间（路径间 Sim，越低越宽）| 信息量（承重维度中位）|
|---|---|---|
| 3 次独立直调 | 0.461（窄）| 4.00 |
| 逐帧各跑一遍＋投票 | 0.123（宽）| **4.50** |
| **我们的组合结构（机械汇总）** | **0.119**（宽）| **2.50**（低）|

⇒ ⇒ **拓宽来自「发散」，损失来自「合并」** ⇒ ⇒ **要同时"保宽 + 保多"，合并方式就是关键变量**
⇒ ⇒ ⇒ **下一个该动的就是合并**（⇒ DCI 的 decision packet：保留未决异议与少数意见，
⇒ ⇒ 而不是把分歧碾平或简单投票）⇒ ⇒ **这也是层 3 的仲裁机制（层2 容忍、层3 学何时收窄）的落点。**

⇒ ⇒ ★ **本稿的净贡献因此不是"我们做出了更好的架构"，而是**：
**① 一个可失败、可测量的度量体系；② 一条"评测层会吞掉架构层效应"的诊断链；
③ 一条把「拓宽搜索空间」与「保住信息量」拆开、并定位代价发生的步骤的分解。**
⇒ ⇒ **③ 直接指出了下一个实验该动哪里** —— 这比一个"我们更好"的结论**更可用**，也更不容易被推翻。
