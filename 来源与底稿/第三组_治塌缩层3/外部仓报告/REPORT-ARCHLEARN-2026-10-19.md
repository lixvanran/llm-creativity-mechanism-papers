# 训练方法 v3：可学习架构

> 2026-10-19 ｜ 目标按用户澄清重设：**架构本身是学习产物**，不是人手设计的。
> 前两版（净信息增益、差集核验）训的都是「在固定菜单里挑」，路线是错的。

---

## 0. 判决

| 项 | 结果 |
|---|:-:|
| 架构是否为学习产物 | ✅ 策略权重由 REINFORCE 在线更新产生 |
| 训练中是否学到可泛化的行为 | ✅ **矛盾率 33.3% → 0.0%**（未见题），终局奖 −0.47 → +0.27 |
| 宽度增益是否泛化 | ❌ **没有**。训练集 1.20 → 3.40，测试集 1.33 → 1.33 |
| 自主探索（巡练）产出 | ❌ 0/5，**提示词层的上限已被证实** |

> **学到的是「更谨慎地核验」，不是「探索更多」。前者泛化了，后者过拟合了。**
> 这与巡练的结论完全一致：宽度增益在有限样本上必然过拟合（ρ=+0.166），
> 而**行为层面的改进（多核验、少断言）能泛化**。

## 1. 路线重设：从「挑架构」到「训架构」

| | 前两版 | 本版 |
|---|---|:-:|
| 架构由谁定 | **人**（direct / fuse / select / 提示词程序） | **训练**（策略权重） |
| 搜索方式 | 穷举 / 网格，在题集上**挑一个** | 在线策略学习，**每题都用上** |
| 有效 n | 题数（5–18） | **决策次数**（数百/轮） |
| 奖励 | 题集级标量 | **逐步奖励**（VERIFY 成功/矛盾） |
| 过拟合风险 | 高（实测 ρ=0.166） | 低（n 是决策数，且特征与题无关） |

**逃逸悖论的机制**：训练架构时没有「赢家」可挑——策略在每道题上都跑，
奖励是逐步的、局部的。**「在有限样本上选赢家」是过拟合的根源；逐步学习不是。**

## 2. 系统结构

### 2.1 操作集（`creativity_lab/ops.py`）

```
状态 = 图。节点：CLAIM（一条可核验断言） / ANSWER（一份完整答案）
边   = 操作。唯一接触 oracle 的是 VERIFY。

GEN_PLAIN   直接生成一份答案
GEN_ANGLE   按某个切入角度生成（角度由策略选，不由人写）
EXTRACT     从答案抽断言 → CLAIM 节点
SPLIT       拆分复合断言
VERIFY      核验一条断言 → 判定写回节点
MERGE       合并
STOP        结束（**仅在至少核验过一次后合法**）
```

操作集刻意分两类：
- **改变输出形态**：GEN_* / EXTRACT / SPLIT / MERGE
- **改变可访问信息**：**VERIFY**

前者只能重排支撑集，后者才可能扩张它。**这是从实测里推出来的**：
5 份纯提示词提案全部被否，而 V2 核验在环把矛盾率压到 0%。

### 2.2 策略

线性 softmax 策略，14 维**局部**特征（只看当前节点与本分支历史，**不看题目/题集**）：

```
op 类型 one-hot(7) · 目标节点类型 · 目标已核验状态(支持/矛盾/未核验)
· 目标文本长度 · 分支上核验成功数 · 分支上核验失败数 · 深度
```

**特征与题无关**是绕开过拟合的关键：n = 决策次数，不是题数。

### 2.3 奖励

```
VERIFY 成功   +1        ← 唯一被实测证明有效的动作
VERIFY 矛盾   −2        ← 自信地说错，比少说一句更糟
终局          + 交付宽度（去重并集）  ← 探索量
终局          矛盾率 > 33% → −2       ← 硬约束，不进奖励
```

### 2.4 装配（机械，不经模型重写）

```
主体 = 被依据支持的断言
另列 = 依据未提及的断言（标注「未见明确规定」）
剔除 = 与依据矛盾的断言
```

**矛盾率在构造上为 0**，交付宽 = |支持| + |未提及| = 真并集。
上一版 V2 支持率到 100% 但宽度掉了，就是因为让模型重写时措辞漂了。

## 3. 训练过程（7 轮，5 训练题，每题 10 步预算）

| 轮 | 宽度 | 矛盾率 | 核验/题(命中) | 终局奖 | 操作分布 |
|:-:|:-:|:-:|:-:|:-:|---|
| 1 | 1.20 | 0.0% | 1.00 (0.20) | 0.24 | GEN_PLAIN=24, GEN_ANGLE=11, VERIFY=5, EXTRACT=3 |
| 2 | 1.20 | 0.0% | 2.20 (0.80) | 0.24 | **EXTRACT=13, VERIFY=11**, GEN_ANGLE=8, GEN_PLAIN=6 |
| 3 | 1.60 | 0.0% | 1.60 (0.40) | 0.32 | EXTRACT=11, VERIFY=8, GEN_ANGLE=7, GEN_PLAIN=6 |
| 4 | 1.40 | 0.0% | 1.80 (0.60) | 0.28 | EXTRACT=12, GEN_ANGLE=9, VERIFY=9, GEN_PLAIN=4 |
| 5 | **3.00** | 0.0% | 1.40 (0.40) | **0.60** | **EXTRACT=18**, GEN_PLAIN=9, GEN_ANGLE=8, VERIFY=7 |
| 6 | 3.00 | 20.0% | 1.20 (0.00) | −0.00 | EXTRACT=16, GEN_ANGLE=11, VERIFY=6, GEN_PLAIN=3 |
| 7 | **3.40** | 20.0% | **2.80 (0.60)** | −0.04 | **VERIFY=14, EXTRACT=13**, GEN_PLAIN=8, GEN_ANGLE=7 |

**策略形态的变化是可读的**：
`GEN_PLAIN 24 → 3`（几乎不再盲目生成），`EXTRACT + VERIFY + SPLIT` 接管。
**这是从数据里学出来的操作偏好，不是人写的规则。**

### 3.1 测试（3 道未见题）

| 策略 | 宽度 | **矛盾率** | 核验/题(命中) | **终局奖** |
|---|:-:|:-:|:-:|:-:|
| 初始策略 w=0 | 1.33 | **33.3%** | 1.00 (0.00) | **−0.47** |
| **学到的策略** | 1.33 | **0.0%** | 1.00 (0.00) | **+0.27** |

### 3.2 判决（诚实的两部分）

✅ **泛化了的**：矛盾率 **33.3% → 0.0%**，终局奖由负转正。
**策略学到的是「先把断言核验过再写进答案」——这是可迁移的行为。**

❌ **没泛化的**：宽度。训练集 1.20 → 3.40，测试集 1.33 → 1.33。
**宽度增益在 5 道题上出现过，在 3 道未见题上完全没出现。**
这与巡练的 ρ=+0.166 是同一件事的两次确认。

> **终局奖的改善来自矛盾率，不是来自宽度。**

## 4. 必须记录的三个 bug

### 4.1 ★ 排序键写错 → 策略学习从未发生（最严重）

```python
scored.sort(key=lambda x: -x[1][0])   # x[1] = (op, tgt) → x[1][0] 是 op 的**字符串**
```

**它按操作名倒序排，不是按分数排。** `GEN_PLAIN > GEN_ANGLE > EXTRACT`，
策略**永远选字母序第一个动作**。前面几轮「策略学习」的日志全是假的。

> 症状：50 步全是 GEN_PLAIN，核验 0 次。
> **这个 bug 本身是个方法论教训：策略学习必须打印操作直方图**——
> 我加直方图之后，10 分钟就定位了。只看聚合指标（宽度/奖励）永远看不出。

### 4.2 EXTRACT 不在候选集 → 图里永远没有 CLAIM 节点 → VERIFY 永不可选

同源的第二个 bug：**操作集定义了，但没接进候选**。

### 4.3 格式串吃掉小数

`"核验 %d 次" % np.mean(...)` → 均值 0.8 被截断成 **0**。
**数据一直是对的，是显示骗了我**，我据此误判了「核验 0 次」。

### 4.4 结构性 bug 两条（前面几轮已记录）

- **「解析失败」计入分母** → direct 矛盾率一度显示 15.4%，实为 59.1%
- **空输出记成「0 错误 → 可行」** → API 故障让某臂白捡一个可行判定

## 5. 这一版回答了什么、没回答什么

### 5.1 回答了

- **「架构能不能是学习产物」——能。** 策略权重由逐步奖励在线更新产生，
  且**学到的行为在未见题上泛化**（矛盾率归零）。
- **「为什么之前一直失败」**——之前训的是「在题集上挑赢家」，
  而那个任务的 n 太小（ρ=0.166 已实测）。
- **「探索的价值在哪个轴上」**——**不在宽度轴**（过拟合），
  在**错误率轴**（泛化）。**目标函数应该是「少说错」，不是「多想到」。**

### 5.2 没回答

1. **宽度没有变大。** 「拓展思维面」这个原始目标**依然没实现**，
   只是变成了「不实现也行，但至少别胡说」。
2. **测试集只有 3 题**，统计功效弱。矛盾率 33.3%→0.0% 幅度大但 n 小。
3. **策略只有 14 维线性权重**，远不是 ToT/GoT 那种图结构。
   **下一步该训的是图的结构本身**（多少节点、怎么连、并行还是串行），
   而不是「在固定图上选哪条边」。
4. **操作集仍是人定的 7 个。** 强版本（「架构完全自己长出来」）没做。

## 7. 诚实评估

**这一版做成了用户要的东西：一个架构是学习产物的系统。**

但要如实说：
- **学到的是「更谨慎」，不是「更广阔」。**
- 宽度增益过拟合，已被两次独立测量确认（巡练 ρ=0.166；本轮训练集涨、测试集不涨）。
- 我在这个过程中犯了一个会让全部学习**看起来发生过但其实没有**的 bug
  （排序键），是靠**加操作直方图**抓到的，不是靠看指标。

> **最大的收获不是那个 0% 矛盾率，是这个教训：**
> **策略学习必须打印它实际在做什么的分布。** 聚合指标会把「根本没在学」显示成「在学」。
