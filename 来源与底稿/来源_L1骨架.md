## 2. 章节骨架与论证链

### §1.1 现象：闭合的可观测表征
**要说的**：闭合不是"答案变差"，是**想法变少**。

论证链：
1. 每份答案抽 N 条可核验断言 → 去重后只剩 M 条不同考虑（已有：9 → **5.2**）
2. 实例内不同采样互相余弦极高（已有：**0.91–0.97**）
3. ⇒ **分支数增加 ≠ 有效信息维度增加**（已有：去重后宽度 0.457 vs 基线 0.500）

**已知风险（必须正面处理）**：审稿人会问「这不就是输出冗余吗，不是塌缩吗？」
**回应**：把两者区分开 —— 冗余是**同一答案内的重复**；塌缩是**不同答案之间的收敛**。本节同时给两者，**并明确本工作测的是后者**。

**待补**：S3 的 α(直调) vs α(工作流) 实测值。

### §1.2 「闭合」的可操作定义（本文的 C1）
**要说的**：这是全文的支点。

> **定义 1（黑盒闭合）**
> 设 R 为一个**参照系**（另一个模型 / 另一个采样温度 / 另一类任务）。
> 模型 M 的**可达集** A(M) = M 独立采样 K 次所得产出的去重并集。
> 则 M 相对 R **闭合** ⟺ `|A(M)| < |A(M) ∪ A(R)|`，且差异超出噪声地板。

**为什么这个定义重要**：
- 它把「闭合」从**修辞**变成**可证伪命题**
- 它**不需要** logprobs / 注意力探针 ⇒ 在纯 API 环境下可执行
- 它把"归因"变成**可分离的**问题：换参照系 = 换层

**必须写的诚实声明**：
> 本文**不**主张已识别闭合的模型内部成因（注意力机制 / 表示坍缩 / 解码熵）。
> 在黑盒 API 条件下内部探针不可得（`logprobs` 不可用 ⇒ typicality / NLL / perplexity / 熵族全部作废）。
> 本文主张的是**分层判据的可执行性**，以及在可执行范围内的分离结果。

### §1.3 三层分离协议
用一张表说清"每个轴是什么、改变什么、预期测到什么"：

| 轴 | 改变什么 | 参照系 | 主指标 | 状态 |
|---|---|---|---|---|
| **解码层** | 采样温度 / top-p / 采样数 | 同模型不同温度 | α(T) = d log PR / d log K | **S1 在跑** |
| **表征层** | 模型档位 | 同族不同档位 | Δ_PR = PR(跨档) − PR(同档 K=32) | 预注册待触发（`PREREG_M_axis.md`） |
| **架构层** | 工作流形式（分支数 / 融合策略 / preflight / 自检） | 同模型不同工作流 | PR(工作流) vs PR(direct) | **已有**：18 变体 13 个更差 |

**这一节是本文的骨架** —— 三轴全部测了，第 1 层就成了一个**完整的分层论证**；只测一轴，就只能是一个单点观察。
